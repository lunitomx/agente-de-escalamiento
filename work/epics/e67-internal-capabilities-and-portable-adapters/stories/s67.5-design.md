# Diseño S67.5 — Paquete de especialistas internos

## Problema y valor

E45 ya define cuatro contratos privados con triggers, no-triggers, contexto
mínimo, permisos, salida y límites. Esos contratos viven en el coordinador
local; no hay todavía una proyección instalable que permita a Codex o Claude
delegar a una definición con la misma frontera.

## Decisión

Crear un compilador local que toma exclusivamente `SPECIALIST_CONTRACTS` y los
perfiles del catálogo MVP. Produce un manifiesto común y dos representaciones:
TOML para `.codex/agents/` y Markdown con frontmatter para `.claude/agents/`.
No fija modelo, razonamiento, MCP ni permisos externos: cada perfil hereda el
entorno del orquestador y queda limitado por sus instrucciones.

El instalador copia sólo los cuatro archivos generados a la plataforma elegida.
Los nombres están reservados con prefijo `escala-`; se reemplazan de manera
atómica por archivo y nunca se enumeran como comandos del skill público.

## Componentes

| Componente | Cambio |
|---|---|
| `validators/specialist_agents.py` | compilar y validar contrato/proyecciones |
| `scripts/build_specialist_agents.py` | generar o comprobar artefactos versionados |
| `adapters/specialists/contract.json` | manifiesto común de cuatro perfiles |
| `adapters/codex/agents/` | cuatro definiciones TOML generadas |
| `adapters/claude/agents/` | cuatro definiciones Markdown generadas |
| `install.sh` | instalar las definiciones de la plataforma seleccionada |
| `tests/test_s67_5_specialist_agents.py` | contrato, drift e instalación segura |

## Límites y riesgos

Las definiciones no sustituyen la validación empresarial E45, ni deciden por
el dueño. People requiere consentimiento explícito; Cash no acepta cifras sin
periodo/unidad; Strategy marca investigación externa sin fuente/fecha; y
Execution no califica individuos. La prueba simula ambas instalaciones sin
tocar configuraciones reales.

Codex admite agentes de proyecto en `.codex/agents/` como TOML; esta entrega
usa los tres campos requeridos (`name`, `description` y
`developer_instructions`) y no añade opciones de plataforma no necesarias.
