# S67.3 — Adaptador Claude

Como empresario que instala ESCALA en Claude Code, quiero encontrar una única
puerta pública (`escala`) para que la experiencia sea simple sin duplicar la
metodología ni activar conexiones externas.

## Criterios de aceptación

```gherkin
Scenario: Instalación limpia de Claude
  Given un bundle portable validado
  When se instala para Claude
  Then sólo aparece la puerta pública escala
  And las capacidades internas no se publican como comandos

Scenario: Límite de plataforma explícito
  Given el adaptador específico de Claude
  When se inspecciona junto al core portable
  Then conserva el mismo catálogo y rutas MVP
  And contiene sólo instrucciones de instalación y extensiones de Claude
  And no instala MCPs, conectores ni credenciales por defecto

Scenario: Alias de compatibilidad
  Given una referencia a un alias histórico
  When Claude recibe la referencia
  Then la redirige al contrato canónico de escala
  And no contiene otra implementación metodológica
```
