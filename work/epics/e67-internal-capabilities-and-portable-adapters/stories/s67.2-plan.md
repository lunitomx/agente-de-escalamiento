# Plan S67.2 — Adaptador Codex

## Secuencia

1. **Rojo — contrato de adaptador.** Añadir pruebas que definan el output
   limpio, una sola puerta pública, paridad con E67, ausencia de MCP/
   credenciales/global y fallos sin publicación parcial.
2. **Verde — generador mínimo.** Implementar el constructor con Python
   estándar en `adapters/codex`, validando el catálogo canónico antes de crear
   un directorio temporal dentro del root autorizado.
3. **Endurecimiento.** Validar paths y contenido de salida; publicar sólo con
   `rename` tras crear y verificar todos los artefactos.
4. **Documentar.** Registrar diseño y plan bajo S67.2 sin modificar el scope
   de E67, que se actualiza al cierre/merge.
5. **Verificar.** Ejecutar pytest focalizado, Ruff, formato y Pyright usando
   el entorno existente; revisar que no haya protocolos ni tests huérfanos.
