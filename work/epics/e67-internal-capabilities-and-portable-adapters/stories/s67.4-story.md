# S67.4 — Paridad y migración de adaptadores

Como empresario que puede instalar ESCALA en Codex o Claude, quiero recibir la
misma puerta y las mismas seis capacidades internas para continuar mi trabajo
sin tener que entender diferencias de plataforma ni rutas históricas.

## Criterios de aceptación

```gherkin
Scenario: Núcleo portable equivalente
  Given el catálogo MVP autorizado
  When se inspeccionan los adaptadores Codex y Claude
  Then ambos resuelven al mismo catálogo, skill público y seis contratos
  And cada contrato conserva intención, procedimiento, evidencia, especialista y lifecycle

Scenario: Instalación nueva
  Given una instalación limpia por plataforma
  When se listan los skills visibles al empresario
  Then sólo aparece escala
  And ningún alias scaleup-* se publica como comando

Scenario: Migración compatible y explícita
  Given un alias histórico existente
  When se revisa la capa de migración
  Then sólo redirige al contrato canónico
  And el reporte explica que el router YAML histórico no es el núcleo MVP JSON
```
