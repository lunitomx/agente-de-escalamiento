# S67.5 — Paquete de especialistas internos

Como empresario que conversa con ESCALA, quiero que el orquestador pueda pedir
una revisión acotada al especialista correcto sin que tenga que aprender
comandos, elegir perfiles técnicos ni crear configuraciones externas.

## Criterios de aceptación

```gherkin
Scenario: Cuatro especialistas proyectados desde un contrato
  Given los contratos privados E45
  When se construyen los adaptadores Codex y Claude
  Then se generan Cash, Execution, People y Strategy en ambas plataformas
  And cada definición contiene el mismo trigger, límites y resultado base

Scenario: Instalación segura
  Given una configuración de agente ajena del usuario
  When ESCALA se instala en una plataforma seleccionada
  Then instala sólo sus cuatro definiciones internas bajo el directorio de agentes
  And conserva el archivo ajeno sin modificarlo

Scenario: Frontera empresarial
  Given los archivos generados
  When se inspecciona la superficie visible de ESCALA
  Then escala sigue siendo la única puerta pública
  And ningún especialista enumera o ejecuta instrucciones de otra decisión
```
