# S67.2 — Adaptador Codex

## User story

Como empresario que instala ESCALA en Codex, quiero una instalación local
limpia que exponga únicamente `escala`, para entrar por una sola puerta sin
tener que aprender el catálogo interno de capacidades.

## Acceptance criteria

```gherkin
Scenario: instalación limpia de Codex
  Given un directorio de destino vacío y un core E67 válido
  When genero el adaptador Codex
  Then se instala exactamente un skill público llamado "escala"
  And su capacidad declarada coincide con el catálogo canónico E67
  And no se instalan MCPs, credenciales ni configuraciones globales

Scenario: separación de plataforma y núcleo
  Given el paquete generado
  When reviso sus artefactos core y específicos de Codex
  Then el core no contiene rutas, comandos o instrucciones exclusivas de Codex
  And el adaptador no redefine la metodología ni la lógica de enrutamiento

Scenario: límite seguro
  Given que falta el catálogo, está malformado o cambia una capacidad
  When intento generar el adaptador
  Then la generación falla de forma explícita
  And no deja una instalación parcial en el destino
```

## Examples

| Entrada | Resultado esperado |
|---|---|
| Catálogo MVP válido | Un único `skills/escala/SKILL.md` público y manifiesto local seguro. |
| Alias interno o capacidad desconocida | Fallo validado; no se transforma en puerta pública. |
| Destino fuera de raíz / preexistente | Rechazo sin escribir ni sobreescribir datos. |
