# S67.6 — Compatibilidad Agent Plugins v1

## User story

Como empresario que instala ESCALA desde un cliente compatible, quiero un paquete portable de estándar abierto para conservar una sola puerta pública y evitar configurar manualmente un catálogo de agentes o conectores.

## Acceptance scenarios

```gherkin
Scenario: paquete portable mínimo
  Given el core aprobado de ESCALA
  When se genera el paquete Agent Plugins
  Then contiene un único plugin.json v1 y skills/escala/SKILL.md
  And no incluye MCP, secretos, datos de empresa ni un segundo skill público

Scenario: manifest inválido o ruta escapada
  Given una selección con campo desconocido o referencia fuera de la raíz
  When se valida o construye el paquete
  Then falla con un motivo estable
  And no produce un paquete parcial

Scenario: handoff de evaluación
  Given un paquete válido
  When E68 ejecuta sus fixtures
  Then puede identificar la capacidad portable y sus límites
  And la equivalencia semántica de modelo sigue siendo una responsabilidad de E68
```
