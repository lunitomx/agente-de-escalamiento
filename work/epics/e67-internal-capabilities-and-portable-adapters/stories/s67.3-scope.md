# Scope S67.3 — Adaptador Claude

## In Scope

- Adaptador mínimo de Claude en `adapters/claude/` que apunte al único skill
  portable público `escala`.
- Instrucciones Claude-specific aisladas del core, incluyendo límites claros de
  extensiones, datos locales y autorización.
- Instalación verificable que no publique procedimientos/capacidades internas,
  no configure MCPs y no cree ni lea credenciales.
- Pruebas estáticas de contrato y de instalación limpia de Claude.

## Out of Scope

- Cambiar la metodología, catálogo, procedimientos E65 o el core portable.
- Crear comandos públicos, subagentes, MCPs, conectores o automatizaciones.
- Prometer paridad de modelos: S67.4 y E68 la prueban y reportan.

## Done When

- `adapters/claude/` es un empaquetado mínimo, no una segunda implementación.
- El artefacto declara una sola puerta pública (`escala`) y el core como fuente
  semántica.
- Las pruebas demuestran ausencia de rutas públicas extra, MCP y credenciales,
  además de que el adaptador no aloja contenido metodológico.
