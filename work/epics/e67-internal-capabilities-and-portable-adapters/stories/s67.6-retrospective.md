# Retrospectiva S67.6 — Compatibilidad Agent Plugins v1

## Resultado

ESCALA tiene un constructor local de Agent Plugins v1 con una única puerta
pública, `escala`. El paquete contiene sólo `plugin.json`, el `SKILL.md` y la
proyección autocontenida del catálogo MVP; no instala nada, ni exporta datos de
empresa, subagentes privados, MCP, OAuth, conectores, credenciales o memoria.

## Decisiones

- El formato abierto se usa como paquete adicional, no como sustituto de los
  adaptadores Codex/Claude ya existentes.
- El catálogo canónico se copia byte a byte y se valida contra la autoridad;
  una desviación falla antes de aceptar el paquete.
- E68 puede usar `build_agent_plugin` y `load_agent_plugin` como fixture
  técnico. La equivalencia semántica y compatibilidad real de modelos no se
  declaran aquí.

## Aprendizaje

La revisión adversarial mostró que validar sólo archivos deja una superficie
vacía no autorizada. El contrato de un paquete debe validar también directorios
para que “sin MCP” signifique ausencia real de la ruta, incluso vacía.

## Seguimiento

El único pendiente técnico ajeno es la higiene global de formato heredada de
S67.5, documentada en `s67.6-qr.md`. No bloquea las pruebas, lint ni tipos de
esta historia, pero sí impide afirmar que el gate global de formato está verde.
