# Scope S67.2 — Adaptador Codex

## In Scope

- Generar un adaptador local de Codex desde el capability map E67 aprobado.
- Declarar una única puerta pública, `escala`, y su contrato semántico
  verificable con las seis capacidades MVP.
- Separar el core portable de instrucciones específicas de Codex.
- Validar que la salida no contiene MCP, secretos, credenciales, comandos de
  instalación global ni una segunda implementación metodológica.
- Pruebas de generación limpia, paridad de capability map y fallos sin
  escrituras parciales.

## Out of Scope

- Instalar en `~/.agents`, `~/.codex` o cualquier configuración global.
- Crear o configurar MCPs, conectores, credenciales o servicios remotos.
- Publicar los procedimientos o perfiles internos como comandos del empresario.
- Construir el adaptador Claude, la matriz interplataforma o el paquete
  Agent Plugins.

## Done when

- Un generador reproducible construye un destino de adaptador Codex vacío con
  exactamente una puerta pública `escala`.
- El manifest y el skill generado representan exactamente las seis
  capacidades aprobadas del catálogo E67 y no contienen lógica de rutas.
- El core portable no incluye vocabulario específico de Codex; los detalles
  de cliente permanecen en `adapters/codex`.
- La validación automatizada demuestra que las entradas inválidas y los
  destinos inseguros no producen una instalación parcial ni tocan datos.
