# Story: Knowledge API — Consultar el Grafo del Libro

## User Story
As a coach using Escala,
I want to search the book's knowledge from any dashboard or skill,
so that I can get context and theory behind every tool and metric.

## Acceptance Criteria
- [ ] GET /api/knowledge/search?q=cash returns entities matching "cash"
- [ ] GET /api/knowledge/entity/power-of-one returns entity with relationships
- [ ] GET /api/knowledge/context?tool=power-of-one returns relevant context
- [ ] All endpoints return JSON with status ok
