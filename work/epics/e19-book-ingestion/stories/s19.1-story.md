# Story: Book Parser — Extract Structure from Scaling Up

## User Story
As the Escala system,
I want to parse `scaling_up_llamaparse.md` into structured JSON entities,
so that the knowledge graph can be populated with the book's concepts, tools, metrics, habits, and principles.

## Acceptance Criteria

### Scenario: Parse chapters
```gherkin
Given the source file scaling_up_llamaparse.md
When the parser runs
Then it extracts all 276 headings into a chapter/section tree
And each chapter has a name, line range, and depth level
```

### Scenario: Extract concepts
```gherkin
Given the parsed book structure
When the parser identifies key concepts
Then it extracts entities like "Power of One", "Rockefeller Habits", "Cash Conversion Cycle"
And each entity includes: name, type (concept/tool/metric/habit/principle), description, source line refs
```

### Scenario: Output format
```gherkin
Given the parser completes
When I check the output
Then it is valid JSON with "chapters", "entities", "relationships" arrays
And the JSON can be ingested by S19.2
```

## Notes
- Source: scaling_up_llamaparse.md (9,380 lines, 653KB)
- Output: JSON file at escala_server/data/book-knowledge.json
- Must extract minimum 30 entities and 50 relationships
- The parser should be rerunnable (idempotent)
