# Scope: S19.1 — Book Parser

## In Scope
- Read `scaling_up_llamaparse.md` from project root
- Extract chapter/section tree from headings (276 total)
- Extract entities: concepts (Power of One, CCC, etc.), tools (FACe, PACe, etc.), metrics (Rev/Employee, NPS, etc.), habits (Daily Huddle, etc.), principles
- For each entity: name, type, description, source keywords, line references
- Extract relationships between entities (contains, is_tool_for, measures, etc.)
- Output: JSON file at `escala_server/data/book-knowledge.json`
- Output must have: chapters[], entities[], relationships[]

- API endpoints (S19.4)
- Tests of ingestion (S19.5)
