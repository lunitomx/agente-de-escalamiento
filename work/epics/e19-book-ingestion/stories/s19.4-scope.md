# Scope: S19.4 — Knowledge API

## In Scope
- GET /api/knowledge/search?q=term — search entities by name/keywords/type
- GET /api/knowledge/entity/{name} — entity details with relationships
- GET /api/knowledge/context?tool=X&category=Y — relevant context for a tool
- Tests for all endpoints

## Out of Scope
- Dashboard UI integration (E20)
- Verne agent (E21)

## Done When
- [ ] Search endpoint returns matching entities
- [ ] Entity endpoint returns entity + relationships
- [ ] Context endpoint returns relevant entities grouped by relevance
- [ ] Tests pass
