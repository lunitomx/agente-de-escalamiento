# Story: Knowledge Context API

## User Story
As un dashboard de Escala,
I want un endpoint que consulte el grafo de conocimiento de E19 y devuelva contexto relevante del libro Scaling Up,
so that cada módulo (Cash, Strategy, People, Execution) pueda mostrar principios, frameworks y métricas asociadas a sus herramientas.

## Acceptance Criteria

### Scenario: consulta por tool específica
```gherkin
Given el grafo de E19 tiene entidades pobladas con datos del libro Scaling Up
When GET /api/knowledge/context?tool=power-of-one
Then retorna un JSON con:
  - tool: "power-of-one"
  - category: "cash"
  - entities: lista de entidades relacionadas (nombre, tipo, propiedades)
  - relationships: lista de relaciones entre entidades
  - facts: citas textuales y definiciones relevantes
  - principles: principios asociados a la herramienta
```

### Scenario: consulta por categoría
```gherkin
Given el grafo tiene datos categorizados
When GET /api/knowledge/context?category=cash
Then retorna todas las herramientas, principios y métricas de la categoría cash
```

### Scenario: tool inexistente
```gherkin
Given el grafo no tiene datos para el tool solicitado
When GET /api/knowledge/context?tool=inexistente
Then retorna 200 con un objeto vacío {entities: [], relationships: [], facts: []}
```

### Scenario: sin parámetros
```gherkin
When GET /api/knowledge/context (sin parámetros)
Then retorna 400 Bad Request indicando que se requiere "tool" o "category"
```

## Examples (Specification by Example)

| Input | Action | Expected Output |
|-------|--------|-----------------|
| ?tool=cash-conversion-cycle | GET /api/knowledge/context | tool + category + entities + relationships + facts |
| ?category=strategy | GET /api/knowledge/context | Todas las herramientas de estrategia |
| ?tool=inexistente | GET /api/knowledge/context | {entities:[], relationships:[], facts:[]} |
| (sin params) | GET /api/knowledge/context | 400 error |

## Notes

- El endpoint se agrega a server.py existente (E18)
- El grafo de E19 debe estar accesible como módulo importable
- Formato de respuesta: JSON estándar
