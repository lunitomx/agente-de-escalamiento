# Story: Dashboard Context Panel

## User Story
As un usuario de los dashboards de Escala,
I want ver un panel lateral con contexto del libro Scaling Up relevante a la herramienta que estoy viendo,
so that pueda entender los principios, métricas y frameworks del libro sin salir del dashboard.

## Acceptance Criteria

### Scenario: panel visible en dashboard Cash
```gherkin
Given estoy en /dashboards/cash/power-of-one.html
When la página carga
Then veo un panel lateral "Contexto de Scaling Up" con principios y métricas de la categoría cash
```

### Scenario: panel visible en dashboard Strategy
```gherkin
Given estoy en /dashboards/strategy/bmc-board.html
When la página carga
Then el panel muestra contexto de estrategia

### Scenario: panel colapsable
```gherkin
Given el panel está visible
When hago clic en el botón de colapsar
Then el panel se oculta y el dashboard ocupa todo el ancho
```

### Scenario: datos desde API
```gherkin
Given el panel se inicializa
When fetch GET /api/knowledge/context?category={categoria_detectada}
Then muestra principios, frameworks y métricas de la categoría
```

## Notes

- La categoría se detecta automáticamente desde la URL del dashboard (/dashboards/{categoria}/)
- Los dashboards existentes no se modifican estructuralmente — solo se agregan includes
- Diseño responsivo: en mobile el panel se colapsa por defecto
