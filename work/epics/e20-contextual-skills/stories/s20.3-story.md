# Story: Coaching Skill Helper

## User Story
As un skill de coaching de Escala,
I want poder llamar `get_scaling_context(category)` desde Python,
so that pueda mostrar principios, frameworks y métricas del libro Scaling Up durante las sesiones de coaching.

## Acceptance Criteria

### Scenario: helper importable
```gherkin
Given el módulo escala_server.scaling_context existe
When import get_scaling_context
Then la función está disponible
```

### Scenario: retorna contexto por categoría
```gherkin
Given la función recibe category="cash"
When se ejecuta get_scaling_context(category="cash")
Then retorna un dict con principles, habits, entities relevantes a cash
```

### Scenario: sin argumentos retorna error
```gherkin
When get_scaling_context() sin argumentos
Then retorna {"status": "error", "message": "..."}
```
