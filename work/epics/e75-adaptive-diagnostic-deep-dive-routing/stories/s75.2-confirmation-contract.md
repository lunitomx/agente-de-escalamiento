# S75.2 — Confirmación de comprensión empresarial

## Objetivo

Convertir el resumen inicial en una comprensión que la persona pueda confirmar
u objetar por campo: industria, oferta, cliente objetivo, modelo de negocio y
reto principal. Ningún campo omitido se interpreta como vacío o cero: queda
marcado como `unknown` y genera una pregunta posterior.

## Contrato

`CompanyUnderstanding` exige que cada campo sea conocido o aparezca exactamente
una vez en `unknown_fields`. Un assessment persiste sólo tras estado
`confirmed` o `corrected` y autorización explícita. La versión aprobada queda
como `narrative_assessment`; el historial local conserva cada revisión en
`narrative_assessments`.

## Criterios de aceptación

- Falta silenciosa de campo empresarial: rechazo fail-closed.
- Campo conocido y marcado unknown: rechazo fail-closed.
- Campo desconocido: se representa visiblemente en Markdown, no como score.
- Corrección autorizada conserva la versión actual y el historial local.
- Progreso, exportación y router consumen el assessment confirmado sin exigir
  scores; si existen scores heredados, se muestran sólo como señal secundaria.
- No se envían datos ni se crea memoria sin consentimiento.
