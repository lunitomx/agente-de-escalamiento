# S32.1 — Closure Evidence Repair

## Goal

Repair the suspicious epic closure records identified by the false-close audit without implementing old product features.

## Acceptance Criteria

- [x] A closure governance validator exists and is covered by tests.
- [x] The validator catches complete epics with open Done Criteria unless explicitly marked partial, absorbed, descoped, legacy, or backlog.
- [x] E11 scope agrees with retrospective evidence.
- [x] E19, E23, and E24 no longer claim unqualified completion while their Done Criteria remain open.
- [x] E22 is represented as absorbed/descoped instead of complete.
- [x] E10 historical milestones are separated from closure Done Criteria.
- [x] E29 has closure retrospective evidence and E30/E31 are referenced correctly.
- [x] A truth matrix records evidence, contradictions, corrected status, follow-up, and tag action.
