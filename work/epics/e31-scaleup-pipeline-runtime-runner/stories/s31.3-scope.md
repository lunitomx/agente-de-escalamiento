# S31.3 Scope — Integration Review

## In Scope

- Add an integration-style test over every canonical ScaleUp pipeline.
- Confirm the runner remains a lightweight guided evidence recorder.
- Document pattern candidates and limitations for future runtime work.

## Out of Scope

- Adding automated skill execution.
- Building a scheduler, daemon, or generic workflow engine.
- Changing the `.raise/pipelines/scaleup.yaml` contract.

## Done Criteria

- [ ] Integration test covers all registry pipelines.
- [ ] Focused pipeline runner tests pass.
- [ ] Full suite and technical gates pass.
- [ ] Retrospective documents closure readiness.
