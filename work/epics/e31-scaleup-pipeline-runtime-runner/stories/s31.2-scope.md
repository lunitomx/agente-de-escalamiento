# S31.2 Scope: Evidence and Resume Hardening

## In Scope
- Load and validate an existing guided pipeline run evidence file.
- Expose a small inspect/resume API in `validators.pipeline_runner`.
- Preserve deterministic append-only event history for resume actions.
- Add tests for inspect, resume, corrupt evidence, and evidence preservation.

## Out of Scope
- Background execution, scheduling, or async orchestration.
- Database storage for pipeline runs.
- Remote synchronization of evidence artifacts.
- Automatic execution of skill phases.

## Done When
- Existing run evidence can be loaded by path or run id.
- Resume identifies the next incomplete phase or terminal status.
- Invalid/corrupt evidence fails with an explicit validation error.
- Tests cover happy path, interruption/resume, corrupt input, and append-only behavior.
- S31.1 behavior remains compatible.
