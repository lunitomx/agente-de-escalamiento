# Story Retrospective: S18.2 — Pattern extraction from transcript and prompts

**Date:** 2026-06-02
**Size:** M
**Commits:** 2 (init + implement)

## What We Built

A Python module `coaching/pattern_extraction.py` that:

- `Pattern` dataclass with type, label, evidence, occurrences, confidence
- `extract_patterns(bundle)` — reads transcript, returns patterns
- `save_patterns(bundle, patterns)` / `load_patterns(bundle)` — JSON persistence
- Theme extraction: n-gram frequency (bigram + trigram) with stopword awareness
- Decision extraction: keyword matching ("compromiso", "acordamos", etc.)
- Commitment extraction: regex patterns ("voy a", "me comprometo", etc.)
