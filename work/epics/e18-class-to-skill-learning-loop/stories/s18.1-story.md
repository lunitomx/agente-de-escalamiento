## User Story

As a member of the Escala coaching team,
I want to bundle a class transcript, audio, and lesson artifacts into a structured, traceable package
so that downstream extraction pipelines can consume a predictable input without guessing paths or formats.

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Create a bundle from transcript path
  Given a class transcript exists at a known path
  And a class title and date are provided
  When I call ingest_class()
  Then a valid ClassBundle is returned
  And a YAML file is persisted under work/classes/{class_id}/bundle.yaml

Scenario: Bundle contains all metadata
  Given a bundle was created with full metadata
  Then it contains class_id, title, date, transcript_path
  And artifact_paths (optional) exist if provided
  And provenances points to the source

Scenario: Missing transcript is rejected
  Given a transcript path that does not exist on disk
  When I call ingest_class()
  Then an error is raised with a clear message
  And no bundle file is created

Scenario: CLI ingest produces identical output
  Given the same transcript, title, and date
  When I run `python -m escala-skills.class_intake ingest --transcript ... --title ...`
  Then the resulting bundle.yaml is identical to one created via the Python API
```

### Example (SbE)

```python
from escala_skills.class_intake import ingest_class

bundle = ingest_class(
    transcript_path="work/referencias/bbb-19d465e7/transcript/audio-16k-mono.txt",
    title="ELN Sesión 2 — Estrategia I",
    date="2026-05-26",
    source_type="bbb",
)
# bundle.class_id == "260526-eln-sesion2"
# File written to work/classes/260526-eln-sesion2/bundle.yaml
```
