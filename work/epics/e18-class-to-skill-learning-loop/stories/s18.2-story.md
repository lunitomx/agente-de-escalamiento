## User Story

As a member of the Escala coaching team,
I want a module that reads a ClassBundle (transcript + prompts) and extracts patterns, decisions, commitments, and contradictions
so that downstream skill suggestions (S18.3) can be grounded in real evidence from the class.

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Extract patterns from a transcript
  Given a ClassBundle exists with a transcript path
  When I call extract_patterns(bundle)
  Then I get a list of extracted patterns
  And each pattern has a type (theme, decision, commitment, contradiction)
  And each pattern has evidence (quote from transcript)

Scenario: Bundle without transcript raises error
  Given a ClassBundle with no transcript_path
  When I call extract_patterns()
  Then an error is raised

Scenario: Repeated themes are detected
  Given a transcript with 3+ occurrences of "a quién sí"
  When I call extract_patterns()
  Then "a quién sí" appears as a repeated theme pattern

Scenario: Save and load patterns
  Given a list of extracted patterns
  When I call save_patterns(bundle, patterns)
  Then patterns.json is saved alongside bundle.yaml
  And load_patterns(bundle) returns the same patterns
```

### Example (SbE)

```python
from coaching.class_intake import load_bundle
from coaching.pattern_extraction import extract_patterns, Pattern

bundle = load_bundle("260526-eln-sesion2")
patterns = extract_patterns(bundle)
# patterns[0].type == "theme"
# patterns[0].label == "a quién sí"
# patterns[0].evidence == "hay que usar 'a quién sí' como filtro estratégico"
# patterns[0].occurrences == 3
```
