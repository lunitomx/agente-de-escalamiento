## In Scope

- `SkillDelta` dataclass: target_skill, suggestion_type, description, evidence, priority
- `load_skills_inventory()` — reads Escala skill names from `escala-skills/` directory
- `suggest_deltas(patterns, skills)` — maps patterns to skill deltas
- Mapping rules: keyword matching (pattern label → skill name), theme→skill mapping config
- `save_deltas(bundle, deltas)` / `load_deltas(bundle)` — JSON persistence
- Tests

## Out of Scope

- Auto-editing skill files (AC: no skill files modified)
- LLM-based suggestion generation (rules-based heuristics)
- Scoring or ranking of suggestions beyond basic priority

- [ ] load_skills_inventory() returns skill names from escala-skills/
- [ ] suggest_deltas() returns list of SkillDelta mapped from patterns
- [ ] Each delta references a real target_skill
- [ ] save/load round-trip works
