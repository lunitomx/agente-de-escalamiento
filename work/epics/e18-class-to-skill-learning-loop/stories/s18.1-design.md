# Story Design: S18.1 — Class intake + source bundling

## Problem

Hoy, cada clase deja un transcript, prompts y materiales sueltos sin una estructura común. El transcript de la última clase ELN quedó en `work/referencias/bbb-19d465e7/transcript/audio-16k-mono.txt`, el audio en `work/referencias/bbb-19d465e7/`, y los prompts de clase en una carpeta externa. No hay un formato predecible que amarre todos los artefactos de una clase en un solo paquete con metadatos, proveniencia y trazabilidad. Sin esto, S18.2 (pattern extraction) no puede empezar porque no sabe dónde está el input ni en qué formato llega.

## Value

Un bundle de clase reproducible permite que cualquier clase nueva produzca un paquete autónomo con trazabilidad clara. Las siguientes historias (S18.2, S18.3, S18.4) pueden leer este bundle sin adivinar rutas ni formatos. Con el primer bundle creado, la pipeline se vuelve repetible: cada clase → bundle → extracción → sugerencias → reporte.

## Approach

Crear un módulo Python `escala-skills/class_intake.py` que:

1. Defina un dataclass `ClassBundle` como contrato de datos
2. Acepte como entrada una de estas fuentes:
   - Path local a un transcript existente + metadatos opcionales
   - URL de grabación BBB + metadata (descarga delegada a herramientas existentes)
   - Path a carpeta con materiales de clase
3. Produzca un bundle estructurado como JSON con:
   - `class_id`: identificador único generado
   - `title`, `date`, `source_type`: metadatos
   - `transcript_path`: path al archivo de transcript
   - `audio_path`: path al audio original (si existe)
   - `artifact_paths[]`: paths a materiales complementarios (prompts, markdowns)
   - `provenance`: contexto de origen (URL de grabación, archivos fuente)
4. Persista el bundle como un archivo YAML + JSON en `work/classes/{class_id}/bundle.yaml`
5. Incluya un helper CLI mínimo con `argparse` para crear bundles sin código

### Components Affected

| Component | Change | Purpose |
|-----------|--------|---------|
| `escala-skills/class_intake.py` | Create | Bundle dataclass, ingestion logic, persistence |
| `escala-skills/__init__.py` | Modify | Export ClassBundle, ingest_class |
| `work/classes/` | Create (dir) | Predictable bundle storage |
| `tests/test_class_intake.py` | Create | Tests for bundle creation, loading, edge cases |

### Design Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| DD1 | Dataclass nativo + JSON/YAML | Cero dependencias externas. YAML legible por humanos, JSON consumible por S18.2 |
| DD2 | Bundle por carpeta, no DB | Simplicidad máxima. Cada clase es su propia carpeta. S18.3+ puede indexar carpetas |
| DD3 | `class_id` con formato `YYMMDD-slug` | Trazabilidad natural, orden cronológico, legible sin herramientas |
| DD4 | No download automático de BBB | Delegado al skill `bigbluebutton-whisper-local`. S18.1 solo recibe el resultado |
| DD5 | CLI mínimo con argparse | No necesita typer/click para 2-3 subcomandos |

### Legacy Sweep

Nada — esto es net-new. No hay V1 que orfanar.

### Drift Risk Check

No se identifican riesgos de drift. El módulo es nuevo y no toca código existente.

### Storage Migration Gate (N/A)

S18.1 no reemplaza almacenamiento — crea uno nuevo.

## Examples

### CLI Usage

```bash
# From a local transcript file
python -m escala-skills.class_intake ingest \
  --transcript work/referencias/bbb-19d465e7/transcript/audio-16k-mono.txt \
  --title "ELN Sesión 2 — Estrategia I" \
  --date 2026-05-26 \
  --source-type bbb \
  --source-url "https://blue.aprenbiz.com/playback/presentation/2.3/19d465e7..." \
  --artifact "lanzamientoahuehuete2026/prompt-canvas-v4-premium.txt" \
  --artifact "Sesion-02-Prompt-0-EstrategiaEnUnaFrase.md"

# Output
# ✓ Bundle created: work/classes/260526-eln-sesion2/bundle.yaml
```

### Python Usage

```python
from escala_skills.class_intake import ingest_class, ClassBundle

bundle = ingest_class(
    transcript_path="work/referencias/bbb-19d465e7/transcript/audio-16k-mono.txt",
    title="ELN Sesión 2 — Estrategia I",
    date="2026-05-26",
    source_type="bbb",
    source_url="https://blue.aprenbiz.com/...",
    artifact_paths=[
        "lanzamientoahuehuete2026/prompt-canvas-v4-premium.txt",
    ]
)
# bundle.class_id → "260526-eln-sesion2"
# bundle.transcript_path → absolute path to transcript
# bundle.artifact_paths → [absolute path, ...]
```

## Acceptance Criteria

### MUST
- [ ] `ingest_class()` acepta transcript_path + title y produce un bundle válido
- [ ] El bundle generado contiene class_id, title, date, transcript_path, artifact_paths
- [ ] `class_id` se genera automáticamente con formato `YYMMDD-slug`
- [ ] Se rechaza con error si el transcript_path no existe en disco
- [ ] El bundle se persiste como YAML en `work/classes/{class_id}/bundle.yaml`
- [ ] CLI `ingest` command funciona con arg decode
- [ ] CLI `load` command imprime resumen del bundle
- [ ] artifact_paths se convierten a rutas absolutas al persistir

### SHOULD
- [ ] El bundle acepta audio_path opcional
- [ ] `source_url` opcional queda como None en el YAML si no se pasa
- [ ] Mensaje de confirmación con ruta absoluta del bundle creado

### MUST NOT
- [ ] No modificar archivos de transcript o audio originales
- [ ] No depender de APIs externas o servicios de red
- [ ] No fallar si los artifact_paths son opcionales
