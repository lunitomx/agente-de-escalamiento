## In Scope

- `Pattern` dataclass: type, label, evidence, occurrences, confidence
- `extract_patterns(bundle)` function that reads transcript and returns list of Pattern
- Pattern types: theme (topic repetition), decision (explicit commitment), contradiction (prompt mismatch)
- Basic text repetition detection (N-gram frequency)
- `save_patterns(bundle, patterns)` → `work/classes/{class_id}/patterns.json`
- `load_patterns(bundle)` → list of Pattern
- Tests: 10+ test cases

## Out of Scope

- Machine learning or LLM-based extraction (simple heuristics first)
- Skill-specific mapping (S18.3)
- Report generation (S18.4)
- UI

## Done When

- [ ] extract_patterns() returns list of Pattern from bundle transcript
- [ ] Pattern types: theme, decision, commitment, contradiction
- [ ] Repeated themes detected via N-gram frequency
- [ ] Patterns persistable to/from JSON alongside bundle
- [ ] All tests pass
