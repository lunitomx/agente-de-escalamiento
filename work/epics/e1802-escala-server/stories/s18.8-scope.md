# Scope: S18.8 — SQLite Database Layer & Schema

## In Scope
- SQLite schema completo (escala.db):
  - companies: id, name, industry, metadata, created_at, updated_at
  - worksheets: id, company_id, category, tool, data (JSON), version, session_id, created_at, updated_at
  - sessions: id, company_id, summary, data (JSON diffs), started_at, closed_at
  - changes_log: id, company_id, session_id, category, tool, field, old_value, new_value, diff_type, created_at
  - memory_facts: id, company_id, content, category, tags, trust_score, source, created_at
  - entities: id, company_id, name, type, metadata, created_at
  - relationships: id, company_id, source_entity, target_entity, relationship_type, weight, created_at
- DAO layer Python (repositorios por dominio)
- Change tracking automático (versión de datos por sesión)
- Funciones de diff (qué cambió entre dos versiones)
- Migración desde YAML existente a SQLite
- Integración con el server: reemplazar DAOs en memoria

## Out of Scope
- Memoria neurosimbólica y grafo (S18.9)
- escala-inicia / escala-cierra (S18.10-11)
- Integración con CRMs externos

## Done When
- [ ] `escala.db` se crea automáticamente con el schema completo
- [ ] Companies CRUD funciona via DAO con SQLite
- [ ] Worksheets CRUD funciona via DAO con SQLite
- [ ] Sessions CRUD funciona via DAO con SQLite
- [ ] Changes_log registra automáticamente cada modificación a worksheets
- [ ] Migración YAML → SQLite funcional
- [ ] Server usa SQLite DAOs en lugar de DAOs en memoria
- [ ] Tests unitarios para cada DAO
- [ ] Todas las tablas tienen índices apropiados
