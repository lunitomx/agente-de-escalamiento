# Story: Navigation & Home

## User Story
As a coach using Escala,
I want a home page with 4 clickable cards for each business decision,
so that I can navigate to the right dashboard quickly and always know where I am.

## Acceptance Criteria

### Scenario: Home shows 4 decision cards
```gherkin
Given the Escala server is running
When I open http://localhost:8080
Then I see 4 cards: Cash, Strategy, People, Execution
And each card shows a score and status
```

### Scenario: Click card navigates to tool list
```gherkin
Given I am on the home page
When I click the "Cash" card
Then I see a list of Cash tools (Power of One, Cash Board, Fundability, etc.)
And breadcrumbs show "Home > Cash"
```

### Scenario: Back to home via breadcrumbs
```gherkin
Given I am in a sub-navigation view
When I click "Home" in the breadcrumbs
Then I return to the main home page
```

## Notes
- Served from escala_server/static/index.html
- Responsive design matching dashboard-base.css
- Data from server API for scores and status
