# Story: Installation & Lifecycle

## User Story
As a user of Escala,
I want to install, configure, and run the complete system with a single setup,
so that I can start coaching immediately without manual configuration.

## Done Criteria
- [ ] `escala-server` CLI completo con start/stop/status/migrate
- [ ] `escala-inicia` y `escala-cierra` como scripts CLI
- [ ] Health check endpoint: GET /api/health
- [ ] Documentación de instalación y uso
- [ ] Migración YAML → SQLite funcional
