# Story: Power of One Interactive (PILOT)

## User Story
As a coach using Escala,
I want to adjust business levers with sliders and see the revenue impact instantly,
so that I can run rapid what-if scenarios and save the results.

## Acceptance Criteria

### Scenario: Dashboard loads saved data
```gherkin
Given the Escala server is running
And the Power of One dashboard has saved data
When I open the dashboard
Then the sliders are positioned at the saved values
And the impact is calculated correctly
```

### Scenario: Slider adjusts revenue
```gherkin
Given the Power of One dashboard is open
When I move the "Precio" slider from 3 to 5
Then the revenue impact recalculates immediately
And the change indicator shows "modificado"
```

### Scenario: Save persists data
```gherkin
Given I have adjusted the sliders
When I click "Guardar"
Then the data is sent to POST /api/worksheets/cash/power-of-one
And the change indicator shows "guardado"
```

## Notes
- Este es el PILOT que establece el patrón para S18.4-S18.7
- Usa el HTML existente de E14 como base
- Conexión al server S18.1 mediante fetch API
- Sin SQLite aún — la persistencia va al DAO en memoria del server
