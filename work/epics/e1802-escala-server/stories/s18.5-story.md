# Story: Strategy Suite Interactive

## User Story
As a coach using Escala,
I want interactive dashboards for all Strategy tools (BMC, Core Customer, Brand Promises, etc.),
so that I can adjust strategy levers and save changes via the API.

## Acceptance Criteria

### Scenario: Strategy dashboards are served
```gherkin
Given the Escala server is running
When I open /dashboards/strategy/bmc-board.html
Then the BMC canvas is displayed with editable sections
```

## Notes
- Pattern inherited from S18.3 (Power of One PILOT)
- Each dashboard follows the dashboard-interactive.js pattern
- Dashboards: BMC Board, Core Customer, Brand Promises, Diff Activities, Sandbox
