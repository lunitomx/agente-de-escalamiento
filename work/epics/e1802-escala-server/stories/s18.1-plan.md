# Plan: S18.1 — Server Core

## Tasks

### Task 1: Estructura del paquete
- Crear directorio `escala_server/`
- `__init__.py` con versión
- `scripts/escala-server` entry point

### Task 2: CLI wrapper
- `escala_server/cli.py` — argparse con start, stop, status
- Comando start: lanza server en proceso background, guarda PID
- Comando stop: mata proceso por PID file
- Comando status: verifica si PID corre

### Task 3: Servidor HTTP + Static Serving
- `escala_server/server.py` — extiende `http.server.HTTPServer`
- Request handler que sirve archivos estáticos desde root configurable
- Maneja GET a rutas no-API como archivos estáticos

### Task 4: API Router
- `escala_server/router.py` — registro de rutas por método + path pattern
- Dispatch: método + path → handler function
- Soporte para path parameters: `/api/worksheets/{category}/{tool}`

### Task 5: API Handlers
- `escala_server/handlers.py` — funciones handler para companies, worksheets, sessions
- DAO en memoria (dict) inicial
- JSON response format: `{"data": ..., "status": "ok"}`

### Task 6: CORS Middleware
- `escala_server/cors.py` — añade headers CORS a todas las respuestas
- Maneja OPTIONS preflight requests

### Task 7: Tests
- `tests/test_escala_server.py`
- Test CLI commands (unit test con mocking)
- Test API endpoints (integration test con server de prueba)
- Test static file serving
- Test CORS headers
- Test 404 handling

## Testing Strategy
| Layer | Tool | Scope |
|-------|------|-------|
| Unit | pytest | CLI commands, router dispatch, handler logic |
| Integration | pytest + http.server test client | Full request/response cycle |
| Smoke | Manual: `escala-server start` + curl | E2E verification |

## Dependencies
- Python 3.8+ (sqlite3 built-in for S18.8, no dep for S18.1)
- No external packages
