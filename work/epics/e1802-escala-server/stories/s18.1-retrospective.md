# Retrospective: S18.1 — Server Core

## Summary
Servidor HTTP local implementado con http.server nativo. API routing, static serving, CORS, y CLI start/stop/status. 10 tests unitarios, verificación E2E manual.

## What Went Well
- Diseño minimalista sin dependencias externas se mantuvo firme
- TDD funcionó: tests primero (RED), luego implementación (GREEN)
- Router con path parameters quedó limpio y extensible
- CLI start/stop/status con PID management funcionó al primer intento después del fix

## What Could Be Improved
- `__main__.py` con imports relativos falló al ejecutarse como script independiente — se corrigió usando `-m` en el CLI y añadiendo sys.path en `__main__.py`
- Python 3.9 del sistema vs 3.14 de brew — el `X | None` syntax no es compatible con 3.9

## Patterns Identified
- PAT-S18.1-001: Server local con http.server para herramientas de coaching
- PAT-S18.1-002: DAO abstracto en memoria como placeholder para SQLite posterior
- PAT-S18.1-003: CLI con argparse y PID file para server management básico
