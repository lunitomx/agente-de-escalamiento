## In Scope

- Endpoint GET /api/knowledge/context en server.py
- Consulta al grafo de conocimiento de E19 (entidades, relaciones, hechos)
- Parámetros: `tool` (herramienta específica) y `category` (categoría completa)
- Respuesta JSON con: tool, category, entities, relationships, facts, principles
- Manejo de tool inexistente (respuesta vacía, no error)
- Validación de parámetros (400 si falta tool y category)

## Out of Scope

- Modificar el grafo de E19 (es consulta-only)
- Panel de UI en dashboards (es S20.2)
- Helper para skills de coaching (es S20.3)
- Cacheo de respuestas
- Autenticación o autorización (usa la existente de server.py)
