# S26.3 — Cobertura en CI

**Epic:** E26 — Infraestructura de Calidad
**Size:** S (<1h)
**Status:** Draft
**Dependencies:** S26.1, S26.2

## Objetivo

Agregar medición de cobertura al pipeline de CI. Sin umbral mínimo — solo visibilidad por ahora.

## Archivos

- `.github/workflows/ci.yml` (modificar job `test`)
- `pyproject.toml` (agregar config de coverage)

## Cambios

En `ci.yml`, modificar el paso de pytest:
```yaml
- run: pytest --cov=escala_server --cov=coaching --cov-report=term-missing
```

En `pyproject.toml`:
```toml
[tool.coverage.run]
source = ["escala_server", "coaching"]
omit = ["*/tests/*", "*/__pycache__/*"]

[tool.coverage.report]
show_missing = true
skip_covered = false
```

## Criterios de Aceptación

- [ ] CI output muestra `TOTAL  XX%` al final del job `test`
- [ ] Coverage report muestra archivos con 0% y 100%
- [ ] No se bloquea el PR por cobertura baja (sin umbral)

## Notas

- No establecer `--cov-fail-under` todavía — primero visibilidad, después metas
- `term-missing` muestra líneas no cubiertas, útil para debugging
