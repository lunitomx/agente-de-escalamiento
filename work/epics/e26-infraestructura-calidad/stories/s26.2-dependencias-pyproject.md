# S26.2 — Dependencias en pyproject.toml

**Epic:** E26 — Infraestructura de Calidad
**Size:** S (<1h)
**Status:** Draft

## Objetivo

Declarar TODAS las dependencias reales del proyecto en `pyproject.toml`. Actualmente está vacío — ni siquiera pytest está listado.

## Archivos

- `pyproject.toml`

## Cambios

Agregar a `[project]`:
```toml
dependencies = [
    "pyyaml>=6.0",
]
```

Agregar sección:
```toml
[project.optional-dependencies]
dev = [
    "pytest>=8.0",
    "pytest-cov>=5.0",
    "ruff>=0.8",
]
```

## Criterios de Aceptación

- [ ] `pip install -e .` instala pyyaml
- [ ] `pip install -e ".[dev]"` instala pytest + ruff + pytest-cov
- [ ] `pytest` corre los 510 tests desde clone limpio
- [ ] Sin errores de import

## Notas

- No agregar `setuptools` ni `wheel` — son implícitos con `[build-system]`
- La versión mínima de Python ya está en `requires-python = ">=3.10"`
