# S26.1 — GitHub Actions CI

**Epic:** E26 — Infraestructura de Calidad
**Size:** S (<2h)
**Status:** Draft

## Objetivo

Crear `.github/workflows/ci.yml` que ejecute pytest + ruff en cada push a main y cada PR. Si los tests fallan o ruff encuentra errores, el PR no se puede mergear.

## Archivos

- `.github/workflows/ci.yml` (nuevo)

## Criterios de Aceptación

- [ ] CI se dispara en push a main y en PRs
- [ ] Job `test` ejecuta `pytest` y falla si tests fallan
- [ ] Job `lint` ejecuta `ruff check .` y falla si hay errores
- [ ] PR merge bloqueado si CI está en rojo

## Notas de Implementación

- Usar `actions/setup-python@v5` con Python 3.12
- Instalar con `pip install -e ".[dev]"`
- Ruff: `ruff check . --select E,F,I,N` (mínimo: errores + formatting)
- No agregar jobs de deploy ni staging — solo test + lint
