- **RED:** the focused gate failed during collection because no build-failure

- **GREEN:** the builder accepts only the full current commit, validates policy

- **REFACTOR:** every failure returns only a stable source-neutral rule ID; all

  validated before the destination is created.
- **Gates:** real temporary Git tests cover dirty/untracked worktrees, invalid
