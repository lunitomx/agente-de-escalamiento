## T2 Evidence

- Real temporary Git repositories distinguish an absent tracked worktree path,
  canonical `HEAD` presence, and history-only path presence.
- Authenticated remote values and secret-shaped file values are inspected only
  in memory; serialized findings contain a remote name or SHA-256 locator.
- Inherited `GIT_DIR`, `GIT_WORK_TREE`, and `GIT_CONFIG_*` variables are removed
  from every scanner subprocess environment.
- The public candidate scanner reads canonical `HEAD`, not dirty/untracked
  content; strong fingerprints prove both repositories unchanged.
- Missing repositories and fingerprint mismatches return typed, sanitized,
  incomplete receipts.
- Duplicate path/content matches collapse to one deterministic finding.

## T3 Evidence

  exit 1 and do not write partial receipts.

  dirty filenames, Git output, or exception text.
- Writers create only explicitly requested paths after a complete scan exists.
