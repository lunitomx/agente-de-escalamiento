# Diseño S68.4 — comparación semántica

`evaluate_cross_platform` usa el evaluador de activación para convertir cada
intent observado a un procedure ID. Después compara `action` y procedure ID,
no el texto crudo del intent. Eso mantiene los aliases autorizados como
equivalentes y deja visibles las diferencias reales.
