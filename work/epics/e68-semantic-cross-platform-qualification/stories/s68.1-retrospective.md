# Retrospectiva S68.1 — Suite de activación

## Resultado

E68 cuenta con un dataset sintético y un evaluador reproducible de activación.
Su reporte separa TP, FP, FN y TN para calcular precision/recall de routing,
y el CLI acepta observaciones externas versionables.

## Aprendizaje

La ruta incorrecta debe penalizar ambos lados de la clasificación: predijo una
ruta no solicitada y omitió la solicitada. El caso de prueba hizo visible la
diferencia entre seis procedimientos únicos y siete casos positivos al incluir
una secuencia; el umbral de 90% continúa siendo exigente (6/7 no alcanza).

## Handoff

S68.2 puede usar el mismo fixture y recibos para validar los entregables. S68.3
y S68.4 deben conservar la distinción entre observación técnica sintética y una
sesión real de modelo.
