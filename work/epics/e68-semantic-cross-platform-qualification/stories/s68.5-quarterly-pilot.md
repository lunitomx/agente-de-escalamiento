# S68.5 — Piloto trimestral

Una empresa autorizada completa el ciclo diagnóstico → prioridad → ejecución →
revisión. Cada artefacto recibe aprobación o corrección humana explícita; el
piloto nunca incorpora información identificable al repositorio.
