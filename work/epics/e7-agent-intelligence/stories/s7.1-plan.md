### T2: `/scaleup-start` sub-skills (4 SKILL.md files)

**Description:** Create the 4 sub-skill directories and SKILL.md files that
the `/scaleup-start` orchestrator will invoke as subagents:

1. `scaleup-start-load-profile/SKILL.md` — reads `company-profile.yaml`, extracts company name, stage, scores, focus. Halts if profile missing/empty.
2. `scaleup-start-load-sessions/SKILL.md` — reads `sessions/*.md`, sorts lexicographically, takes last 3, produces summary (date, focus, key outcomes). Returns empty summary if none exist.
3. `scaleup-start-load-tasks/SKILL.md` — reads `tasks.md`, parses sections (En Progreso, Proximo, Completado), produces task counts + in-progress list.
4. `scaleup-start-present/SKILL.md` — receives profile data + session summaries + task state, presents formatted context summary, proposes session focus based on lowest score or pending tasks.

**Files:**
- `.claude/skills/scaleup-start-load-profile/SKILL.md` — create
- `.claude/skills/scaleup-start-load-sessions/SKILL.md` — create
- `.claude/skills/scaleup-start-load-tasks/SKILL.md` — create
- `.claude/skills/scaleup-start-present/SKILL.md` — create

**AC reference:** "scaleup-start-load-profile reads company-profile.yaml", "scaleup-start-load-sessions reads last 3 session logs", "scaleup-start-load-tasks reads tasks.md"

**Verification:** Each SKILL.md exists, has YAML frontmatter (name, description), describes clear numbered steps, references correct file paths.

**Size:** M
**Dependencies:** none (can run parallel with T1, but logically T1 first)

### T3: `/scaleup-start` orchestrator

**Description:** Create the orchestrator skill that sequences the 4 sub-skills
from T2 with the quality gate from T1. The orchestrator:

1. Launches `scaleup-start-load-profile` as subagent via Task tool
2. Runs `validate_context_bundle` (Python) — on failure, halts and redirects to `/scaleup-welcome`
3. Launches `scaleup-start-load-sessions` as subagent
4. Launches `scaleup-start-load-tasks` as subagent
5. Launches `scaleup-start-present` as subagent with combined context

**Files:**
- `.claude/skills/scaleup-start/SKILL.md` — create

**AC reference:** "/scaleup-start orchestrates sub-skills as subagents (not inline)", "redirects to /scaleup-welcome when no profile exists", "Orchestration pattern proven"

**Verification:** SKILL.md exists, has frontmatter, describes orchestration flow with explicit subagent launch instructions, references quality gate by path, includes halt logic for missing profile.

**Size:** S
