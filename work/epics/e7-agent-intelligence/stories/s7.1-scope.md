# S7.1 — Scope Definition

## In Scope

- `/scaleup-start` orchestrator skill with sub-skills as subagents:
  - `load-profile` — read and parse company profile
  - `load-sessions` — read last 3 session logs and summarize
  - `load-tasks` — read current task board state
  - `present-context` — format and present loaded context to user
- `/scaleup-close` orchestrator skill with sub-skills as subagents:
  - `capture` — collect session activity and decisions
  - `log` — write session log file with YAML frontmatter
  - `sync` — update any modified state files
- Quality gate validator in Python for session log frontmatter schema
- Session log format: one markdown file per session in `.scaleup/my-company/sessions/YYYY-MM-DD.md`
- YAML frontmatter schema: date, duration, focus, artifacts

## Out of Scope

- Persistent memory YAML source of truth (S7.2)
- Task board CRUD operations (S7.4)
- Accountability loop logic (S7.5)
- Company knowledge graph (S7.6)
- SMART annual goal integration (S7.3)
- Any coaching logic or worksheet facilitation (E8)
- External API integrations

## Done Criteria

- [ ] `/scaleup-start` orchestrates sub-skills as subagents (not inline)
- [ ] `/scaleup-start` loads and presents company context when profile exists
- [ ] `/scaleup-start` redirects to `/scaleup-welcome` when no profile exists
- [ ] `/scaleup-start` summarizes last 3 sessions when they exist
- [ ] `/scaleup-close` writes session log to `.scaleup/my-company/sessions/`
- [ ] Session log has valid YAML frontmatter (date, duration, focus, artifacts)
- [ ] At least 1 Python quality gate validator for session log schema
- [ ] Orchestration pattern proven: each phase runs as a subagent with quality gates in code

## Risks

| Risk | Mitigation |
|------|-----------|
| Subagent orchestration pattern is unproven in this codebase | This story IS the proof — keep scope minimal to validate the pattern |
| Session log schema may need revision as S7.2 adds persistent memory | Define minimal schema now, extend in S7.2 |
| Python quality gates require PyYAML dependency | PyYAML already required by E6 |
