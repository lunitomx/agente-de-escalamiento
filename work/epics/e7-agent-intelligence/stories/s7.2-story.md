# S7.2 — Persistent Memory

## User Story

As a ScaleUp coach agent, I need a single source of truth for company data (YAML) with auto-generated markdown views, so that data is never duplicated or out of sync between machine-readable and human-readable formats.

## Acceptance Criteria

- YAML (`company-profile.yaml`) is the only file skills write to
- Markdown views (`my-company/profile.md`, etc.) are generated on `/scaleup-close`
- `validate_company_profile` Python gate validates required fields
- Diagnosis history tracked in YAML (date + scores per diagnosis)
- Existing `/scaleup-welcome` skill writes to YAML correctly
