## User Story

As a member of the Escala coaching team,
I want to map extracted patterns from a class to specific Escala skills and generate suggested improvements (deltas)
so that the learning from each class feeds directly into product improvements.

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Map patterns to skills
  Given a list of extracted patterns from a class bundle
  When I call suggest_deltas(bundle, skills_inventory)
  Then I get a list of SkillDelta items
  And each delta has a target_skill, description, evidence, and priority

Scenario: Delta points to a real skill
  Given a SkillDelta with target_skill "kokoro-canvas"
  When I validate the delta
  Then the target_skill exists in the skills inventory

Scenario: No auto-editing
  Given a list of SkillDelta items
  When I inspect the output
  Then no skill file has been modified

Scenario: Save and load deltas
  Given a list of SkillDelta items
  When I save_deltas() and load_deltas()
  Then the round-trip preserves all fields
```

### Example

```python
from coaching.pattern_extraction import load_patterns
from coaching.skill_deltas import suggest_deltas, load_skills_inventory

patterns = load_patterns("260526-eln-sesion2")
skills = load_skills_inventory()
deltas = suggest_deltas(patterns, skills)
# deltas[0].target_skill == "kokoro-canvas"
# deltas[0].suggestion_type == "strengthen_prompt"
# deltas[0].description == "Reforzar el filtro 'a quién sí' en el prompt del canvas"
```
