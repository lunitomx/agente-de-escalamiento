# Design: S18.2 — Pattern extraction from transcript and prompts

## Problem

Un bundle de clase contiene un transcript y artefactos, pero no hay nada que extraiga señales útiles de ese texto. Temas repetidos, decisiones explicitas, compromisos de alumnos y contradicciones entre prompts y enseñanza quedan sin capturar.

## Value

La extracción estructurada de patrones es la diferencia entre un transcript crudo (877 líneas) y un insumo accionable para mejorar el agente Escala. Sin S18.2, S18.3 no tiene entrada.

## Approach

Módulo `coaching/pattern_extraction.py` con:

1. **Pattern dataclass** — type (theme/decision/commitment/contradiction), label, evidence, occurrences, confidence
2. **extract_patterns(bundle)** — heuristics simples (sin LLM, sin ML):
   - **Theme**: N-gram frequency (2-4 grams) con filtro de stopwords y scoring por repetición
   - **Decision**: keywords como "compromiso", "acordamos", "les voy a pedir", "antes de la próxima clase"
   - **Commitment**: "voy a", "me comprometo a", "esta semana"
   - **Contradiction**: comparar prompts del bundle con instrucciones del transcript
3. **save/load patterns** — JSON en `work/classes/{class_id}/patterns.json`

### Design Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| DD1 | Heuristics sin LLM/ML | La primera versión debe ser determinista y sin dependencias pesadas. Los hits tempranos validan el shape de datos para S18.3 |
| DD2 | N-gram frequency para temas | Simple, rápido, sin APIs. Los temas repetidos en una clase son obvios en bigramas/trigramas |
| DD3 | Keywords + regex para decisions | Términos como "compromiso", "acordamos" son señales fiables de decisiones |
