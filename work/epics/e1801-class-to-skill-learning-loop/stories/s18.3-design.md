# Design: S18.3 — Skill delta suggestions

## Problem

S18.2 extrae patrones de un transcript (temas, decisiones, compromisos), pero esos patrones no están conectados a ningún skill del agente Escala. Falta el puente entre "aquí hay un patrón" y "este skill necesita mejorar".

## Value

Los skill deltas son el entregable central del Class-to-Skill Learning Loop. Transforman patrones abstractos en sugerencias concretas y accionables para mejorar el agente Escala.

## Approach

Módulo `coaching/skill_deltas.py` con:

1. **SkillDelta dataclass** — target_skill, suggestion_type (new_prompt/strengthen_prompt/fix_contradiction/new_heuristic), description, evidence (from pattern), priority (P0-P3)
2. **load_skills_inventory()** — escanea `escala-skills/` y opcionalmente `kokoro/` skills de Hermes, devuelve lista de skill names
3. **suggest_deltas(patterns, skills)** — mapeo reglas-based:
   - Si un patrón theme contiene palabras clave (canvas, estrategia, cliente, promesa) → mapea al skill kokoro correspondiente
   - Si un patrón decision contiene "compromiso" o "antes de la próxima clase" → sugiere mejorar prompt de seguimiento
   - Si un patrón commitment aparece → sugiere validación en skill de ejecución
4. **save/load deltas** — JSON en `work/classes/{class_id}/deltas.json`

### Mapping Rules (simplified)

| Pattern keyword | Target skill area | Suggestion type |
|----------------|-------------------|-----------------|
| canvas, modelo de negocio | kokoro-canvas | strengthen_prompt |
| estrategia | kokoro-diagnose, escala-strategy | new_prompt |
| cliente, core customer | kokoro-canvas, escala-people | strengthen_prompt |
| promesa, brand promise | kokoro-luxury-communication | new_prompt |
| compromiso, tarea | escala-execution | new_heuristic |
| a quién sí | kokoro-canvas | strengthen_prompt |
