## In Scope

- ClassBundle dataclass with class_id, title, date, transcript_path, audio_path, artifact_paths, provenance, created_at
- ingest_class() function accepting transcript path + metadata
- YAML persistence under work/classes/{class_id}/bundle.yaml
- CLI with `ingest` and `load` subcommands via argparse
- class_id auto-generation: YYMMDD-slug
- Tests: create bundle (minimal + full), missing transcript error, class_id format, CLI ingest and load

## Out of Scope

- BBB download automation (delegated to bigbluebutton-whisper-local)
- Pattern extraction or analysis of any kind (S18.2)
- Database persistence (file-based only)
- Any UI or web serving

- [ ] ingest_class() produces valid ClassBundle from transcript + title
- [ ] Bundle is persisted as YAML work/classes/{class_id}/bundle.yaml
- [ ] Missing transcript raises clear error
- [ ] CLI `ingest` and `load` commands functional
- [ ] All 7 tests pass (pytest)
