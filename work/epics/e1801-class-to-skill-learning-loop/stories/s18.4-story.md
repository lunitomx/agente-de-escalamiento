## User Story

As a member of the Escala coaching team,
I want a human-readable report that summarizes a class bundle, its extracted patterns, and the suggested skill deltas
so that I can review the learning from a class in under 10 minutes without inspecting raw files.

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Generate report from bundle
  Given a ClassBundle with patterns and deltas saved
  When I call generate_report(bundle)
  Then a markdown report is saved at work/classes/{class_id}/report.md

Scenario: Report has three sections
  Given a generated report
  Then it contains a Summary section, Patterns section, and Deltas section

Scenario: Evidence is visible
  Given a report with patterns
  Then each pattern entry shows its evidence and occurrence count

Scenario: Report is reviewable
  Given a report with deltas
  Then each delta shows target_skill, suggestion, and priority
```
