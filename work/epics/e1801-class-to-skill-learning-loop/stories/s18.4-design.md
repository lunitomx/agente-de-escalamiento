# Design: S18.4 — Reviewable learning report per class

## Problem

S18.1-S18.3 producen bundle, patterns y deltas como archivos JSON. Revisarlos requiere abrir múltiples archivos JSON dispersos. Falta una vista unificada, legible y revisable en <10 minutos.

## Value

El reporte es el entregable visible del Class-to-Skill Learning Loop. Es lo que el equipo de coaching revisa, discute y acciona. Sin reporte, las sugerencias quedan en archivos técnicos que nadie lee.

## Approach

Módulo `coaching/class_report.py` con `generate_report(bundle)` que:

1. Lee bundle.yaml, patterns.json, deltas.json del class_id
2. Genera report.md con tres secciones separadas
3. **Facts** (bundle metadata), **Patterns** (evidence + ocurrencias), **Deltas** (skill + prioridad + evidencia)
4. Guarda en `work/classes/{class_id}/report.md`
