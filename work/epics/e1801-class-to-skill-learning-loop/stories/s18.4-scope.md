## In Scope

- `generate_report(bundle)` → markdown report saved alongside bundle
- Report sections: Class Summary, Extracted Patterns, Skill Deltas
- Each pattern shows type, label, evidence, occurrences
- Each delta shows target_skill, description, evidence, priority
- Facts, interpretations, and suggestions clearly separated

## Out of Scope

- HTML rendering (plain markdown is reviewable)
- Visual design or branding
- Automated delivery (email, dashboard)

## Done When

- [ ] generate_report() writes report.md to bundle class_id directory
- [ ] Report has 3 sections: Summary, Patterns, Deltas
- [ ] Each pattern includes evidence
- [ ] Each delta references a skill
- [ ] Report readable in <10 min without inspecting raw files
- [ ] Tests pass
