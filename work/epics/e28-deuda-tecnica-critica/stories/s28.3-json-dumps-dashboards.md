# S28.3 — json.dumps() en generate_dashboards.py

**Epic:** E28 — Deuda Técnica Crítica
**Size:** S (<1h)
**Status:** Draft

## Objetivo

Reemplazar la serialización JSON manual frágil en `generate_dashboards.py` con `json.dumps()` estándar.

## Archivos

- `escala_server/cash/generate_dashboards.py:498`

## Cambio

**Antes (línea 498):**
```python
metrics_json = str(db["metrics"]).replace("'", '"').replace('"key"', "'key'").replace('"label"', "'label'").replace('"tip"', "'tip'")
```

**Después:**
```python
metrics_json = json.dumps(db["metrics"])
```

Y en el template HTML (líneas 376, 436-448), ajustar para usar nombres de clave con comillas dobles (que es lo que `json.dumps` produce).

## Verificación

1. Ejecutar `python -m escala_server.cash.generate_dashboards`
2. Abrir un dashboard generado (`build/dashboards/cash/power-of-one.html`)
3. Verificar que `var METRICS = [...]` contiene JSON válido
4. Abrir en browser y verificar que los campos se renderizan

## Criterios de Aceptación

- [ ] `json.dumps(db["metrics"])` usado sin replaces manuales
- [ ] Dashboards generados tienen JavaScript sintácticamente válido
- [ ] Browser renderiza campos correctamente

## Trampa

- El replace de `'key'` por `"key"` era un workaround para que el JavaScript funcionara con comillas simples. Con `json.dumps`, las claves ya van con comillas dobles. Solo hay que verificar que el JavaScript en el template itere correctamente con `m.key` (que funciona con ambos).
