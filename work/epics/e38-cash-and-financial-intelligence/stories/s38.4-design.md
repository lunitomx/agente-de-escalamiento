# S38.4 — Design

## Complexity

Moderada: tres representaciones del mismo payload, escaping HTML, hash
determinista y escritura atómica en autoridad local.

## Gemba

`escala_server/cash/generate_dashboards.py` genera dashboards estáticos
educativos; no se reemplaza. El reporte nuevo consume `CashDecision`, usa
inline CSS/HTML sin dependencias y escribe bajo `WorkspaceConfig.data_root`.

## Approach

Construir un payload canónico, derivar `report_id` SHA-256 y escribir HTML,
JSON y Markdown dentro de `.escala-cash-reports/<id>/`. El HTML muestra valores
solo en el artefacto privado local, siempre escapados; el receipt público del
artefacto contiene únicamente IDs, rutas relativas y hashes.

## Legacy sweep

El dashboard estático V1 queda coexistiendo para presentación sin datos. No se
elimina porque no es una vista de evidencia financiera dinámica.
