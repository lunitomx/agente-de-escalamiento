# S38.4: Visual Cash Evidence

## User story

Como empresario, quiero abrir un reporte visual local para ver mi cash, las
preguntas abiertas, los escenarios y la evidencia que respalda cada cifra,
para descargarlo o compartir el archivo sin convertir la carpeta compartida en
la autoridad del sistema.

## Acceptance criteria

### Scenario 1 — reporte positivo

Given una decisión `ready`  
When se genera el reporte  
Then se escriben HTML, Markdown y JSON locales con métricas, CCC, escenarios,
recommendations y provenance, usando solo rutas relativas y sin red.

### Scenario 2 — reporte de bloqueo

Given decisión `blocked` con findings/questions  
When se genera el reporte  
Then el reporte muestra el bloqueo y preguntas accionables, y no muestra una
recommendation inventada.

### Scenario 3 — rerun seguro

Given el mismo decision payload  
When se genera dos veces  
Then el `report_id` y contenido son deterministas, el workbook original no
mutates y el receipt de artefacto no contiene valores sensibles ni rutas de
máquina.

## Out of scope

- Servidor hospedado, navegador remoto, OAuth o sincronización SQLite.
- Dashboard ejecutivo 0–100 (E40).

## Done when

- `write_cash_report` crea artefactos locales descargables bajo `data_root`.
- El HTML es autosuficiente, redacted respecto a rutas y escapado.
- Qualification positiva y negativa pasa con receipt determinista.
