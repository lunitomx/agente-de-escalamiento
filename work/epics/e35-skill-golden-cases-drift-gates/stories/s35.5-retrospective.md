## Risks Accepted

- The integration is a versioned script/checklist, not a native `rai gate` id.
  `rai gate list -f json` did not show a project-local registry to extend.
- Release outputs are deterministic fixtures, not live model calls.
- `rai gate check --all -f json` is not fully green because `gate-sync`
  requires keys even under aggregate execution. Scoped gates and full pytest
  passed.

## Follow-Ups

- If RaiSE later exposes versioned local gate registration, wrap this script in
  a native gate id.
