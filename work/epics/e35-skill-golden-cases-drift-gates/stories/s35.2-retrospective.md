## Risks Accepted

- S35.2 does not validate generated outputs. That is intentionally deferred to
  S35.3.
- S35.2 does not create a release gate. That remains S35.5.
- Fixtures validate expected properties, not full prose snapshots, to avoid
  brittle golden text.

## Follow-Ups

- S35.3 must use these fixtures to detect missing methodology sections,
  forbidden claim patterns, and evidence behavior in output files.
- S35.4 must require rationale when fixture expectations change.
- S35.5 must make the golden-case status visible in release review.
