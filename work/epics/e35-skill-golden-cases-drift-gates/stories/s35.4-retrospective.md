# S35.4 Retrospective: Prompt/Version Changelog

## Outcome

S35.4 is complete. Golden-case expectations now require changelog evidence tied
to a stable expectation hash.

## What Changed

- Added changelog entries for all current core golden cases.
- Added `GoldenCaseChangelogEntry`.
- Added `golden_case_expectation_hash`.
- Added `validate_golden_case_changelog`.
- Added tests that fail when expectations change without matching changelog
  evidence.

## Risks Accepted

- The changelog validates current expectation hashes, not historical git
  ancestry.
- A maintainer can still update both fixture and changelog together, but must
  leave reason, reviewer, changed fields, and expected behavior change.

## Follow-Ups

- S35.5 must expose changelog validation alongside fixture and drift validation
  in release review.
