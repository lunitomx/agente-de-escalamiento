# S35.5 Scope: Release Gate Integration

## In Scope

- Add a release check script that validates:
  - core golden-case fixtures;
  - golden-case output drift;
  - golden-case changelog evidence.
- Add a release checklist documenting when and how to cite the check.
- Add tests for the release check success and failure behavior.
- Record sample passing output in E35 evidence.

## Out of Scope

- Modifying RaiSE CLI internals.
- Automatic release promotion.
- CI provider configuration.
- Live LLM calls or semantic grading.

## Done When

- Release review can run one command for golden-case status.
- The check names failed cases and why they failed.
- Documentation states how this differs from E30 pipeline registry, E31 runner,
  and E32 closure governance.
- Tests cover the release check.

## Verification

- `rai gate check gate-tests --scope tests/test_skill_golden_case_gate.py`
- `rai gate check gate-tests --scope tests/test_skill_golden_case_changelog.py`
- `rai gate check gate-tests --scope tests/test_skill_golden_case_drift.py`
- `rai gate check gate-tests --scope tests/test_skill_golden_cases.py`
- `rai gate check gate-lint`
- `rai gate check gate-format`
- `rai gate check gate-types`
