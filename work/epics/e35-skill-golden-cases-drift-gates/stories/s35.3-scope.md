# S35.3 Scope: Drift Check Implementation

## In Scope

- Implement deterministic drift checks for golden-case output files.
- Detect missing expected sections.
- Detect forbidden claim patterns.
- Detect missing evidence behavior when `evidence_required` is true.
- Add passing and deliberate regression output fixtures.
- Return readable errors that identify the failing case and property.

## Out of Scope

- Live LLM calls.
- Semantic grading or fuzzy similarity scoring.
- Full prose snapshot comparison.
- Changelog enforcement.
- Release gate registration.

## Done When

- A compliant output passes for a core golden case.
- An output missing a required section fails.
- An output containing a forbidden claim pattern fails.
- An evidence-required output without evidence behavior fails.
- Tests cover the drift checker and existing golden-case fixture validation.
- Story artifacts include design, plan, progress, and retrospective before
  story close.
