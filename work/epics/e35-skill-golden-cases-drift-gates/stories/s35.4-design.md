# S35.4 Design: Prompt/Version Changelog

## Complexity

Moderate. The validator needs a stable hash of golden-case expectation fields,
but it does not need git diff inspection or external systems.

## Problem

Golden cases can be weakened silently if fixture expectations change without a
reviewable rationale. S35.4 must make expectation changes auditable before
release-gate integration.

## Value

The changelog creates a durable review trail for accepted drift. It protects
S35.3 from becoming a rubber stamp where expectations are edited to fit weaker
outputs.

## Approach

Add a changelog YAML file:

- `.raise/skill-golden-cases/changelog.yaml`

Each entry records:

- `change_id`
- `case_id`
- `skill`
- `expectation_hash`
- `reason`
- `reviewer`
- `changed_fields`
- `expected_behavior_change`

The hash covers expectation-bearing fields only:

- `expected_sections`
- `required_methodology_terms`
- `forbidden_claim_patterns`
- `evidence_required`

If any of those fields change, the hash changes and validation fails until the
changelog is updated with rationale.

## Components

| Component | Change | Purpose |
|---|---|---|
| `.raise/skill-golden-cases/changelog.yaml` | create | Accepted expectation-change evidence. |
| `validators/skill_golden_cases.py` | extend | Changelog model, hashing, and validation. |
| `tests/test_skill_golden_case_changelog.py` | create | Valid and invalid changelog tests. |

## Acceptance Criteria

### MUST

- Current core cases have matching changelog entries.
- Changed expectations without matching hash fail validation.
- Changelog entries require rationale and reviewer fields.

### MUST NOT

- Do not register release gates.
- Do not use git diff as the only source of truth.
- Do not accept blank rationale.

## Testing Strategy

| Layer | Test | Purpose |
|---|---|---|
| Unit | current changelog validates | Proves baseline evidence exists. |
| Unit | changed expectation hash fails | Proves silent expectation drift is caught. |
| Unit | missing rationale fails | Proves review evidence is required. |
