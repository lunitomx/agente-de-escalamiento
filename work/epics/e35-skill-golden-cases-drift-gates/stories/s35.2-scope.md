# S35.2 Scope: Core Skill Golden Cases

## In Scope

- Add golden cases for `scaleup-strategy`, `scaleup-cash`, `scaleup-people`,
  and `scaleup-execution`.
- Store core fixtures under a separate deterministic fixture directory.
- Validate that each selected skill has at least one golden case.
- Define expected sections, required methodology terms, forbidden weak behavior,
  evidence requirements, and notes for every selected skill.
- Use the tracked skill catalog under `.claude/skills` for reproducible tests.

## Out of Scope

- Exhaustive coverage of all ScaleUp skills.
- Live LLM calls or generated answer scoring.
- Full prose snapshot comparison.
- Drift checking against output files.
- Prompt/version changelog and release gate integration.

## Done When

- Each selected skill has at least one core golden case.
- Core fixtures validate against the tracked skill catalog.
- Tests prove the selected skill set is fully covered.
- Tests prove core cases declare methodology properties and forbidden behavior.
- Story artifacts include design, plan, progress, and retrospective before
  story close.

## Verification

- `rai gate check gate-tests --scope tests/test_skill_golden_cases.py`
- `rai gate check gate-lint`
- `rai gate check gate-format`
- `rai gate check gate-types`
