# S35.1 Story: Golden Case Fixture Contract

## User Story

As a skill maintainer, I want a fixture format for expected skill behavior so
methodological drift can be detected without comparing full prose snapshots.

## Acceptance Criteria

### Scenario: Complete Fixture Passes

Given a golden case fixture for an existing ScaleUp skill
When the fixture is validated
Then validation passes
And expected sections, required methodology terms, forbidden claim patterns,
and evidence requirements are present.

### Scenario: Missing Skill Fails

Given a golden case fixture that references a missing skill
When the fixture is validated
Then validation fails with an actionable error.

### Scenario: Missing Expected Properties Fails

Given a golden case fixture without expected sections or behavior properties
When the fixture is validated
Then validation fails
And the error names the missing expected property.
