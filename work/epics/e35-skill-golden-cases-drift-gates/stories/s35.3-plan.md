# S35.3 Plan: Drift Check Implementation

**Story:** S35.3 Drift Check Implementation
**Size:** M
**Date:** 2026-06-19

## Overview

Implement deterministic drift checking over golden-case output files. Keep the
checker simple and auditable: required strings must be present, forbidden
strings must be absent, and evidence-required cases must show citation or
missing-evidence behavior.

## Risks And Mitigations

| Risk | Mitigation |
|---|---|
| String checks become too shallow. | Keep them as first deterministic gate; future semantic scoring must be separate. |
| Evidence behavior becomes ambiguous. | Use explicit evidence markers and fail missing-evidence outputs. |
| Output fixtures become snapshots. | Store small fixture excerpts, not full generated responses. |
