# S35.1 Scope: Golden Case Fixture Contract

## In Scope

- Define a golden case fixture model for skill behavior validation.
- Validate required fields: case id, skill, input context, expected sections,
  required methodology terms, forbidden claim patterns, evidence requirement,
  and notes.
- Validate referenced skills exist under the local skill catalog.
- Add positive and negative fixture examples.
- Return readable validation errors.

## Out of Scope

- Running live LLM calls.
- Creating golden cases for every core skill.
- Checking actual output drift against fixtures.
- Release gate integration.
- Prompt/version changelog.

## Done When

- A complete fixture for an existing skill validates successfully.
- A fixture referencing a missing skill fails validation.
- A fixture without expected behavior properties fails validation.
- Tests cover positive and negative fixture cases.
- Story artifacts include design, plan, progress, and retrospective before
  story close.

## Verification

- `rai gate check gate-tests --scope tests/test_skill_golden_cases.py`
- `rai gate check gate-lint`
- `rai gate check gate-format`
- `rai gate check gate-types`
