# S35.4 Scope: Prompt/Version Changelog

## In Scope

- Define changelog fields for golden-case expectation changes.
- Add changelog entries for the current core golden cases.
- Hash expectation-bearing fixture fields so changed expectations require a
  matching changelog update.
- Validate changelog completeness and readability.

## Out of Scope

- Release gate registration.
- External approval workflow.
- Reconstructing every historical prompt change.
- Live model calls or semantic scoring.

## Done When

- Changelog entries include case id, skill, expectation hash, reason, reviewer,
  changed fields, and expected behavior change.
- Current core golden cases have matching changelog evidence.
- A fixture expectation change without matching changelog evidence fails.
- Tests cover valid and invalid changelog scenarios.
