# S35.5 Story: Release Gate Integration

As a release reviewer, I want golden-case status visible in release checks so
skill changes cannot ship without behavior evidence.

## Notes

The current RaiSE CLI lists built-in gates but no versioned local gate registry
for adding a new `rai gate` id. This story provides a versioned release check
script and checklist that can be cited in release review.
