## In Scope

- Algoritmo/heurística de selección de herramienta según área de decisión y evidencia disponible.
- Integración con el paquete de evidencia de S43.2.
- Recibos/logs que registren por qué se eligió cada herramienta.
- Primer recorrido end-to-end para Cash y Weekly.
- Manejo seguro del caso "dato mínimo no existe".

## Out of Scope

- Crear nuevos motores de análisis (se reutilizan Cash, Execution, Strategy, People existentes).
- Persistencia remota o API externa.
- UI nueva para el empresario (se usa formato ejecutivo de S43.5).
- Calificación de los cuatro pilares → S43.6.

## Done when

- ESCALA selecciona Cash cuando la evidencia es un workbook financiero.
- ESCALA selecciona Execution cuando la evidencia son reuniones/prioridades.
- Cuando falta el dato mínimo, ESCALA pregunta antes de concluir.
- Cada elección deja un recibo trazable (área, evidencia usada, herramienta elegida).
- Tests pasan y cubren los escenarios positivo, negativo y de dato faltante.
