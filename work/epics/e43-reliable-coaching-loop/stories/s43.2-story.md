# S43.2 — Armar el paquete de evidencia

## Historia de usuario

**Como** empresario que toma una decisión con ESCALA,  
**quiero** ver qué evidencia usa el sistema antes de recomendar,  
**para que** pueda confiar en la recomendación o pedir lo que falta.

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Paquete de evidencia

  Background:
    Given una pregunta empresarial ya aclarada en S43.1

  Scenario: Evidencia disponible para la decisión
    Given existen archivos locales, sesiones, métricas, tareas o worksheets relevantes
    When ESCALA arma el paquete de evidencia
    Then incluye las fuentes disponibles con periodo y nivel de confianza
    And no expone rutas internas ni datos de otra empresa

  Scenario: Información relevante ausente
    Given no hay fuentes suficientes para responder con seguridad
    When ESCALA arma el paquete
    Then lista explícitamente la evidencia ausente
    And pregunta por esa información antes de concluir

  Scenario: Evidencia disponible pero no confiable todavía
    Given una fuente local existe pero está desactualizada o incompleta
    When ESCALA la evalúa
    Then la marca como "no confiable todavía"
    And documenta por qué no se puede usar como hecho
```

## Ejemplos por especificación (SbE)

| Decisión | Evidencia disponible | Evidencia ausente | Certeza | Resultado esperado |
|---|---|---|---|---|
| ¿Podemos pagar la nómina de agosto? | Cash workbook julio, última proyección de ingresos | Cuentas por cobrar vencidas, gastos confirmados de agosto | Media | Muestra el workbook y pide los datos faltantes |
| ¿Quién debe ocupar el puesto clave de ventas? | FACChart actual, entrevistas recientes de Topgrading | Evaluaciones de desempeño del último trimestre | Media-Alta | Usa el FACChart y pide las evaluaciones |
| ¿Avanzamos con el nuevo canal de distribución? | OPSP del trimestre, datos de pipeline | Costo de adquisición actualizado por canal | Baja | Muestra el OPSP y señala el riesgo del costo desconocido |

## Notas

- El paquete es un paso intermedio: alimenta la elección de herramienta en S43.3.
- La confianza se expresa como un nivel (alta/media/baja) más una razón corta.
- La privacidad es un criterio duro: nunca se exponen rutas absolutas ni datos de otras empresas.
