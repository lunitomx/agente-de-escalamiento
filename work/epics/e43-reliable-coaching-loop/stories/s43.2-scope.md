# S43.2 — Armar el paquete de evidencia: alcance

## Dentro del alcance

- Recibir la decisión aclarada de S43.1 (objetivo, área, horizonte, resultado esperado).
- Buscar evidencia relevante en archivos locales, sesiones previas, métricas, tareas y worksheets del área afectada.
- Clasificar cada fuente en: **disponible**, **ausente** o **no confiable todavía**.
- Anotar procedencia, periodo cubierto y nivel de confianza de cada fuente.
- Generar un paquete de evidencia legible que alimente la elección de herramienta (S43.3).
- Respetar privacidad: no exponer rutas de archivo internas, datos innecesarios ni información de otras empresas.
- Añadir tests que cubran los escenarios de disponible, ausente y no confiable.

## Fuera del alcance

- Elegir la herramienta de análisis → S43.3.
- Revisar contradicciones, cálculos dudosos o afirmaciones sin fuente → S43.4.
- Generar la respuesta ejecutiva de cinco bloques → S43.5.
- Crear nuevos pipelines de ingesta, APIs externas o bases de datos compartidas.
- Visualizaciones gráficas del camino de evidencia (parking lot del épico).

## Termina cuando

- [ ] ESCALA lista fuentes disponibles con periodo y nivel de confianza.
- [ ] ESCALA lista fuentes ausentes que bloquean o limitan la conclusión.
- [ ] ESCALA marca fuentes no confiables con una razón clara.
- [ ] El paquete no revela rutas internas, datos sobrantes ni información ajena.
- [ ] Los tests de los tres escenarios pasan localmente.
- [ ] La decisión de S43.1 y el paquete están vinculados trazablemente.
