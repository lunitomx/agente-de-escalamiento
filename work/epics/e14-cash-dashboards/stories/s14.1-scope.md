# S14.1 Scope: CASh — Cash Acceleration Strategies Board

## In Scope

| # | Item |
|---|------|
| 1 | 4×3 grid component: 4 ciclos (Sales, Production, Delivery, Billing) × 3 estrategias (Shorten, Eliminate, Improve) |
| 2 | Day meter per ciclo — numeric display + visual indicator (bar, ring, or progress element) |
| 3 | Traffic-light health indicator per ciclo (green / yellow / red) with threshold logic |
| 4 | Responsive layout: desktop grid view + mobile stacked card view |
| 5 | Placeholder/zero-data render mode so skill works before data is entered |
| 6 | Visualization framework selection and ADR document |
| 7 | JSON data contract specification for the component |
| 8 | Self-contained component — no external API calls, all data inline |

## Out of Scope

| # | Item | Why excluded |
|---|------|-------------|
| 1 | Real-time data from accounting/banking APIs | Epic-level exclusion |
| 2 | PDF or Excel export | Epic-level exclusion |
| 3 | Translation / i18n | Epic-level exclusion |
| 4 | Editable form inputs inside the dashboard | Data entry stays in the coaching skill flow; dashboard is read-only visualization |
| 5 | Animated transitions / micro-interactions | Nice to have, deferred to polish pass if time allows |
| 6 | Power of One calculations | S14.2's responsibility |
| 7 | Radar chart | S14.4's responsibility |
| 8 | Recurring Revenue hierarchy visual | S14.3's responsibility |

## Assumptions

1. The skill output context can embed an HTML component inline — either as a file reference the user opens, or as part of the chat output
2. Vanilla HTML/CSS/JS is the default candidate for framework (zero dependencies, easiest to embed) — ADR may confirm or override
3. Threshold values for traffic lights (e.g., >60 days = red) will use Scaling Up methodology defaults; no user configuration UI needed in this story

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|-----------|
| Framework choice causes rework in S14.2–S14.4 | Low | High | Choose framework with radar chart support (Chart.js) or plan upgrade path before closing S14.1 |
| Embedding HTML in skill output is unsupported | Medium | High | Test embed approach on day 1; fallback = standalone .html file the user opens locally |
| Grid layout breaks on very small screens | Low | Low | Add a ≤480px breakpoint that collapses to single-column list |
