# S14.2 Scope: Power of One — Visual Dashboard

## In Scope

| # | Item |
|---|------|
| 1 | Two-column layout: Current Position vs Adjusted Position for all 7 variables |
| 2 | 7 variable rows: Price, Volume, COGS, Overheads, A/R (days), Inventory (days), A/P (days) |
| 3 | Cash Flow impact calculation per variable (delta from current to adjusted) |
| 4 | EBIT impact calculation per variable (delta from current to adjusted) |
| 5 | Summary row with total Cash Flow impact and total EBIT impact |
| 6 | Traffic light indicators per variable row (green/yellow/red based on impact direction) |
| 7 | Summary traffic light reflecting overall net impact |
| 8 | Read-only dashboard — data injected via `window.CASH_DATA`, no editable inputs |
| 9 | Placeholder/demo data mode so dashboard renders before user fills in values |
| 10 | Responsive layout: two-column desktop view, stacked mobile view |
| 11 | Reuse of `components/shared/styles/dashboard-base.css` and vendored Chart.js from S14.1 |
| 12 | Self-contained HTML file — no external API calls, no backend required |

## Out of Scope

| # | Item | Why excluded |
|---|------|-------------|
| 1 | Editable form inputs inside the dashboard | Dashboard is read-only; data entry stays in the coaching skill flow |
| 2 | Real-time data from accounting/banking APIs | Epic-level exclusion |
| 3 | PDF or Excel export | Epic-level exclusion |
| 4 | Translation / i18n | Epic-level exclusion |
| 5 | Animated transitions / micro-interactions | Nice to have; deferred to polish pass |
| 6 | Scenario comparison (more than two columns) | Current vs Adjusted is the full Power of One model; multi-scenario is a future enhancement |
| 7 | Drill-down per variable (historical trends) | Out of Power of One methodology scope |
| 8 | Radar chart | S14.4's responsibility (Fundability) |
| 9 | Recurring Revenue hierarchy visual | S14.3's responsibility |
| 10 | New CDN dependencies without ADR update | Framework locked in S14.1 ADR-001; any addition requires explicit decision record |

## Assumptions

1. The data contract from S14.1 (`window.CASH_DATA`) is extended with a `powerOfOne` key — no new loading mechanism needed
2. Working capital variables (A/R, Inventory, A/P) affect only Cash Flow; revenue/cost variables affect both Cash Flow and EBIT
3. Traffic light thresholds: positive delta = green, zero/near-zero = yellow, negative delta = red
4. Daily revenue for working capital calculations is derived from `Volume × Price / 365` when available, or passed explicitly in the data payload
5. Chart.js bar chart showing net impact is optional — the table/grid view is the primary visualization
