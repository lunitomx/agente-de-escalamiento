# Story s14.4 — Fundability Visual Dashboard

## User Story

**As a** ScaleUp user evaluating fundability,
**I want** a radar chart dashboard showing my 8 fundability criteria,
**So that** I can identify which dimensions to improve for investor readiness.

---

## Acceptance Criteria (Gherkin)

### AC1 — Radar renders all 8 criteria
```gherkin
Given window.CASH_DATA.fundability contains ratings for all 8 criteria
When the dashboard loads
Then a Chart.js v4 radar chart renders with 8 axes:
  Leadership, Business Model, Values, Industry, Exit, House, Consistency, Assets
And each axis reflects the correct rating value
```

### AC2 — Weak / Solid / Great rating system
```gherkin
Given a criterion is rated "Weak", "Solid", or "Great"
When the radar chart renders
Then "Weak" maps to value 1, "Solid" to 2, "Great" to 3
And the polygon shape reflects the composite of all 8 ratings
```

### AC3 — Color-coded areas
```gherkin
Given the radar chart is visible
When the user views the chart
Then the fill color communicates overall fundability health:
  - Predominantly Weak ratings → red/amber fill
  - Mixed ratings → amber/yellow fill
  - Predominantly Great ratings → green fill
And the color coding is accessible (not color-only)
```

### AC4 — Summary scorecard table
```gherkin
Given the radar chart has rendered
When the user scrolls below the chart
Then a summary table lists all 8 criteria
And each row shows: criterion name, current rating (Weak/Solid/Great), and a status indicator
And the table is readable without the chart
```

### AC5 — Responsive layout
```gherkin
Given the dashboard is open
When the viewport is 375px wide (mobile)
Then the radar chart scales to fit without horizontal scroll
And the summary table stacks or scrolls correctly

When the viewport is 1440px wide (desktop)
Then the chart and table use available space effectively
```

### AC6 — Data injection pattern
```gherkin
Given a host page sets window.CASH_DATA.fundability before the script loads
When the component initializes
Then it reads criteria ratings from window.CASH_DATA.fundability
And renders placeholder/demo data if window.CASH_DATA is absent or incomplete
```

### AC7 — No innerHTML
```gherkin
Given the component renders dynamic content
When any criterion name, rating label, or score is inserted into the DOM
Then no innerHTML assignment is used for user-controlled data
And all DOM mutations use createElement / textContent / setAttribute
```

---

## Size: M
Chart.js radar is a new chart type in this epic. Requires axis configuration, scale definition, and color logic beyond the bar/line charts in S14.1/S14.2.

## Tech Stack
- Vanilla HTML5 / CSS3 / ES6 (no framework)
- Chart.js v4 — vendored at `components/shared/vendor/`
- Data pattern: `window.CASH_DATA.fundability` (mirrors `window.CASH_DATA.powerOfOne`)

## Dependencies
- Chart.js v4 already vendored (confirmed in S14.1/S14.2)
- Epic scaffold at `components/cash/`
