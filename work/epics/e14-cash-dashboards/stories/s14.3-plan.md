## Execution Order

```
T1 (scaffold) → T2 (banner) → T3 (cards) → T4 (customers) → T5 (responsive)
```

Sequential — each task builds on the previous. No parallelism possible (single file).

## Risks

| Risk | Mitigation |
|------|-----------|
| 4 colors too similar at a glance | Each tier uses icon + label + color (not color-only). Accessible. |
| Mobile 2×2 grid tight on small phones | At <=768px collapse to single column stacked |
| Tenure formatting edge cases | Use simple logic: >=12 months → years, else months |

## Gate Policy

Este es un componente visual vanilla HTML — no hay pytest, lint, ni typecheck. Las verificaciones son manuales con browser.

| When | Verification |
|------|-------------|
| Per task | Open in browser, check visual + console |
| End of story | Full AC sweep at 375px + 1440px, innerHTML audit |
