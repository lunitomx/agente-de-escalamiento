## 3. Contradiction Resolution: Read-only vs. Editable Inputs

The skill instructions (Step 6 MUST) mentioned "an input for days + a note field" per cell. However:

- `s14.1-scope.md` Out of Scope #4 states explicitly: *"Editable form inputs inside the dashboard — Data entry stays in the coaching skill flow; dashboard is read-only visualization"*
- `s14.1-story.md` AC2 uses display verbs: "displayed", "visually represents" — not "input" or "editable"
- AC6 specifies: "data is passed via a JSON payload or inline template variables"

**Resolution: Dashboard is read-only.** Scope.md supersedes skill prose. The coaching skill (`/scaleup-cash-ccc` and `/scaleup-cash-acceleration`) handles data collection. The dashboard renders what was collected. This is the correct pattern for all E14–E17 dashboards.

## 6. Traffic Light Threshold Logic

### Per-Cycle Thresholds

| Ciclo | Green (healthy) | Yellow (warning) | Red (critical) |
|-------|----------------|-----------------|----------------|
| Sales | ≤ 30 days | 31–60 days | > 60 days |
| Production | ≤ 14 days | 15–30 days | > 30 days |
| Delivery | ≤ 7 days | 8–14 days | > 14 days |
| Billing | ≤ 30 days | 31–45 days | > 45 days |

Each cycle has its own benchmark because the Scaling Up methodology recognizes that different industries have structurally different cycles. A 30-day production cycle might be normal manufacturing but alarming for software services.

**Placeholder mode:** When `current_days === 0`, show a neutral gray indicator (not red, not green). Zero means "not measured yet" — not "zero days."

### Grand Total CCC Thresholds

| Total CCC | Indicator | Meaning |
|-----------|-----------|---------|
| ≤ 30 days | Green | Excellent — approaching negative CCC |
| 31–81 days | Yellow | Within benchmark range — watch and improve |
| 82–120 days | Orange | Above benchmark — prioritize acceleration |
| > 120 days | Red | Critical — CCC is destroying cash; escalate |

The grand total uses a different scale because individual cycle health can be green while the total CCC is still problematic.

## 9. UX Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Read-only vs editable | Read-only | Scope.md §Out-of-Scope #4 overrides skill prose |
| Placeholder state | Neutral gray indicator, 0d shown | Zero means "not measured" — not "zero days achieved" |
| Bar meter library | CSS `<progress>` or CSS width calc, not Chart.js | Simpler; Chart.js reserved for radar/bar charts in S14.2/S14.4 |
| Strategy cell density | Description + potential days saved only | Actions list too verbose for a dashboard; actions stay in skill flow |
| Language | Spanish labels for cycle names, English for strategy terms | Follows existing ScaleUp skill convention |
