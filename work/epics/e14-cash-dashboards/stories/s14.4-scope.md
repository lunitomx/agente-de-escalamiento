# Scope: s14.4 — Fundability Visual Dashboard

## In Scope

| Item | Notes |
|------|-------|
| 8-criterion radar chart | Leadership, Business Model, Values, Industry, Exit, House, Consistency, Assets |
| Weak / Solid / Great rating system | Maps to numeric scale 1/2/3 for Chart.js |
| Color-coded radar fill | Reflects overall fundability health |
| Summary scorecard table | Below chart — criterion name, rating, status indicator |
| Responsive layout | Tested at 375px (mobile) and 1440px (desktop) |
| Chart.js v4 radar type | Uses vendored library already present in project |
| `window.CASH_DATA.fundability` injection | Same data pattern as powerOfOne dashboard |
| Placeholder/demo data | Renders gracefully when no data injected |
| No innerHTML for dynamic content | Security constraint — all dynamic DOM via createElement/textContent |

---

## Out of Scope

| Item | Reason |
|------|--------|
| Multiple radar overlays | Would require historical data — tracked separately |
| PDF / image export | Separate export feature, not part of this story |
| Inline edit mode | Ratings are injected externally, not edited in-dashboard |
| Historical tracking | Time-series analysis is a future epic |
| Animated transitions between states | Nice-to-have, deferred to polish pass |
| Server-side rendering | Static component only |

## Chart.js Radar Configuration Notes

- Scale: `min: 0`, `max: 3`, `stepSize: 1`
- Tick labels: `0 → ""`, `1 → "Weak"`, `2 → "Solid"`, `3 → "Great"`
- 8 axes in order: Leadership, Business Model, Values, Industry, Exit, House, Consistency, Assets
- Point labels: visible, readable at mobile sizes
- Fill: semi-transparent (alpha ~0.3) to show axis grid beneath
