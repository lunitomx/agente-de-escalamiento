# S14.2: Power of One — Visual Dashboard

## User Story (Connextra Format)

**As a** ScaleUp user working on the Cash decision,
**I want** a visual dashboard showing all 7 Power of One variables with their current and adjusted positions,
**So that** I can immediately see how a 1-unit improvement in each lever impacts my Cash Flow and EBIT, and prioritize which variable to move first.

---

## Acceptance Criteria (Gherkin)

### AC1 — Two-column layout renders correctly

```gherkin
Given the user opens the Power of One dashboard
When the component loads with default or placeholder data
Then a two-column layout is displayed: "Current Position" vs "Adjusted Position"
And all 7 variables are listed as rows: Price, Volume, COGS, Overheads, A/R, Inventory, A/P
And each row shows the current value and an adjusted value side by side
```

### AC2 — Cash Flow impact is calculated and displayed

```gherkin
Given the Power of One dashboard is loaded with current and adjusted values
When the system computes the impact for each variable
Then a "Cash Flow Impact" column or section shows the delta (adjusted minus current effect on cash)
And the total Cash Flow impact is displayed as a summary row
And the impact is recalculated whenever adjusted values change
```

### AC3 — EBIT impact is calculated and displayed

```gherkin
Given the Power of One dashboard is loaded with current and adjusted values
When the system computes the EBIT impact for each variable
Then an "EBIT Impact" column or section shows the delta for each variable
And the total EBIT impact is displayed as a summary row
And the impact is recalculated alongside Cash Flow impact
```

### AC4 — Traffic light indicators per variable

```gherkin
Given the Power of One dashboard is loaded
When the system evaluates each variable's adjusted position vs current position
Then a traffic-light indicator (green / yellow / red) is shown for each variable row
And green = improvement from current (positive impact on cash or EBIT)
And yellow = neutral or minimal change (within a tolerance threshold)
And red = deterioration or negative impact vs current
And a summary traffic light reflects the overall net impact
```

### AC5 — Responsive design

```gherkin
Given the Power of One dashboard
When viewed on a desktop viewport (>=1024px)
Then the two-column layout is fully visible with all 7 variable rows
When viewed on a mobile viewport (<=768px)
Then the layout stacks gracefully: current and adjusted positions shown vertically per variable
And no horizontal scroll occurs on standard mobile widths
```

### AC6 — Data injected via window.CASH_DATA

```gherkin
Given the self-contained dashboard HTML file
When the component initializes
Then it reads data from window.CASH_DATA (or renders with placeholder/demo data if absent)
And no external API calls are made
And the dashboard renders meaningfully with zero/placeholder values
```

### AC7 — Reuses S14.1 tech stack

```gherkin
Given the visualization framework established in S14.1 (Vanilla HTML/CSS/JS + Chart.js v4)
When the Power of One dashboard is implemented
Then it uses the same vendor files from components/shared/vendor/
And it imports components/shared/styles/dashboard-base.css for base styles
And no new external CDN dependencies are introduced without an ADR update
```

---

## Implementation Notes

- **Variables:** Price, Volume, COGS, Overheads, A/R (Accounts Receivable days), Inventory (days), A/P (Accounts Payable days)
- **Calculation logic:**
  - Revenue variables (Price, Volume): affect both EBIT and Cash Flow
  - Cost variables (COGS, Overheads): negative effect on EBIT; impact Cash Flow proportionally
  - Working capital variables (A/R, Inventory, A/P): affect Cash Flow directly (days × daily revenue), EBIT neutral
- **Data contract:** `window.CASH_DATA.powerOfOne` — object with 7 variable keys, each containing `current`, `adjusted`, and optional `unit` fields
- **Placeholder mode:** All 7 rows render with zeroed/example values so skill works before user enters data
- **Chart.js usage:** Optional bar chart showing net Cash Flow and EBIT impact per variable; implementation optional if layout complexity warrants deferring
