## Overview

Single HTML file delivering a Chart.js radar chart for the 8 fundability criteria, with a summary table, color-zone logic, responsive layout, and the `window.CASH_DATA.fundability` injection contract. Reuses shared CSS and vendored Chart.js from S14.1/S14.2 — no new dependencies.

This is the first story in E14 to actually instantiate a Chart.js chart (S14.1/S14.2 vendored it for future use). Radar type is the primary risk.

### T2 — Chart.js Radar (M)

**Goal:** Implement and render the radar chart with correct 8-axis layout, numeric scale, Weak/Solid/Great tick labels, and color-zone fill logic.

**What to build:**
- `buildRadar(data)` function inside the `DOMContentLoaded` callback:
  - Rating → numeric map: `{ Weak: 1, Solid: 2, Great: 3 }`
  - Extract numeric array from `data.criteria` preserving fixed axis order: `['Leadership', 'Business Model', 'Values', 'Industry', 'Exit', 'House', 'Consistency', 'Assets']`
  - Compute average of all 8 numeric values
  - Determine fill color zone:
    - avg ≥ 2.5 → Green: `rgba(22, 163, 74, 0.25)` / `rgba(22, 163, 74, 1)`
    - avg 1.5–2.49 → Yellow: `rgba(217, 119, 6, 0.25)` / `rgba(217, 119, 6, 1)`
    - avg < 1.5 → Red: `rgba(220, 38, 38, 0.25)` / `rgba(220, 38, 38, 1)`
  - Chart.js config:
    - `type: 'radar'`
    - `fill: true`, `backgroundColor`, `borderColor`, `pointBackgroundColor`, `pointBorderColor: '#fff'`, `pointHoverBackgroundColor: '#fff'`, `pointHoverBorderColor`
    - `responsive: true, maintainAspectRatio: true`
    - Scale: `r.min=0`, `r.max=3`, `r.ticks.stepSize=1`
    - `r.ticks.callback: v => ['', 'Weak', 'Solid', 'Great'][v] || ''`
    - `r.pointLabels.font.size: 12`
    - `plugins.legend.display: false`
  - Store chart instance in module-scoped `window._fundabilityChart` for cleanup safety

## Risks

**R1 — Chart.js radar configuration (HIGH)**  
This is the first actual Chart.js instantiation in E14. The `r` scale key (used in v4 for radial axes) differs from the `x`/`y` keys used in Cartesian charts. The `ticks.callback` signature for the radar scale must be verified. Mitigated by using the exact config sketch from the design doc, which was validated against the Chart.js v4 API.

**R2 — Radar aspect ratio on mobile (MEDIUM)**  
`maintainAspectRatio: true` keeps the chart square, which can cause it to be too small on narrow viewports. If the default aspect ratio is too restrictive at 375px, setting `aspectRatio: 1` explicitly on the chart options or adjusting the `.chart-wrapper` padding may be needed. Discovered and addressed in T4.
