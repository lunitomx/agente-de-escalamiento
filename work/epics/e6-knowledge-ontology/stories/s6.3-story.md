# S6.3 — Strategy Decision: Ontology Population

## User Story

**As a** agente ScaleUp que facilita la decisión Strategy,
**I want** todos los conceptos, herramientas, worksheets y métricas de Strategy representados como nodos YAML en la ontología,
**So that** el agente puede hacer retrieval determinístico del conocimiento Strategy para cualquier contexto de coaching.

## Acceptance Criteria

```gherkin
Feature: Ontología Strategy poblada desde LlamaParse

  Scenario: Nodos de conceptos Strategy creados
    Given el contenido de strategy_workbook.txt y scaling_up_llamaparse.txt
    When se populan los nodos de tipo concept
    Then existen nodos para: BHAG, Core Purpose, Brand Promise, Core Customer, Differentiating Activities
    And cada nodo tiene id, type, name, name_es, decision=strategy, summary, relationships

  Scenario: Nodos de herramientas Strategy creados
    Given las fuentes LlamaParse
    When se populan los nodos de tipo tool
    Then existen nodos para: 7 Strata of Strategy, SWT Analysis, OPSP (actualizado), Sandbox, X-Factor, Profit per X
    And cada tool tiene time_estimate y frequency en metadata

  Scenario: Nodos de worksheets Strategy creados
    When se populan los nodos de tipo worksheet
    Then existen worksheets para: OPSP, SWT, 7 Strata, Core Customer
    And cada worksheet tiene fields y output documentados

  Scenario: Métricas Strategy creadas
    When se populan los nodos de tipo metric
    Then existen métricas para: Revenue Growth Rate, Brand Promise Kept Rate, Profit per X Value
    And cada métrica tiene unit, direction, benchmark

  Scenario: Relaciones Strategy correctas
    Given todos los nodos Strategy
    When se verifican las relaciones
    Then cada nodo tiene belongs-to → decision-strategy
    And tool-opsp actualizado apunta a IDs correctos (no broken refs)
    And no existen relaciones cross-decisión (eso es S6.6)

  Scenario: decision-strategy wired
    Given la ontología
    When se busca decision-strategy
    Then relationships ya no es [] — contiene todos los nodos Strategy via contains
```
