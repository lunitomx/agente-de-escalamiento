# S88.2 · Investigación con fuentes: Vivid Vision, propósito personal y Fanocracy

## Historia

Como dueño que llena las hojas del Strategy Day 2026,
quiero que los consejos de Vivid Vision, Personal Why y Fanocracy vengan de fuentes reales y revisadas,
para confiar en ellos sin leer los libros completos.

## Criterios (Gherkin)

```gherkin
Escenario: cada tema tiene hallazgos triangulados
  Dado los archivos work/research/e88-tips/{vivid-vision,life-purpose,fanocracy}.md
  Cuando la prueba lee sus bloques yaml
  Entonces cada archivo tiene 3 o más hallazgos "### fN" con <a id="fN"></a>
  Y cada hallazgo con triangulated: true cita 2 o más familias de fuentes externas

Escenario: el ancla e88 se revisa
  Dado un tip con fuente "work/research/e88-tips/x.md#f1"
  Cuando corre la revisión de anclas
  Entonces el patrón coincide y se revisa la triangulación

Escenario: hallazgo e88 sin triangular falla
  Dado un archivo temporal e88 con f1 sin triangulated: true
  Cuando corre la revisión de anclas
  Entonces la revisión reporta "no está triangulado"
```
