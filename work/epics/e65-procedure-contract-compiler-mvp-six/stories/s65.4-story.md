# S65.4 — OPPP y Vision con entrevistas narrativas

## User story

Como líder o equipo, quiero construir un OPPP o Vision Summary mediante
respuestas narrativas detalladas para obtener un borrador trazable sin que una
escala de 1 a 5 sustituya mi contexto, decisiones o confirmación.

## Acceptance criteria

```gherkin
Scenario: respuesta narrativa incompleta
  Given una entrevista de OPPP con respuestas parciales
  When el runtime construye el borrador
  Then conserva el detalle disponible
  And declara los campos desconocidos y preguntas abiertas
  And no asigna una calificación Likert como sustituto

Scenario: visión con una hipótesis local
  Given una entrevista de Vision Summary con una hipótesis no aprobada
  When el runtime genera el artefacto
  Then etiqueta la hipótesis como model-hypothesis
  And no la presenta como una decisión de empresa

Scenario: persistencia sin confirmación
  Given un borrador completo pero no confirmado por una persona autorizada
  When se solicita persistirlo
  Then el runtime lo rechaza
  And conserva sólo una actualización propuesta sin estado confirmado
```
