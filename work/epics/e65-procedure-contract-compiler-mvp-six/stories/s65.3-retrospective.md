# Retrospectiva S65.3

## Resultado

El diagnóstico ahora usa una barrera de completitud: una sola señal llamativa
no basta para declarar una restricción primaria si otra decisión permanece sin
evidencia narrativa local válida.

## Aprendizaje

Los modelos inmutables de Pydantic no vuelven segura una modificación por
`model_copy`; toda combinación de entradas de usuario con un contrato validado
debe volver a pasar por `model_validate`.

## Mejora aplicada

La selección sólo ocurre después de validar las cuatro decisiones y el output
operativo se revalida en su contrato original. Se añadieron regresiones para
evitar un bypass por texto largo, URL o ruta.
