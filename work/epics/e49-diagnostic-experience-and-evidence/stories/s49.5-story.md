# Story: Resultado diagnóstico y ruta de 90 días

## User Story

As a business leader completing an Escala diagnostic,
I want a local report that shows my scores, evidence, funnel, and a short route,
so that the session ends with an action I can own instead of a generic result.

## Acceptance Criteria

### Scenario: result explains the selected focus
```gherkin
Given an explainable diagnosis with focus evidence
When the result is built and rendered
Then the Markdown and JSON include the focus, coverage, confidence, and evidence IDs
```

### Scenario: route is bounded
```gherkin
Given a focus decision
When the default route is generated
Then it contains at most two concrete actions with owner/metric slots
```

### Scenario: local artifacts are created
```gherkin
Given a validated intake
When the diagnostic export runs
Then dated Markdown and JSON files are created under local `.escala/` and no network call occurs
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| execution focus | render result | Q1 route with KPI/weekly rhythm actions |
| funnel counts | render result | conversion rows and source counts |
| invalid intake | run export | errors, no artifact |
