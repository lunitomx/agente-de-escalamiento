# S49.3 Scope

## In scope

- Typed funnel metrics and optional average sale.
- Intake builder accepting conversation, estimate, profile/OPSP, user-file, and
  CRM-export evidence kinds.
- Normalization of optional blanks and preservation of N/A.
- Tests for mixed sources, negative counts, and missing optional values.

## Out of scope

- Reading arbitrary files, CRM APIs, scoring, persistence, and rendering.

## Done when

- [ ] `build_diagnostic_intake` returns a validated `DiagnosticIntake`.
- [ ] Negative funnel values fail before consumers run.
- [ ] Optional values stay absent rather than fake zero.
- [ ] Targeted gates pass.
