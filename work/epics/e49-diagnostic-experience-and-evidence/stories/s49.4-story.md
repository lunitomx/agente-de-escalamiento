# Story: Scoring explicable y evidencia de cuello de botella

## User Story

As a business leader receiving a diagnostic,
I want to see how each score was calculated and which answers support the focus,
so that I can challenge or trust the recommendation instead of receiving an
opaque lowest-number label.

## Acceptance Criteria

### Scenario: score excludes not-applicable items
```gherkin
Given one applicable score of 5 and one not-applicable item
When the decision score is calculated
Then the score is 5, the denominator is 1, and the N/A item is listed as excluded
```

### Scenario: bottleneck cites evidence
```gherkin
Given evidence for four decisions with execution lowest
When the diagnosis is built
Then focus is execution and the result contains execution evidence IDs and coverage
```

### Scenario: invalid applicable answer fails closed
```gherkin
Given an applicable answer outside the 1–5 range
When scoring runs
Then it raises a validation error instead of silently dropping the answer
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| `execution_q2=2` | score intake | evidence ID appears in execution result |
| `commercial_q6=N/A` | score intake | excluded count increments, no zero |
| `cash_q1=7` | score intake | `ValueError`/validation error |

## Notes

This story is pure scoring; result rendering and action route are S49.5.
