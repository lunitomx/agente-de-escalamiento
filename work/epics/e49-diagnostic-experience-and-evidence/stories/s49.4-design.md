# S49.4 Design

## Approach

Add `coaching/diagnose/explainable.py` with typed `DecisionScore` and
`ExplainableDiagnosis`. Group evidence by explicit decision or the prefix of a
question ID, validate applicable values, calculate decimal averages and
coverage, then choose the lowest score using the existing Four Decisions order.

## Components

| Component | Change |
|-----------|--------|
| `coaching/diagnose/models.py` | Optional decision on evidence plus score/result models |
| `coaching/diagnose/explainable.py` | New pure scoring function |
| `coaching/diagnose/__init__.py` | Export score function/models |
| `coaching/diagnose/tests/test_explainable.py` | Score, N/A, tie, and invalid-value tests |

## Value preservation

The domain value is not arithmetic alone: the result keeps denominator,
coverage, confidence, selection rule, and evidence IDs so a coach can challenge
the focus. Silent omission of an applicable invalid answer is forbidden.
