# Story: Paquete de evidencia opcional

## User Story

As a business leader who wants proof behind a provisional focus,
I want to add only the relevant funnel, context, and source-backed facts,
so that Escala deepens the diagnosis without forcing a mandatory form.

## Acceptance Criteria

### Scenario: targeted intake accepts mixed sources
```gherkin
Given conversation facts, a user estimate, and a CRM export summary
When the evidence pack is built
Then each item retains its source kind, status, and evidence ID
```

### Scenario: optional funnel fields are safe
```gherkin
Given a funnel with blank average sale and populated counts
When the pack is built
Then counts are retained, blank optional values remain absent, and no fake zero is created
```

### Scenario: invalid funnel values fail closed
```gherkin
Given a negative prospect count
When the pack is built
Then validation returns an error before scoring or persistence
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| conversation + estimate | build pack | two evidence items with distinct status |
| no sellers | mark question N/A | excluded from denominator |
| `wins=-1` | build funnel | validation error |
