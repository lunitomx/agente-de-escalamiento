# Story: Walking skeleton de bienvenida conversacional

## User Story

As a business leader opening Escala,
I want one useful question at a time that remembers my answer and routes me to
the right first action,
so that I reach an insight before facing a long diagnostic form.

## Acceptance Criteria

### Scenario: first contact starts with concern
```gherkin
Given no prior Escala session
When the welcome starts
Then it asks one natural concern question and shows no commands or menu
```

### Scenario: specific pain routes directly
```gherkin
Given the user says that sales dropped and cash is tight
When Escala classifies the response
Then it chooses a relevant decision route and asks for only the next context
question
```

### Scenario: returning user gets continuity
```gherkin
Given a previous focus exists
When the welcome starts again
Then it asks whether to continue that focus or address something new
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| first contact | start | one concern question |
| `mis ventas bajaron y no sé cobrar` | respond | Cash route, source question next |
| previous focus `execution` | start | continuity prompt mentioning execution |

## Notes

This is pure conversation state, not a UI framework. Evidence collection is
S49.3; the route target remains internal metadata.
