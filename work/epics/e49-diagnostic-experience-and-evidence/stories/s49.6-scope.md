# S49.6 Scope

## In scope

- Pure profile/OPSP prefill builder with source and freshness.
- Confirmation questions for inferred/stale/unknown values.
- Explicit confirmation transition without filesystem mutation.
- Boundary tests for dates, missing facts, and confirmation IDs.

## Out of scope

- Reading files, writing profile state, hosted sync, and result rendering.

## Done when

- [ ] Prefill returns typed evidence and visible confirmation questions.
- [ ] Stale/inferred values cannot silently enter scoring as facts.
- [ ] Confirmation is deterministic and side-effect free.
- [ ] Targeted gates pass.
