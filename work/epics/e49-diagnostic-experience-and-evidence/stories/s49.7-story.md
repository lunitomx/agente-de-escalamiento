# Story: Dogfood y evidencia de aceptación E49

## User Story

As the Escala product owner,
I want a reproducible synthetic run and comparison receipt,
so that E49 is accepted on observable first value, evidence coverage,
actionability, and local trust rather than on a design claim.

## Acceptance Criteria

### Scenario: end-to-end synthetic run
```gherkin
Given a synthetic concern and evidence pack
When the welcome, intake, scoring, and local export path runs
Then a provisional focus and dated Markdown/JSON result are produced
```

### Scenario: benchmark comparison is bounded
```gherkin
Given the redacted VisionHub structural benchmark
When E49 acceptance is recorded
Then borrowed capabilities, deliberately rejected UX, and remaining gaps are separated
```

### Scenario: local boundary holds
```gherkin
Given the synthetic run
When artifacts are generated
Then no network or hosted submission is required and no raw personal data is stored
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| synthetic cash concern | full path | execution/cash focus with evidence IDs |
| no-seller N/A | score/export | N/A visible, not zero |
| no intake | export | error, no artifact |
