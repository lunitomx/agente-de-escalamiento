# S49.2 Design

## Approach

Implement a small pure state machine in `coaching/welcome/conversation.py`.
Reuse `coaching.decision.engine.classify_area` for the Four Decisions and keep
the user-facing prompt separate from internal route metadata.

## Components

| Component | Change |
|-----------|--------|
| `coaching/welcome/conversation.py` | New Pydantic state/turn and deterministic classifier |
| `coaching/welcome/__init__.py` | Export the conversation entry points |
| `coaching/welcome/tests/test_conversation.py` | Walking-skeleton behavior tests |

## Decisions

- Vague input asks a single narrowing question.
- Specific input routes to one decision; no broad tour.
- Returning context is surfaced before asking for new data.
- Internal route metadata may contain a decision key, but prompts never expose
  slash commands or skill names.
