# S49.4 Scope

## In scope

- Explainable 1–5 decision scores from `DiagnosticIntake` evidence.
- Coverage, denominator, confidence, and supporting evidence IDs.
- Deterministic focus selection with stable Four Decisions tie-break order.
- Fail-closed validation for applicable nonnumeric/out-of-range values.

## Out of scope

- Conversation, file adapters, result Markdown, route planning, and persistence.

## Done when

- [ ] `score_diagnostic` returns typed decision scores and focus evidence.
- [ ] N/A items are excluded and visible.
- [ ] Invalid applicable answers fail before a result is emitted.
- [ ] Targeted gates pass.
