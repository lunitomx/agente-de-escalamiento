# S22.2 — Runtime, instalación y ciclo SQLite local: scope

## In Scope

- Resolver una ruta de base SQLite por proyecto bajo `.scaleup/memory/`.
- Reutilizar los DAOs y esquema existentes de E18 sin servidor HTTP.
- Crear, validar, respaldar y restaurar una base local.
- Proveer un bridge con resultado seguro para que el coach pueda degradar.
- Pruebas unitarias y de integración del ciclo local.

## Out of Scope

- Migrar YAML/Markdown existentes (S22.3).
- Recuperar o confirmar información en conversación (S22.4–S22.6).
- Vectores, embeddings, nube, plugins o sincronización.
- Cambiar dashboards o iniciar `escala_server` como proceso.

## Done when

- Una base se crea y valida sólo bajo la raíz del proyecto indicada.
- Backup/restore conserva registros y no toca rutas globales.
- Un error de almacenamiento se representa como degradación segura.
- Las pruebas demuestran que no se usa `~/.escala` ni HTTP.
