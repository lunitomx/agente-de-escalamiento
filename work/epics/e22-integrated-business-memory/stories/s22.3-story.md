# S22.3 — Migración YAML idempotente

## User story

Como empresario que ya usa ScaleUp con archivos locales, quiero que mi perfil,
diagnóstico, plan y worksheets existentes se incorporen una sola vez a la
memoria SQLite del mismo proyecto, para retomar el trabajo sin perder datos ni
recibir duplicados al actualizar o reinstalar.

## Scenarios

```gherkin
Feature: Migración local de memoria empresarial

  Scenario: migrar una empresa existente por primera vez
    Given una empresa aislada con perfil, diagnóstico, un OPSP y dos worksheets guardados
    And una base `.scaleup/memory/escala.db` saludable
    When ejecuto la migración local
    Then el perfil, diagnóstico, plan y worksheets aparecen con su fuente en SQLite
    And el resumen informa cada artefacto importado o ignorado
    And los YAML y Markdown de origen permanecen intactos

  Scenario: repetir la misma migración
    Given una empresa cuyo snapshot de perfil, diagnóstico, OPSP y worksheets ya fue migrado
    When ejecuto de nuevo la migración sin cambiar los archivos
    Then los conteos de filas de empresa, facts y worksheets no aumentan
    And el resumen informa que los artefactos sin cambio fueron omitidos

  Scenario: migrar un cambio real sin duplicar el estado previo
    Given una empresa con un worksheet ya migrado
    When cambia su contenido guardado y ejecuto la migración
    Then SQLite guarda exactamente una nueva versión de ese worksheet
    And conserva la proveniencia y fingerprint del nuevo snapshot

  Scenario: encontrar una fuente ausente o inválida
    Given una empresa sin un plan, o con un YAML de worksheet inválido
    When ejecuto la migración local
    Then los artefactos válidos se migran
    And el resumen identifica el archivo omitido o fallido sin borrar ni modificar su origen
    And el flujo de ScaleUp puede degradar al comportamiento actual
```

## Examples

Una llamada de implementación futura se limitará a la raíz del proyecto y al
runtime ya creado por S22.2:

```python
result = ProjectMemoryMigrator(project_root).migrate()

assert result.ready is True
# Esta es una segunda ejecución sobre un snapshot ya importado.
assert result.imported == {}
assert result.skipped["work/strategy/opsp.md"] == "unchanged"
assert result.errors == {}
```

El resultado no incluye el contenido de una conversación ni una ruta global:

```python
assert result.db_path == project_root / ".scaleup/memory/escala.db"
assert ".scaleup/agent/memory/conversation.yaml" not in result.sources
```
