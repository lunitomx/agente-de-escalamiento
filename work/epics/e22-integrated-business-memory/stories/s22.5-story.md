# S22.5 — Cierre, hechos y patrones confirmados

## User story

Como empresario que termina o pausa una sesión de ScaleUp, quiero revisar y
confirmar explícitamente cada propuesta de hecho, decisión o patrón antes de
que se conserve en la memoria local, para que mi siguiente sesión tenga
continuidad verificable sin que el sistema convierta sus inferencias en verdad.

## Scenarios

```gherkin
Feature: Confirmación local al cierre de sesión

  Scenario: confirmar dos propuestas explícitas
    Given una raíz de proyecto con SQLite saludable y una sesión local abierta
    And hay una propuesta de decisión "Contratar una líder de ventas"
    And hay una propuesta de fact "El objetivo de septiembre es 1.2 M MXN"
    When la persona responde exactamente "sí" para cada propuesta
    And cierro la sesión
    Then se conservan dos entradas confirmadas, una por propuesta
    And cada entrada conserva tipo, texto aprobado, sesión fuente, fecha y confianza de confirmación
    And la decisión y el fact no modifican los facts migrados ni su ledger

  Scenario: rechazar y dejar ambigua una propuesta
    Given una propuesta de patrón con dos observaciones identificadas
    When la persona responde exactamente "no"
    Then la propuesta queda rechazada y no se crea una entrada confirmada
    When la persona responde "tal vez" a otra propuesta
    Then esa propuesta permanece pendiente y no se cierra la sesión como completada

  Scenario: no convertir una inferencia en memoria
    Given un candidato con fuente "modelo infiere que habrá problema de caja"
    When se intenta proponerlo sin observaciones empresariales explícitas
    Then se rechaza como inválido
    And SQLite no contiene un hecho, decisión ni patrón confirmado adicional
```

## Examples

El bridge futuro recibe una raíz y candidatos estructurados; no recibe ni
analiza la transcripción libre para decidir qué es verdadero:

```python
close = ProjectMemorySessionClose(project_root)
proposal = close.propose(
    session_id="s-2026-08-26-01",
    candidate=MemoryCandidate(
        kind="decision",
        statement="Contratar una líder de ventas en septiembre",
        source=CandidateSource(
            session_id="s-2026-08-26-01",
            observation_ids=("obs-01",),
            origin="explicit_user_statement",
        ),
    ),
)

assert proposal.status == "proposed"
assert close.confirm(proposal.id, answer="sí").status == "confirmed"
assert close.close("s-2026-08-26-01").closed is True
```

Una respuesta que no es afirmación inequívoca no confirma nada:

```python
pending = close.confirm(proposal.id, answer="lo vemos después")
assert pending.status == "proposed"
assert close.close("s-2026-08-26-01").closed is False
assert pending.reason == "confirmation_pending"
```
