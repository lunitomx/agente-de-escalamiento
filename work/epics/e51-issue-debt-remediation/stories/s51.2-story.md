# S51.2: Knowledge References Repair

## User Story
As a user invoking an escala skill, I want the skill to read real knowledge files, so that guidance is based on actual content instead of failing silently.

## Gherkin AC
Feature: Knowledge references are resolvable

Scenario: OPSP skill references existing knowledge
  Given escala-strategy-opsp is invoked
  When it reads the OPSP knowledge file
  Then the file exists and is a YAML source of truth

Scenario: No SKILL.md references a missing knowledge file
  Given all escala-skills SKILL.md files
  When scanned for .escala/knowledge references
  Then every referenced path exists

## SbE Examples
- Reference: `.escala/knowledge/strategy/tools/one-page-strategic-plan.md` → real: `conocimiento/strategy/tools/opsp.yaml`
- Reference: `.escala/knowledge/people/tools/function-accountability-chart.md` → real: `conocimiento/people/tools/face.yaml`
