# S51.1: Welcome Engine Cleanup

## User Story
As a maintainer, I want a single welcome contract, so that onboarding does not break due to conflicting field names.

## Gherkin AC
Feature: Welcome engine contract

Scenario: Onboarding with company_name succeeds
  Given a clean workspace
  When I call coaching.welcome.run with company_name, industry, employees
  Then the profile is created without errors

Scenario: Orphaned engine does not block onboarding
  Given the old engine expected "name"
  When the new code expects "company_name"
  Then there is only one canonical contract

## SbE Examples
- Input: {"company_name": "Acme", "industry": "SaaS", "employees": 15}
- Output: profile with company.name = "Acme"
