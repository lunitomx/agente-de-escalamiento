# S51.3 Scope

## In Scope
- Create `.escala/agent/sub-agents/{strategy,people,execution,cash}.md`.
- Create `.escala/knowledge/{strategy,people,execution}/overview.md`.
- Derive content from `conocimiento/decisions/*.yaml` and existing knowledge nodes.
- Add a regression test verifying the 7 files exist and are non-empty.

## Out of Scope
- Modifying the decision skills themselves (they already reference these files).
- Creating sub-agent/overviews for decisions outside the 4 core decisions.

## Done when
- The 7 files exist and contain meaningful content.
- A test verifies their existence.
- All existing tests pass.
