### T3: Markdown generation + file output (M)

**Goal:** Assemble 5-section markdown document and write to exports path.

**Output file:** `.scaleup/my-company/exports/YYYY-MM-DD-action-plan.md`

**Required sections (exact `##` headers):**
1. `## 1. Diagnosis Scores` — markdown table from YAML scores
2. `## 2. Annual Goal` — verbatim content of `annual-goal.md`
3. `## 3. Active Priorities (Current Quarter)` — verbatim content of `quarterly-focus.md`
4. `## 4. Open Tasks & Commitments` — verbatim content of `tasks.md`
5. `## 5. Next Steps` — generated from priority decision routing (lowest score → recommend command)

**Scores table format:**

| Decision  | Score | Level          |
|-----------|-------|----------------|
| People    | 3     | Emergente      |
| Strategy  | 2     | Ad hoc         |
| Execution | 4     | Establecido    |
| Cash      | 1     | No iniciado    |

**Level mapping:**
- 1 → No iniciado
- 2 → Ad hoc
- 3 → Emergente
- 4 → Establecido
- 5 → Optimizado

**Priority focus:** decision with lowest score → map to `/scaleup-{decision}` command.

**File output:**
- Create `.scaleup/my-company/exports/` directory if it does not exist
- Filename: `{date}-action-plan.md` using `datetime.date.today().isoformat()`
- Include timestamp at header and footer

**Return dict:**
```python
{
    "output": "Export generated: .scaleup/my-company/exports/2026-05-06-action-plan.md",
    "artifacts": {
        "export_path": ".scaleup/my-company/exports/2026-05-06-action-plan.md",
        "sections_included": ["scores", "goal", "priorities", "tasks", "next_steps"],
        "missing_optional": []   # list of filenames that were missing
    },
    "errors": []
}
```

**Files:**
- `coaching/export/__init__.py` (complete implementation)
- `coaching/export/tests/test_export.py` (extended: test markdown structure, 5-section presence, file written)

**Acceptance:**
- All export tests pass (GREEN)
- Output file exists at correct path
- All 5 `##` section headers present in output
- File includes timestamp in header and footer

### T4: Quality gate validator + SKILL.md adapter (S)

**Goal:** Add the export.py quality gate and thin SKILL.md adapter.

**Quality gate (`.scaleup/agent/validators/export.py`):**

Validates the output file has all 5 required section headers:

```python
REQUIRED_SECTIONS = [
    "## 1. Diagnosis Scores",
    "## 2. Annual Goal",
    "## 3. Active Priorities",
    "## 4. Open Tasks",
    "## 5. Next Steps",
]
```

- Reads file path from `sys.argv[1]`
- Prints human-readable errors to stderr: `ERROR: Missing required section: ## 3. Active Priorities`
- Exits with `sys.exit(1)` when any error found, `sys.exit(0)` when valid

**SKILL.md adapter (`.claude/skills/scaleup-export/SKILL.md`):**

Thin wrapper following exact pattern of `.claude/skills/scaleup-diagnose/SKILL.md`:
1. Load context (check prerequisites — project initialized)
2. Invoke core Python: `echo '{"base_path": "."}' | python3 -m coaching.export`
3. Present `result["output"]` to user
4. Handle `result["errors"]` if non-empty
5. Run quality gate: `python3 .scaleup/agent/validators/export.py <export_path>`
6. Show path to generated file

**MUST NOT contain business logic** — adapter is a shell/prompt wrapper only.

**Files:**
- `.scaleup/agent/validators/export.py` (new)
- `.claude/skills/scaleup-export/SKILL.md` (new)

**Acceptance:**
- `python3 .scaleup/agent/validators/export.py <valid-file>` exits 0
- `python3 .scaleup/agent/validators/export.py <invalid-file>` exits 1 with readable errors
- SKILL.md contains no inline business logic
- SKILL.md follows diagnose adapter pattern exactly
