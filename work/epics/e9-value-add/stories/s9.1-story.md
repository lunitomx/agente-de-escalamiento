# S9.1 — Action Plan Export

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-export` and get a shareable markdown document with my current state,
**So that** I can share progress with my leadership team or board.

## Size: M

## Acceptance Criteria

- Export produces a clean markdown document with: current diagnosis scores, annual SMART goal, active priorities, open tasks, next steps
- Document is saved to `.scaleup/my-company/exports/YYYY-MM-DD-action-plan.md`
- Quality gate validates all required fields are present
- Core Python module in `coaching/export/`, adapter in `.claude/skills/scaleup-export/`
- Shareable format: one markdown file, no external dependencies
