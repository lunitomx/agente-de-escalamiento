# S9.4 Scope — Coaching Session Summary

## Story Reference

- **Story ID:** S9.4
- **Epic:** E9 — Value-Add Features
- **Branch:** story/s9.4/coaching-session-summary
- **Size:** S

## In Scope

- `coaching/summary/` core Python module
  - `engine.py` — summary generation logic
  - `formatter.py` — markdown formatting for session log
  - `__init__.py` — public API
- Auto-generate session summary when `/scaleup-close` runs (no user action required)
- Append summary to `.scaleup/my-company/sessions/YYYY-MM-DD.md`
- Summary content includes:
  - Session duration (start → close timestamps)
  - Decisions and worksheets worked on
  - Tasks created and completed during session
  - Score changes (before vs after, if diagnosis ran)
- Integration into existing `scaleup-close` orchestrator skill
- Quality gate validator in `.scaleup/agent/validators/summary_validator.py`
- Adapter SKILL.md update in `.claude/skills/scaleup-close/`

## Out of Scope

- UI changes or visual formatting beyond markdown
- Sending summaries via email or external services
- Retroactive summary generation for past sessions
- Modifying the session log schema from E7

## Done Criteria

- [ ] Summary auto-generated on `/scaleup-close` without user action
- [ ] Session log file written to `.scaleup/my-company/sessions/YYYY-MM-DD.md`
- [ ] Summary includes: duration, decisions, worksheets, tasks, score changes
- [ ] `scaleup-close` validator passes with summary present
- [ ] Core Python module in `coaching/summary/` callable standalone via stdin JSON
- [ ] Existing `scaleup-close` tests still pass (no regression)

## Technical Notes

- Follow E8/E9 cross-platform pattern: core Python + thin SKILL.md adapter
- Session start time tracked from when `/scaleup-start` loads context
- Score changes derived by comparing diagnose data before/after session
- If no diagnosis ran during session, score change section is omitted
- File path: `.scaleup/my-company/sessions/YYYY-MM-DD.md` where date = session start date
- Multiple sessions same day: append with separator (not overwrite)
