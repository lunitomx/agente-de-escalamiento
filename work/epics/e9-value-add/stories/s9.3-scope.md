# S9.3 — Progress Dashboard — Scope

## In Scope

- Core Python module `coaching/dashboard/__init__.py` with `run(context) -> dict`
- `coaching/dashboard/__main__.py` entrypoint (2-line, same pattern as export/pulse)
- Current scores per decision from `.scaleup/agent/memory/` (diagnosis data)
- Historical trajectory from `pulse-history.yaml` (S9.2 output: {pulses: [{date, answers, trends}]})
- Wins: decisions that improved in most recent pulse vs prior (trend == "improving")
- Attention areas: decisions regressing or stagnated across 2+ consecutive pulses
- Markdown dashboard output with: current scores table, pulse history table, wins, attention areas
- Quality gate: `.scaleup/agent/validators/dashboard.py`
- SKILL.md adapter: `.claude/skills/scaleup-dashboard/SKILL.md`

## Out of Scope

- Graphical/ASCII charts (markdown tables only)
- Reading raw session logs from `.scaleup/my-company/sessions/` (use pulse-history.yaml instead — it is the structured source)
- Modifying `coaching/progress/` or any existing coaching module
- External dependencies

## Done When

- `echo '{}' | python -m coaching.dashboard` produces a markdown dashboard
- Dashboard shows current scores + pulse history + wins + attention areas
- Quality gate validates output structure
- All unit tests pass

## Data Sources

| Source | Purpose |
|--------|---------|
| `.scaleup/agent/memory/diagnosis.yaml` | Current scores per decision (People/Strategy/Execution/Cash) |
| `.scaleup/my-company/pulse-history.yaml` | Historical pulse trajectory from S9.2 |

## Output Structure

```markdown
# ScaleUp Progress Dashboard

## Current Scores
| Decision   | Score | Level       |
|------------|-------|-------------|
| People     | X/5   | Established |
| Strategy   | X/5   | Emergent    |
| Execution  | X/5   | Ad hoc      |
| Cash       | X/5   | Established |

## Pulse History
| Date       | People | Strategy | Execution | Cash |
|------------|--------|----------|-----------|------|
| YYYY-MM-DD | X      | X        | X         | X    |

## Wins
- Decision improved since last pulse

## Attention Areas
- Decision regressed or stagnated 2+ consecutive pulses
```

## Architecture

Follows the same cross-platform pattern established in E8:
- `coaching/dashboard/__init__.py` — pure Python, no I/O side effects, returns dict
- `coaching/dashboard/__main__.py` — reads JSON from stdin, calls `run()`, prints markdown
- `.scaleup/agent/validators/dashboard.py` — validates output keys and markdown structure
- `.claude/skills/scaleup-dashboard/SKILL.md` — thin Claude adapter invoking the core module

## Dependencies

- S9.2 (Pulse Check) must be complete — provides `pulse-history.yaml` schema
- `coaching/export/` pattern (S9.1) — reference for module structure
