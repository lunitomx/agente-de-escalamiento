# S9.2 — Quarterly Pulse: Scope

## In Scope

- Core Python module `coaching/pulse/__init__.py` with PulseEngine (`run(context) -> dict`)
- `coaching/pulse/__main__.py` entrypoint
- 5 questions: one per Scaling Up decision (People, Strategy, Execution, Cash) + 1 overall
- Answers: -1 (peor), 0 (igual), +1 (mejor)
- Compare current answers vs previous pulse in pulse-history.yaml
- Trend detection per decision: improving / stalling / regressing
- Course correction suggestions for regressing areas
- Pulse history stored at `.scaleup/my-company/pulse-history.yaml`
- Quality gate: `.scaleup/agent/validators/pulse.py`
- SKILL.md adapter: `.claude/skills/scaleup-pulse/SKILL.md`

## Out of Scope

- Full 26-question re-diagnosis (that's `/scaleup-diagnose`)
- Graphing or visualization (S9.3)
- Modifying existing coaching/ modules
- External dependencies

## Done when

- `echo '{"answers": [-1, 0, 1, 0, 1]}' | python -m coaching.pulse` produces pulse output
- Trend detected correctly vs prior pulse
- History appended to pulse-history.yaml
- All unit tests pass
- Quality gate validates output
