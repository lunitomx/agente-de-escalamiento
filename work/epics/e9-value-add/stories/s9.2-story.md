# S9.2 — Quarterly Pulse

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-pulse` for a quick 5-question re-diagnosis,
**So that** I can track whether I'm improving, stalling, or regressing between full diagnoses.

## Size: M

## Acceptance Criteria

- 5 questions: 1 per decision + 1 overall
- Each answer: -1 (peor), 0 (igual), +1 (mejor)
- Compares scores vs previous pulse
- Detects trends: improving, stalling, regressing per decision
- Suggests course corrections for regressing areas
- Pulse history stored in `.scaleup/my-company/pulse-history.yaml`
- Core Python in `coaching/pulse/`, adapter in `.claude/skills/scaleup-pulse/`
- Completes in under 5 minutes
