## In Scope
- Core Python module `coaching/export/` with ExportEngine class
- SKILL.md adapter in `.claude/skills/scaleup-export/SKILL.md`
- Export produces markdown at `.scaleup/my-company/exports/YYYY-MM-DD-action-plan.md`
- Content: current diagnosis scores, annual SMART goal, active priorities, open tasks, next steps
- Quality gate: validates all required fields present

## Out of Scope
- HTML, PDF, or any format other than markdown
- Email/share integration
- Historical comparison (S9.2 scope)
- Any modification to existing coaching modules

## Done when
- `python -m coaching.export` produces a valid markdown file
- File saved to correct path with correct filename format
- All 5 required sections present (scores, goal, priorities, tasks, next steps)
- Quality gate returns meaningful error if fields missing
- SKILL.md adapter invokes core Python cleanly
