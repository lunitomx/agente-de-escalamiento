# S9.3 — Progress Dashboard

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-dashboard` and see my score history over time,
**So that** I can visualize my trajectory and celebrate wins.

## Size: M

## Acceptance Criteria

- Shows current scores per decision (reuse S8.4 data)
- Shows historical trajectory: score changes over time extracted from session logs
- Flags wins: decisions that improved since last diagnosis
- Flags attention areas: decisions that regressed or stagnated
- Pulls data from session history in `.scaleup/my-company/sessions/`
- Core Python in `coaching/dashboard/` (extends `coaching/progress/`)
- Adapter in `.claude/skills/scaleup-dashboard/SKILL.md`
