# Epic Brief: E9 — Value-Add Features

## Hypothesis

Si agregamos exportación, pulse rápido, dashboard histórico y resúmenes automáticos de sesión, entonces el coaching se vuelve tangible y compartible — el empresario puede mostrar progreso a su equipo y board, y mantener el momentum entre sesiones.

## Success Metrics

| Metric | Target |
|--------|--------|
| Export produces shareable doc | 1 markdown file with all key info |
| Pulse re-diagnosis | < 5 minutos |
| Dashboard histórico | Muestra trayectoria desde session logs |
| Session summary | Auto-generado en cada `/scaleup-close` |
| Cross-platform | Core Python + adapters (mismo patrón E8) |

## Appetite

4 stories (3M + 1S). Todos los datos ya existen en `.scaleup/my-company/` — solo hay que agregarlos, no crearlos.
