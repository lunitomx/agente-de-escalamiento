# S55.2 — Dashboard de evidencia previo al diagnóstico

## Entrega

`coaching.evidence.run` acepta `action: facts_dashboard` y devuelve una vista
local de hechos comparables, hechos explícitamente no comparables y requisitos
pendientes. La salida dice que no es una calificación y el resumen estructurado
no contiene score (`null`).

## Casos verificados

- Ingreso comparable conocido no vuelve a aparecer como pregunta pendiente.
- Gasto marcado no comparable queda fuera de comparaciones.
- Cobros ausentes produce una pregunta explícita.
- La ejecución usa únicamente `base_path/.escala/agent/memory/facts.yaml`.
