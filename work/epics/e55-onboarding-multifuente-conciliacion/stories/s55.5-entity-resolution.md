# S55.5 — Resolución conservadora de entidades

## Entrega y guardrail

La resolución sólo marca `resolved` cuando el tipo de entidad comparte
identificador primario y nombre exacto normalizado. ID igual con nombre distinto
es `ambiguous`; nombre igual sin ID es `unresolved`. Ninguna salida fusiona o
reescribe la entidad.
