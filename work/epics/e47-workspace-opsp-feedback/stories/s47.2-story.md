# S47.2 — Instalador, recursos y migración

## User story

**Como** persona que instala o actualiza ESCALA, **quiero** que el worktree
reciba sólo la configuración segura necesaria para ejecutar RaiSE y que el
instalador no introduzca drift, **para** continuar historias sin copiar bases
SQLite, secretos ni configuración privada.

## Acceptance criteria

### Scenario: Manifiesto seguro en worktree

- **Given** un worktree nuevo registrado por RaiSE
- **When** se propagan los recursos declarados
- **Then** existe `.raise/manifest.yaml` para resolver los gates
- **And** no se propaga `.raise/rai/raise.db` ni un token.

### Scenario: Drift de paquete editable

- **Given** que el aprovisionamiento genera metadata de `escala-coaching`
- **When** Git inspecciona el worktree
- **Then** `*.egg-info/` no aparece como drift de producto.

### Scenario: Compatibilidad de instalación

- **Given** una instalación existente o nueva
- **When** se ejecuta el instalador
- **Then** los recursos locales se preservan y los avisos explican lo que falta
  sin instalar globalmente.
