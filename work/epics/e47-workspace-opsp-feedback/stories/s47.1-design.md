# S47.1 — Diseño: Contrato Workspace Codex/MCP

## Problema y valor

ESCALA declara `rai-workspace` en `.mcp.json`, pero una instalación nueva de
Codex no recibe configuración de proyecto portable. Cuando el CLI de RaiSE
intenta mutar estado global dentro del sandbox, SQLite queda en sólo lectura y
se muestra un traceback en vez de una ruta segura.

El contrato permite continuar por MCP sin ampliar permisos sobre `~/.rai` ni
confundir el límite del sandbox con un error de Jira.

## Gemba y complejidad

Complejidad moderada: instalador, configuración local, guía de agente y pruebas;
sin dependencias nuevas.

- `.mcp.json` declara el servidor, pero no materializa un `config.toml` usable
  en una instalación nueva.
- `install.sh` instala skills y paquete editable, pero no configura MCP ni
  comprueba `rai-mcp-pipeline`.
- El `config.toml` observado es local e ignorado; contiene una ruta de worktree
  y no es distribuible.
- No hay V1 que retirar: este contrato es net-new. El riesgo AG2 se limita con
  un solo configurador; AG4 se mantiene en cuatro archivos.

## Enfoque y decisiones

Crear `scripts/configure_codex_mcp.sh` para renderizar `.codex/config.toml` con
el ejecutable y raíz actuales sólo si no existe. `install.sh` lo invoca si
detecta Codex. `CODEX.md` establece MCP-first ante SQLite read-only. No se
descargan dependencias ni se cambian permisos.

- **S47.1-D1:** MCP-first en Codex; nunca ampliar `~/.rai`.
- **S47.1-D2:** preservar `config.toml` existente.
- **S47.1-D3:** `rai-mcp-pipeline` ausente es advertencia accionable, no
  instalación global automática.

## Ejemplos

```sh
PATH="$fixture_bin:$PATH" ./scripts/configure_codex_mcp.sh /tmp/escala
# escribe /tmp/escala/.codex/config.toml
```

> RaiSE necesita estado escribible y el CLI está restringido por el sandbox de
> Codex. Usa el servidor `rai-workspace` MCP configurado para este proyecto; no
> concedas acceso a `~/.rai`.

## Criterios de aceptación

- [ ] AC-1: instalación limpia crea config con ejecutable resuelto y `--project`.
- [ ] AC-2: config Codex existente no se sobrescribe.
- [ ] AC-3: guía MCP-first para SQLite read-only sin ampliar `~/.rai`.
- [ ] AC-4: ejecutable RaiSE ausente sólo genera advertencia.
- [ ] AC-5: no se agregan tokens, rutas de usuario ni dependencias.

## Riesgos y pruebas

- **AG2:** varios instaladores/superficies podrían duplicar configuración.
  Mitigación: un único configurador y S47.2 inventariará las copias restantes.
- **AG4:** instalador, config y guía están acoplados. Mitigación: cuatro
  archivos, sin almacenamiento o permisos, y pruebas locales.

Pruebas de configurador limpio, no sobrescritura, ejecutable ausente y guía
segura; lint, tipos y pruebas acotadas antes de cada commit.
