# S47.3 — OPSP completo y coherente

## Historia

Como líder de una empresa, quiero construir un OPSP con estructura fiel y
pendientes explícitos para alinear estrategia y ejecución sin que ESCALA
invente datos de mi empresa.

## Criterios de aceptación

### Escenario: modelo completo sin datos inventados

**Dado** un conjunto parcial de respuestas del dueño  
**Cuando** se construye el OPSP  
**Entonces** cada campo faltante permanece como pendiente explícito y se
formula su pregunta de aclaración.

### Escenario: estructura de una página

**Dado** un OPSP  
**Cuando** se valida su esquema  
**Entonces** incluye las siete columnas, filas de Actions/Goals/Targets,
responsables por persona y Key Capabilities de 3–5 años.

### Escenario: semántica coherente

**Dado** el material de estrategia instalado  
**Cuando** una persona consulta el OPSP  
**Entonces** no hay contradicción entre el rango de columnas de ejecución y se
distingue estrategia de ejecución.

## Fuera de alcance

Persistencia, reanudación y exportación se realizan en S47.4.
