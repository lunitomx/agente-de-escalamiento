# Alcance S47.3

## In Scope

- Definir un modelo validado de OPSP de una página: siete columnas, filas
  Actions/Goals/Targets y responsables.
- Incluir Core Values, Core Purpose, BHAG, Sandbox, Brand Promises, Profit per
  X, Key Capabilities a 3–5 años, metas anuales y planificación trimestral.
- Corregir las fuentes de conocimiento instaladas para que la explicación de
  las columnas de ejecución sea consistente.
- Exponer faltantes como pendientes y preguntas; nunca inferir valores de una
  empresa.
- Cubrir el modelo con pruebas unitarias de campos completos, parciales e
  inválidos.

## Out of Scope

- Persistir o exportar el OPSP (S47.4).
- Recopilar contexto de conversación o generar feedback (S47.5).
- Cargar secretos, datos corporativos reales o depender de RaiSE como paquete
  de producto.

## Done when

- El código puede representar y validar un OPSP completo, incluidas filas y
  accountability por persona.
- Las fuentes de estrategia ya no contienen la contradicción de columnas 4–7
  frente a 5–7.
- Las pruebas demuestran que los datos ausentes quedan explícitos.
- La guía instalada apunta a artefactos que existen o declara con honestidad
  que la persistencia pertenece a S47.4.
