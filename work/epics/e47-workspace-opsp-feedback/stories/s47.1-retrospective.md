# Retrospective: S47.1 — Contrato Workspace Codex/MCP

**Fechas:** 2026-08-09 → 2026-08-10

## Summary
Se estableció MCP-first para Codex y se migró `.mcp.json` de configuración rastreada a runtime local por worktree. El instalador preserva configuración existente y nunca amplía acceso a `~/.rai`.

## What went well
- TDD detectó la ausencia del configurador y cubrió rutas con espacios, configuración existente y binario ausente.
- El type gate expuso la dependencia implícita de los validadores; se incorporó el contrato local ya calificado por S47.2, no una ruta ni paquete de RaiSE.

## What to improve
- La recuperación de pipelines con token perdido sigue bloqueada cuando Codex no proporciona identidad de sesión; requiere reparación en RaiSE antes del cierre mecánico.

## Heutagogical Checkpoint
1. **Aprendizaje:** la configuración MCP es estado local y no debe viajar como contenido rastreado.
2. **Proceso:** validar readiness del worktree antes de iniciar implementación evita repetir gates con un runtime equivocado.
3. **Framework:** el provisionador debe aceptar el runtime RaiSE global que él mismo resuelve cuando el producto no lo declara como dependencia.
4. **Capacidad:** ahora se puede distinguir entre aislamiento del producto y runtime de gobernanza sin relajar permisos.

## Improvements applied
- RaiSE acepta el runtime global verificado para `rai-workspace`; mantiene el rechazo de comandos externos arbitrarios.

## Patterns added / reinforced
- Ninguno; el aprendizaje de runtime se conserva en la evidencia de S47.1.
