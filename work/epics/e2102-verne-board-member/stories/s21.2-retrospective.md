# Retrospective: S21.2 — Consulta directa

## Summary

Handler Verne + API endpoints + CLI para consultar a Verne Harnish sobre temas
de negocio. Usa clasificación por keywords, templates por categoría y contexto
del grafo E19.

## What Went Well

- **12 tests nuevos**, todos pasando en 0.03s
- **Clasificación precisa**: cash, people, strategy, execution con fallback a general
- **Sin dependencia externa**: respuestas template-based sin LLM
- Conserva la voz de Verne: preguntas características, principios, llamado a acción
- Sigue el patrón de DI de KnowledgeHandler (GraphEngine injection)

## What Could Be Improved

- Clasificación solo por keywords (sin NLP) — preguntas complejas pueden caer en "general"
- Las entidades del grafo se buscan pero la BD local tiene 0 entidades (nunca se ingirió)
- La respuesta no incluye entidades concretas del grafo cuando no hay datos en la DB

## Decisions

- **D1**: Template-based sobre LLM — evita dependencia externa y costos de API
- **D2**: Clasificación por keywords con fallback a general
- **D3**: Respuesta estructurada fija: diagnóstico → preguntas → principios → llamado a acción

## Patterns

- **PAT-E21-002**: Para handlers de board members, el patrón es: clasificar → buscar contexto → template estructurado
