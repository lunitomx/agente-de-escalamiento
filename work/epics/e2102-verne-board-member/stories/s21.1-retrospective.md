# Retrospective: S21.1 — Alma de Verne

## Summary

Creación del documento fundacional `miembro-board/verne-harnish.md` con la
personalidad, framework y principios de Verne Harnish, basado estrictamente en
el grafo de conocimiento E19 (libro "Scaling Up").

## What Went Well

- **266 líneas** de contenido, cubriendo las 4 Decisiones, Rockefeller Habits,
  preguntas características, lente/sesgos, principios y tabla de trazabilidad
- Cada afirmación tiene origen verificable en una entidad del grafo E19
- Relaciones del grafo usadas para conectar conceptos (e.g., `power-of-one
  --[impacts]--> cash-conversion-cycle`)
- 43 de 42 entidades referenciadas (una entidad FACe aparece dos veces: como
  tool y en tabla de fuentes)

## What Could Be Improved

- No se pudo verificar contra el texto original del libro (el .md fuente no
  está en el repo local), solo contra el grafo estructurado
- Algunas descripciones de entidades están vacías (solo name + keywords + type)
  — el alma usa los keywords para inferir contexto

## Decisions

- El alma se escribió como documento markdown independiente, no como código
- Se incluyó una tabla de trazabilidad detallada (fuente: entidad ID) para
  garantizar que cualquier afirmación pueda verificarse
- La carpeta `miembro-board/` se creó en raíz del proyecto para futuros miembros
  del board (Hormozi, Collins, etc.)

## Patterns

- **PAT-E21-001**: Para almas de board members, la estructura es: Identidad →
  Framework → Preguntas → Lente/Sesgos → Principios → Voz → Fuentes
