# S21.3 — Revisión de dailys

## Scope

Verne puede recibir un resumen de daily huddle (texto o JSON) y dar observaciones
consistentes con los Rockefeller Habits.

## Acceptance Criteria

- [ ] Método `review_daily` en VerneHandler que analiza un daily
- [ ] Detecta presencia/ausencia de elementos clave del daily huddle (logros, planes, obstáculos)
- [ ] Da observaciones específicas basadas en los Rockefeller Habits
- [ ] Endpoint `POST /api/verne/review-daily`
- [ ] CLI `escala verne review-daily`
- [ ] Tests: daily completo ✅, daily incompleto con recomendaciones
