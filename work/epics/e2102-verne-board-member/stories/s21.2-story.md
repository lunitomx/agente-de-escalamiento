# S21.2 — Consulta directa

## Scope

Crear el handler, endpoints API y CLI para que Verne responda a consultas directas
del tipo "Verne, ¿qué opinas de X?" usando el alma documentada (S21.1) y el grafo
de conocimiento (E19).

## Acceptance Criteria

- [ ] `VerneHandler` implementado en `escala_server/verne_handler.py`
- [ ] Lee el alma desde `miembro-board/verne-harnish.md`
- [ ] Consulta el grafo de conocimiento para contexto relevante a la pregunta
- [ ] Endpoint `POST /api/verne/ask` acepta `{question: string, context?: object}`
- [ ] Endpoint `GET /api/verne/ask?q=...` para consultas simples
- [ ] CLI `escala verne ask "pregunta"`
- [ ] Respuestas son coherentes con el libro (usan framework de Verne)
- [ ] Respuestas incluyen referencias a entidades del grafo donde aplica
