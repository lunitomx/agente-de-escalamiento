# Epic Brief: E28 — Instalación Portátil y Runtime Visual

**Issues:** #1, #2

ScaleUp debe instalar y servir su experiencia visual completa en macOS, Linux,
Claude, Codex y Hermes. Hoy BSD sed bloquea macOS y el instalador omite el
servidor HTTP, API y estáticos necesarios para los paneles.

La épica entrega una instalación portable y verificable; no rediseña los
dashboards ni inventa datos de empresa.
