# Story: Historial, evaluación y recuperación

## User Story

Como empresa, quiero que la cadencia sea útil varias semanas sin exponer datos
ni romper el plan existente.

## Scope

- Historial local resumido, edición/borrado y recuperación selectiva.
- Fixtures de varias semanas, DST/zona horaria, pausa y plan cambiado.
- Smoke E2E y documentación de límites.

## Acceptance Criteria

- [x] Historial no duplica revisiones al reabrir sesión.
- [x] Cambio de prioridad preserva historia y pide reconciliación.
- [x] Pruebas cubren omitir, pausar, reanudar y revisión vencida.
- [x] Instalación limpia Claude/Codex conserva recorrido no técnico.

## Out of Scope

Analítica remota de productividad.
