# Story: Sugerencias de recordatorio nativo del host

## User Story

Como usuario, quiero saber si mi cliente puede recordarme la revisión sin que
ScaleUp acceda a mis cuentas ni prometa automatización inexistente.

## Scope

- Capacidades declaradas por Claude/Codex, sin adivinarlas.
- Explicar creación de recordatorio nativo si hay ruta soportada.
- Degradar a revisión al abrir ScaleUp si no existe capacidad.

## Acceptance Criteria

- [x] Nunca pide credenciales ni conserva datos de Calendar.
- [x] No asegura notificación creada sin confirmación del host.
- [x] Recomendación incluye propósito, frecuencia y cómo desactivarla.
- [x] Host no compatible conserva cadencia local.

## Out of Scope

OAuth, APIs Calendar y ejecución de conectores.
