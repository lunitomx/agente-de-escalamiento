# Story: Alta de revisión semanal tras Welcome

## User Story

Como nuevo usuario, quiero elegir una cadencia semanal sólo cuando ya entiendo
mi meta y sin configurar herramientas técnicas.

## Scope

- Oferta contextual después de Welcome/plan, nunca obligatoria.
- Día, zona horaria, duración y primer compromiso.
- Confirmación, vista de configuración y salida sencilla.

## Acceptance Criteria

- [x] Omitir deja intacto el flujo normal.
- [x] La propuesta explica qué ocurrirá al abrir la siguiente sesión.
- [x] El compromiso enlaza prioridad o pide crearla.
- [x] No menciona cron, APIs ni comandos.

## Out of Scope

Revisión de semana o conectores.
