# Story: Conversación de revisión y siguiente acción

## User Story

Como líder, quiero revisar la semana anterior y salir con una siguiente acción
realista que acerque a mi empresa a su prioridad.

## Scope

- Detectar revisión pendiente al abrir y permitir posponerla explícitamente.
- Preguntar resultado, aprendizaje/bloqueo y revisar listas GTD.
- Cerrar, delegar, diferir o descomponer el compromiso.
- Proponer una siguiente acción y confirmar antes de guardarla.

## Acceptance Criteria

- [x] Resultado no logrado no se marca como éxito ni se penaliza.
- [x] Bloqueo crea waiting-for o pide decisión, no tarea falsa.
- [x] Siguiente acción confirmada vincula prioridad/proyecto/dueño.
- [x] Recupera sólo historia relevante de semanas previas.
