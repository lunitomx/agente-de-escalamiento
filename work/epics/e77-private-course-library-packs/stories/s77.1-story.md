# S77.1 — Contrato local de fuente y derechos

## User story

Como dueño de una empresa que aporta un curso propio o autorizado, quiero registrar su procedencia, derechos y límites locales antes de que ESCALA lo procese, para que ningún contenido privado o sin permiso se convierta por accidente en conocimiento instalable.

## Acceptance scenarios

```gherkin
Scenario: fuente autorizada y verificable
  Given un archivo local con hash, propietario y permiso de uso local
  When se registra su manifiesto
  Then el sistema puede dejarla en estado candidate
  And no exporta el contenido ni sus derivados

Scenario: permiso ausente
  Given una fuente sin declaración de derechos
  When se solicita curarla o compilarla
  Then el sistema la bloquea de forma fail-closed
  And explica qué evidencia falta

Scenario: transcripción ruidosa
  Given una transcripción sin timestamps ni revisión humana
  When se ingesta
  Then sólo puede producir candidatos de revisión
  And no puede producir reglas, fórmulas, citas o un pack instalable
```

## Constraints

- Todo contenido y sus localizadores viven fuera de Git y del export público.
- El contrato conserva sólo metadatos mínimos, hash, estado y decisiones de revisión.
- No se agrega un comando público ni se instala un mini-agente visible al empresario.
