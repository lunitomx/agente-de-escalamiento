# S77.1 — Diseño: contrato local de fuente y derechos

## Problema y valor

E57 cubre una metodología de terceros concreta con derechos todavía no
resueltos. No puede representar con precisión un curso que un empresario aporta
para uso local, ni impedir que una transcripción ruidosa se convierta en
conocimiento instalable.

S77.1 agrega un contrato mínimo y fail-closed: permite curar después sólo
fuentes autorizadas, sin que contenido crudo, títulos, rutas o permisos
detallados lleguen a Git, al export público o a una nueva superficie de
comandos.

## Decisiones

1. La biblioteca vive sólo en `.scaleup/course-library/`, ignorada por Git y
   fuera del export.
2. La promoción exige permiso de uso local documentado, hash, retención,
   revisión humana y captura original o transcripción revisada.
3. Los recibos son acotados: id seguro, estado, motivo y hashes; nunca texto,
   título, autor o ruta.
4. Es un contrato net-new. No altera ni generaliza `SourceAuthority` de E57,
   que sigue siendo la autoridad de la fuente metodológica base.

## Componentes

| Componente | Cambio | Propósito |
|---|---|---|
| `validators/course_source.py` | Crear | Contrato local, validación y recibos seguros. |
| `tests/test_course_source.py` | Crear | Fixtures sintéticos, fallos cerrados y no filtración. |
| `.gitignore` | Modificar | Excluir biblioteca local y packs privados. |

## Ejemplos

```python
decision = promotion_decision(noisy_manifest)
assert decision.status == "blocked"
assert decision.reason == "capture_not_reviewed"
```

El manifiesto de prueba autorizado usa únicamente identificadores y hashes
sintéticos. El curso real nunca se incluye en el repositorio.

## Criterios de aceptación

- Una fuente local autorizada, con hash, retención y captura revisada queda
  como candidata local, no como contenido exportable.
- Falta de permiso, hash, retención o revisión bloquea con motivo estable.
- Una transcripción ruidosa o sin timestamps no promueve reglas, fórmulas,
  citas ni packs.
- Git ignora la biblioteca y los recibos no filtran título, autor, ruta ni
  texto.
- No se instala skill, agente, MCP o comando público.

## Riesgos y prueba

- **AG2:** no duplicar E57; el modelo de cursos tiene semántica separada y sólo
  comparte convenciones seguras.
- **AG4:** no anticipar E65/E67; este contrato decide elegibilidad, no compila
  capacidades.
- Pruebas unitarias, de privacidad y de ciclo sintético validan el
  comportamiento.

## Dependencias

E57/E58 habilitan este contrato. E65/E67/E68 siguen bloqueando la compilación,
el empaquetado, el piloto BlackSeller y el cierre de E77.
