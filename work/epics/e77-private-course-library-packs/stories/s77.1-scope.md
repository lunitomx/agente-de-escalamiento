# Scope S77.1

## In Scope

- Esquema local y validación fail-closed de manifiesto de fuente de curso.
- Consentimiento/propiedad, hash, retención, calidad de captura y estados permitidos.
- Límites explícitos para export, compilación y tipos de afirmación según la evidencia.
- Fixtures estrictamente sintéticos y pruebas positivas/negativas.

## Out of Scope

- Guardar o versionar el curso BlackSeller, cualquier transcripción o archivo aportado.
- Curar candidatos, compilar procedimientos E65 o activar packs.
- Resolver derechos con una inferencia del modelo o asesoría legal.

## Done when

- Una fuente sin permiso, hash o retención queda bloqueada.
- Una transcripción sin timestamps/revisión no puede promover reglas ni packs.
- Un manifiesto autorizado permite sólo uso local y conserva límites de export.
- Las pruebas demuestran que no se guarda contenido crudo ni un localizador sensible.
