no ingesta BlackSeller, no crea skills ni cambia la autoridad E57: sólo entrega

## Orden y riesgos

La prueba de privacidad va primero porque define el comportamiento observable;
después se implementa la mínima custodia y al final se verifica integración. El
riesgo mayor es mezclar E57 con el curso; se mitiga con un módulo nuevo,
fixtures sintéticos y una prueba explícita de que no hay activación pública.

| Riesgo | Mitigación |
|---|---|
| Contenido local entra a Git | `.gitignore` dedicado y prueba con `git check-ignore`. |
| Transcripción no fiable se promueve | decisión de promoción deny-by-default. |
| Recibo revela detalles de curso | prueba de redacción con valores sentinela. |
