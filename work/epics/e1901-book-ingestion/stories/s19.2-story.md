# Story: Entity Ingest — Poblar el Grafo desde el Parser

## User Story
As the Escala system,
I want to ingest the parsed book entities into the GraphEngine,
so that the knowledge becomes queryable through the existing graph API.

## Done Criteria
- [ ] All 42 entities from book-knowledge.json are ingested into GraphEngine
- [ ] All 59 relationships are created between entities
- [ ] Entity properties include description, keywords, line_refs, chapter_ids
- [ ] Ingest script is idempotent (rerunnable without duplicates)
- [ ] Tests verify entities and relationships exist in the graph
