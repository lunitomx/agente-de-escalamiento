# Story: Strategy and Four-Decision Coaching

## User Story

Como empresario,
quiero que el agente me ayude a construir mi visión/OPSP y me lleve al skill correcto,
para convertir el diagnóstico en una conversación concreta sin que complete huecos por mí.

## Acceptance Criteria

### Scenario: partial OPSP
```gherkin
Given owner answers for purpose, BHAG, customer and brand promise but no Critical Number
When build_strategy_plan runs
Then the answers are retained, the plan is partial and Critical Number is unresolved
```

### Scenario: explicit route
```gherkin
Given a supported diagnostic and an explicit Cash request
When route_coaching runs
Then it returns /escala-cash with a rationale grounded in the request and evidence state
```

### Scenario: unsupported route
```gherkin
Given no supported evidence for People
When route_coaching requests People
Then supported is false and the route asks a material question instead of claiming a diagnosis
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| `purpose`, `bhag`, `brand_promise` supplied | `build_strategy_plan` | fields retained, unresolved includes `critical_number` if absent |
| explicit decision `cash` | `route_coaching` | `skill=/escala-cash`, supported when cash evidence exists |
| missing People evidence | `route_coaching` | `supported=False`, question requests evidence/owner answer |

## Notes

The route reuses the existing command vocabulary from `coaching.router` and `escala-skills`; this story does not run a sub-agent or call a network service.
