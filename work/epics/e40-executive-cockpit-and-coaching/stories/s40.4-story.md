# Story: Persistent Execution and Honest Guidance

## User Story

Como director,
quiero que mis objetivos, prioridades, tareas y continuidad sobrevivan una sesión local,
para que el agente me ayude con contexto real y me diga claramente qué es hecho, inferencia o desconocido.

## Acceptance Criteria

### Scenario: local execution round trip
```gherkin
Given goals, priorities, tasks, owners, due dates and progress
When save_execution_state writes to the installer data root and load_execution_state reads it
Then the same state is queryable after the write and the exchange remains untouched
```

### Scenario: material uncertainty
```gherkin
Given a guidance request with facts, inferences and an unknown Cash Conversion Cycle
When build_honest_guidance runs
Then it labels all three states and asks a material question instead of filling the CCC
```

### Scenario: invalid local authority
```gherkin
Given the configured database is inside the exchange folder
When save_execution_state runs
Then it fails before writing the derived state
```

## Examples

| Input | Action | Expected Output |
|-------|--------|-----------------|
| Goal `g1`, owner `Ana`, due `2026-08-01`, progress 40 | `save_execution_state` | round-trip state preserves fields |
| unknown `cash_conversion_cycle` | `build_honest_guidance` | `evidence_limited`, question present |
| `database_path=exchange/shared.sqlite` | `save_execution_state` | `WorkspaceAuthorityError` |

## Notes

The state is a deterministic derived JSON snapshot below `data_root`; the authoritative local SQLite remains governed by E37. No cloud sync or OS scheduler is added here.
