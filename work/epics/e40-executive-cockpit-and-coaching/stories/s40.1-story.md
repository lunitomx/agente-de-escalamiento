# Story: Guided Onboarding and Diagnostic

## User Story

Como empresario,
quiero responder preguntas sobre mi empresa y recibir un diagnóstico 0–100 de las cuatro decisiones,
para saber qué se conoce, qué falta y cuál es el principal dolor sin que el agente invente información.

## Acceptance Criteria

### Scenario: validated profile with supplied answers
```gherkin
Given owner answers for company_name, industry, stage and employees
When build_company_profile validates the answers
Then it returns a typed profile with fact fields and no machine paths
```

### Scenario: missing or ambiguous field
```gherkin
Given the owner omits critical_number and marks stage as uncertain
When build_company_profile runs
Then the fields remain unknown and bounded clarification questions are returned
```

### Scenario: evidence-backed four-decision diagnostic
```gherkin
Given supplied evidence-backed answers for people, strategy, execution and cash
When build_diagnostic aggregates them
Then it returns one deterministic 0–100 assessment per decision with evidence and freshness
```

### Scenario: no evidence is not a negative diagnosis
```gherkin
Given no answer or source exists for cash
When build_diagnostic runs
Then cash is evidence_limited with a material question, not an invented zero or failure claim
```

## Examples (Specification by Example)

| Input | Action | Expected Output |
|-------|--------|-----------------|
| `Nopal Foods`, 28 employees, `industry=food` | `build_company_profile(...)` | `profile.status=ready`, required facts preserved |
| `cash` answer 42 with `source_id=fin-001` | `build_diagnostic(...)` | `cash.score=42`, `evidence_status=supported` |
| missing `strategy` answers | `build_diagnostic(...)` | `strategy.score=None`, `evidence_limited`, bounded question |
