# S40.3: Strategy and Four-Decision Coaching — Design

## Complexity

Complex: strategy has eight partial fields and routing depends on diagnostic evidence, but it remains pure local transformation with no persistence.

## Gemba and legacy sweep

`escala-skills/escala-strategy-opsp/SKILL.md` defines the expected OPSP sections and ordering. `coaching.router` defines command names and deterministic lowest-score routing, but it uses 1–5 dictionaries and cannot distinguish unsupported evidence. E40 will preserve its command vocabulary while adding typed strategy fields and support status; no legacy skill is replaced.

## Approach

`build_strategy_plan` maps declared owner answers into a stable partial OPSP and emits unresolved keys for missing/uncertain fields. `route_coaching` honors an explicit decision, otherwise selects the lowest supported score from the diagnostic. It returns a skill command, rationale, evidence status and questions; unsupported or evidence-limited targets return `supported=False` and never produce a claim about company performance.

## Concrete examples

```python
plan = build_strategy_plan((
    StrategyAnswer(key="purpose", value="hacer accesible la comida sana", status="fact"),
    StrategyAnswer(key="bhag", value="100 tiendas en 10 años", status="fact"),
))
assert plan.status == "needs_clarification"
assert "critical_number" in plan.unresolved

route = route_coaching(CoachingRequest(decision="cash"), diagnostic)
assert route.skill == "/escala-cash"
assert route.supported is True
```

## Acceptance criteria

### MUST

- Strategy fields are retained as owner answers with explicit unknown/inference states.
- Missing material sections remain unresolved and ask bounded questions.
- Routes use exactly the four existing skill commands and include evidence status/rationale.
- Unsupported requests return `supported=False` and clarifying questions.

### MUST NOT

- Fill an OPSP value from a generic template or infer sentiment/personality.
- Create a new route outside People, Strategy, Execution and Cash.
