# Epic Scope: E30 — Accountability Empresarial Longitudinal

**Status:** Complete
**Dependencies:** E22 (memoria), E24 (cadencia), E25 (conectores/privacidad), E26 (workspace)
**Tamaño:** XL

## Outcome

Una persona puede preparar, revisar y aprender de sus Accountability Groups en
lenguaje natural. Cada sesión y compromiso conserva fuente, fecha, evidencia y
consentimiento; los patrones son determinísticos, explicables y corregibles.

## Stories

1. S30.1 — Ingesta consentida de worksheets históricos.
2. S30.2 — Preparación guiada de una sesión de Accountability.
3. S30.3 — Compromisos y revisión con rúbrica explicable.
4. S30.4 — Patrones longitudinales con evidencia.
5. S30.5 — Lenguaje natural, resumen visual e instalación portable.

## Acceptance criteria

- [x] Un documento se previsualiza y advierte datos delicados antes de guardar.
- [x] La entrevista conserva actualización personal/negocio, asunto, pilar,
  contexto, opciones, preguntas profundas y resultado deseado.
- [x] Todo compromiso tiene una persona, fecha y medida de éxito.
- [x] La revisión usa resultado/evidencia/plazo/aprendizaje; cualquier porcentaje
  es derivado y muestra sus razones, nunca una impresión 1–5.
- [x] Los patrones citan al menos dos sesiones o se presentan como observación única.
- [x] La persona puede corregir o excluir sesiones y reconstruir el análisis.
- [x] El flujo funciona desde el único skill público y en Claude/Codex/Hermes.

## Fuera de alcance

- Sincronización automática o escritura en Google Drive.
- Importación silenciosa de carpetas o documentos.
- Diagnóstico psicológico a partir de actualizaciones personales.
- Presentar correlación como causalidad o inferencias del modelo como hechos.
