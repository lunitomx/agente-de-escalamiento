# Story: Motor de contexto y recuperación

## User Story

Como asesor, quiero combinar contexto empresarial con evidencia selectiva sin
cargar el libro completo.

## Scope

- Normalizar texto, `SessionContext`, worksheets y memoria.
- Clasificar cuatro decisiones con override explícito.
- Construir `EvidencePacket v1` mediante `KnowledgeHandler`.
- Deduplicar/limitar evidencia y registrar gaps/warnings.
- Mantener texto empresarial como dato no ejecutable.

## Acceptance Criteria

- [x] Fixtures de las cuatro decisiones recuperan evidencia trazable.
- [x] Override prevalece sobre clasificación automática.
- [x] Referencias preservan líneas/capítulos disponibles.
- [x] Relaciones SQLite no presentan provenance inexistente.
- [x] DB vacía y tool desconocida producen packet válido con gaps.
- [x] Misma entrada/base genera salida determinística.
- [x] Instrucción maliciosa dentro de un daily no cambia reglas.
- [x] Packet respeta límite configurable de contexto.

## Out of Scope

Embeddings, web o redacción conversacional final.

## Evidence

Tests con DB temporal E19, adversariales y snapshots no sensibles.
