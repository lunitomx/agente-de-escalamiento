# Story: Ciclo de sesión y distribución

## User Story

Como usuario, quiero invocar el asesor e incorporarlo opcionalmente a una sesión
sin romper el flujo existente.

## Scope

- Crear skill `scaleup-board-verne` con daily/consult.
- Agregar hooks opt-in a inicio/cierre.
- Adjuntar resultado/versiones a metadata.
- Distribuir/adaptar runtime para Claude/Hermes.
- Actualizar tests/manifiestos rígidos de E10.

## Acceptance Criteria

- [ ] Feature off conserva start/close actuales.
- [ ] Feature on recibe `SessionContext` y produce respuesta válida.
- [ ] Fallo/timeout advierte y no impide cierre.
- [ ] Metadata conserva versiones de schema/profile.
- [ ] Instalación aislada incluye runtime, perfil y skill.
- [ ] Claude/Hermes descubren el mismo skill y runtime.
- [ ] Bundles son equivalentes desde proyectos vacíos.

## Out of Scope

Activación por defecto, Codex, PyPI o telemetría remota.

## Evidence

E2E temporal on/off y descubrimiento oficial sin consumir modelo.
