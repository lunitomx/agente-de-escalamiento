# Story: Revisión de daily y consulta directa

## User Story

Como líder, quiero preguntas y próximos pasos fundamentados para un daily o una
decisión.

## Scope

- Implementar `daily_review` y `decision_consult`.
- Generar/validar `BoardResponse v1`.
- Renderizar Markdown con disclosure, evidencia, inferencias y límites.
- Exponer interfaz Python y CLI local.

## Acceptance Criteria

- [x] Ambos modos retornan el mismo esquema versionado.
- [x] Daily review limita a tres observaciones priorizadas.
- [x] Observaciones/acciones cumplen invariantes de referencias.
- [x] Salida distingue evidencia, dato e inferencia.
- [x] Sin datos formula preguntas y muestra limitaciones.
- [x] No suplanta al autor ni afirma respaldo.
- [x] No ejecuta acciones ni muta DB/archivos.
- [x] CLI falla solo ante entrada o contrato inválido.

## Out of Scope

Hooks de sesión o llamadas remotas a modelos.

## Evidence

Golden tests de ambos modos/cuatro decisiones y prueba de no mutación.
