# Story: Perfil metodológico y contrato de evidencia

## User Story

Como usuario, quiero distinguir evidencia, datos de empresa e inferencias.

## Scope

- Crear `miembro-board/verne-harnish.md` desde E19.
- Incluir disclosure, atribución, límites, cuatro decisiones y fallback.
- Definir `CompanyFact`, `EvidenceRef`, `AdviceItem`, `EvidencePacket` y
  `BoardResponse`.
- Crear validadores de perfil y contratos.

## Acceptance Criteria

- [x] Perfil declara que es sintético, no afiliado y no representa al autor.
- [x] Las cuatro decisiones tienen evidencia por nombre, líneas y capítulos.
- [x] Validador rechaza perfil sin disclosure, límites o categoría.
- [x] `source_summary` sin evidence es inválido.
- [x] Observación sin facts/evidence es inválida.
- [x] Inferencia válida queda marcada y conserva referencias.
- [x] Contratos serializan/deserializan sin pérdida.

## Out of Scope

Generar consejos, integrar sesiones o crear el skill.

## Evidence

Tests unitarios y mapa perfil → entidades E19 resolubles.
