# S58.1 — Schema y vocabulario

## Objetivo

Definir una ontología v2 privada, tipada y determinista antes de migrar activos
E6 o extraer unidades de conocimiento.

## Criterios de aceptación

- JSON Schema cubre nodo, relación, alias y decisión de revisión.
- Vocabulario enumera las dieciséis clases, seis orígenes y cuatro estados.
- Los nodos derivados exigen evidencia; una síntesis aprobada exige dos fuentes.
- El contrato no contiene corpus ni locators privados.
- El schema versionado coincide byte a byte con el generador tipado.
