# S58.2 — Origen, evidencia y revisión

## Objetivo

Separar de forma verificable los candidatos de conocimiento aprobado y exigir
procedencia suficiente para toda decisión de promoción.

## Criterios de aceptación

- Cada candidato conserva un nodo propuesto y preguntas no resueltas.
- Ningún candidato usa un estado terminal dentro de la cola.
- Una aprobación requiere evidencia; una decisión sólo apunta a un candidato.
- La cola canónica puede estar vacía y su CLI no expone corpus.
