# S29.3 — .gitattributes + limpieza de fin de línea

**Epic:** E29 — Simplificación y Orden
**Size:** S (15 min)
**Status:** Draft

## Objetivo

Crear `.gitattributes` para forzar consistencia de fin de línea (LF) en todos los archivos de texto del proyecto. Evitar diffs spurios por diferencias CRLF/LF entre macOS y otros sistemas.

## Archivos

- `.gitattributes` (nuevo)

## Contenido

```
# Auto-detect text files, normalize to LF
* text=auto

# Explicit LF for source files
*.py text eol=lf
*.yaml text eol=lf
*.yml text eol=lf
*.md text eol=lf
*.toml text eol=lf
*.json text eol=lf
*.html text eol=lf
*.css text eol=lf
*.js text eol=lf
*.sh text eol=lf

# Binary files
*.db binary
*.png binary
*.jpg binary
*.jpeg binary
*.gif binary
*.ico binary
*.woff binary
*.woff2 binary
*.pyc binary
```

## Pasos

1. Crear `.gitattributes`
2. Ejecutar `git add --renormalize .`
3. `git status` — verificar que no hay cambios spurios
4. Si hay cambios, commit con mensaje `chore: normalize line endings`

## Criterios de Aceptación

- [ ] `.gitattributes` existe
- [ ] `git status` limpio tras renormalize
- [ ] Archivos YAML no muestran diffs de whitespace en futuros commits
