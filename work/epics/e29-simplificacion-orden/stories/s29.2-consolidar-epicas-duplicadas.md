## Objetivo

Eliminar la ambigüedad de tener 10 directorios para 5 épicas. Mover las versiones no-canónicas a un archivo `_archived/`.

## Pasos

1. Para cada par, determinar canónica: la que tiene retrospectiva (`retrospective.md` o stories con `-retrospective.md`)
2. Si ambas tienen retrospectiva, mantener la que tiene el close commit en main
3. Mover no-canónica a `work/epics/_archived/E{N}-{nombre}/`
4. Reconstruir graph: `rai graph build`
5. Verificar 0 warnings de duplicados

## Criterios de Aceptación

- [ ] 5 directorios movidos a `_archived/`
- [ ] `ls work/epics/ | grep -c "e18"` devuelve 1 (y similar para e19-e22)
- [ ] `rai graph build` sin warnings de `Duplicate node ID`
- [ ] `_archived/` tiene README explicando qué son
