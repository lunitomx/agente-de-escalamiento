# S87.3 · Alcance

## In Scope

- Correr `/rai-research` una vez por cada una de las 8 herramientas de la lista de la historia.
- Escribir 8 archivos en `work/research/e87-tips/`, uno por herramienta, con nombres estables para citar:
  `bmc.md`, `strategy-canvas.md`, `brand-promise.md`, `core-customer.md`,
  `differentiating-activities.md`, `sandbox.md`, `vision-summary.md`, `oppp-vision-boards.md`.
- Cada archivo: hallazgos numerados con ancla (`#f1`, `#f2`…), cada uno con sus fuentes y su estado (triangulado o no).
- Al menos 3 hallazgos triangulados (3+ fuentes independientes) por archivo.
- Citas al workbook solo como paráfrasis en español con número de página.

## Out of Scope

- Escribir hojas, tarjetas o el campo `tips:` en `conocimiento/` (eso es S87.4 a S87.9).
- Código del motor de hojas, la vista HTML o el skill `escala-worksheet` (S87.2).
- El mapa de cobertura y la lista `pending` (S87.1).
- Strategy Canvas de Océano Azul como herramienta.
- Imágenes, PDF o texto copiado del workbook.

## Done when

- `ls work/research/e87-tips/*.md` muestra 8 archivos.
- Cada archivo tiene al menos 3 hallazgos marcados como triangulados, cada uno con 3 fuentes o más.
- Ningún archivo trae imágenes ni texto copiado del workbook.
- `uv run rai gate check --all` pasa.
