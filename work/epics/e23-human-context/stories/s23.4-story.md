# Story: Integración y evaluación de privacidad

## User Story

Como empresa, quiero comprobar que el contexto humano no degrada privacidad ni
el recorrido de quien no quiere compartirlo.

## Scope

- Matriz omitir, consentir, corregir, borrar y dato delicado.
- Smoke desde instalación limpia en Claude Code y Codex.
- Documentación de límites, retención y control.

## Acceptance Criteria

- [x] Regresiones de Welcome, memoria y diagnóstico verdes.
- [x] Casos sensibles no se guardan ni recuperan.
- [x] Smoke cubre omitir y una personalización confirmada.
- [x] Inventario sólo marca Complete con evidencia verificable.

## Out of Scope

Cerrar E23 sin pruebas de instalación.
