# Story: Conversación voluntaria posterior a Welcome

## User Story

Como persona no técnica, quiero personalizar la ayuda sin revelar información
privada ni quedar bloqueada si no deseo hacerlo.

## Scope

- Invitación clara tras Welcome y entrada posterior por lenguaje natural.
- Una pregunta útil por turno, con saltar y detener disponibles.
- Propuesta legible y confirmación antes de persistir cada campo.

## Acceptance Criteria

- [x] “Ahora no” continúa hacia diagnóstico/plan sin fricción.
- [x] Cada pregunta explica para qué serviría la respuesta.
- [x] Respuesta delicada recibe advertencia y versión generalizada.
- [x] No muestra rutas, comandos ni jerga técnica.

## Out of Scope

Recordatorios semanales o conectores externos.
