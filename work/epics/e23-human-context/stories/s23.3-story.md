# Story: Gestión y recuperación mínima

## User Story

Como líder, quiero revisar, cambiar o borrar mi contexto y que ScaleUp use sólo
lo pertinente para ayudarme.

## Scope

- Acciones naturales de ver/cambiar/borrar.
- Recuperación selectiva por caso de uso y trazabilidad de consumo.
- Degradación con perfil ausente, incompleto o borrado.

## Acceptance Criteria

- [x] El resumen es entendible y no muestra metadatos internos.
- [x] Cambio y borrado son idempotentes y sobreviven otra sesión.
- [x] Contexto no pertinente no llega a una consulta.
- [x] Perfil faltante no rompe coaching, E24 ni E21.

## Out of Scope

Colaboración multiusuario.
