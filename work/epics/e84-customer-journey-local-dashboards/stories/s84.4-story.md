# S84.4 — "Sí, ármalo" deja un tablero en la computadora del dueño

## Objetivo

Cuando el dueño acepta una propuesta, ESCALA arma el tablero con sus números
locales (también los del recorrido del cliente), lo guarda como un HTML que se
lee en el teléfono y su gemelo Markdown en `.escala/my-company/tableros/`, y
muestra el Markdown en el chat. Lo que falta dice «Falta» y cómo conseguirlo.
Sin un solo número no se arma nada. Nunca se publica.

## Alcance (design.md § S84.4, U2)

- `coaching/dashboard/boards/render.py`: `Board`, `build_board`,
  `render_html`, `render_markdown`, `save_board` (patrón E38: escape,
  determinista, escritura atómica).
- `coaching/dashboard/boards/sources.py`: conteos de `journey.yaml` (S84.2)
  como datos del tablero, con su mes y fuente local (pendiente que S84.3 dejó).
- `flow.py`: acción `generate`, sólo con la última decisión `construir`
  (`memory.is_accepted`); la propuesta se reconstruye del catálogo.
- `escala-dashboard/SKILL.md`: Step T3 y piso Markdown.
- `coaching/journey/asks.py`: un YAML dict sin `asks` (p. ej. `"::: x ["`)
  cuenta como corrupto (declinado y respaldo `.bak`).

## Criterios de aceptación

- [x] Sólo una propuesta aceptada genera archivos; «todavía no», «no» o sin
      decisión → `not_accepted`, nada escrito.
- [x] HTML + `.md` sólo en `.escala/my-company/tableros/AAAA-MM-DD-<id>.*`.
- [x] Salida sin `http`, `<script`, `@import`, `url(`, `<link`, `src=`; un
      texto con enlace se reemplaza, no se muestra.
- [x] «Falta: <dato>. Cómo conseguirlo: …»; un supuesto o un rango nunca se
      muestra como número.
- [x] Encabezado «Sólo en tu computadora; no se publica.»; pie con la decisión.
- [x] Texto escapado; salida determinista; HTML y MD dicen lo mismo.
- [x] Legible en teléfono: viewport, una columna de tarjetas, sin tablas,
      barras SVG en línea.
- [x] Sin números no se genera; el mensaje dice qué datos conseguir.
- [x] Conteos del journey entran como datos con mes y fuente; la razón «de
      cada 10» sólo con dos conteos comparables del mismo mes.
- [x] `asks.yaml` sin clave `asks` = corrupto (test primero).
- [x] Recorrido sintético completo automatizado (pedido → propuesta → decisión
      → archivo, por `python -m`) y caso journey → tablero.
