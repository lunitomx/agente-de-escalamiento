# S11.1: Crear repo público y estructura base — Design

## Problem
No existe un repositorio público donde los estudiantes puedan acceder e instalar el Agente de Escalamiento. Todo el código está en el repositorio interno de desarrollo.

## Value
Los estudiantes pueden clonar el repo y seguir las instrucciones de instalación sin depender del equipo de desarrollo.

## Approach
Crear repositorio público en GitHub con licencia MIT. Estructura de directorios que refleje la organización del agente: skills, conocimiento, coaching, validators.

## Components Affected

| Componente | Cambio | Propósito |
|-----------|--------|-----------|
| `github.com/lunitomx/agente-de-escalamiento` | Crear | Repositorio público |
| `escala-skills/` | Crear | Directorio para skills anonimizados |
| `conocimiento/` | Crear | Base de conocimiento estructurada |
| `coaching/` | Crear | Motores Python de coaching |
| `validators/` | Crear | Validadores Python |
| `README.md` | Crear | Documentación inicial |
| `LICENSE` | Crear | Licencia MIT (sin copyright personal) |
| `.gitignore` | Crear | Excluir artefactos locales |

## Complexity
Simple — 1 componente externo (GitHub), sin lógica nueva.

## Acceptance Criteria
- [x] Repositorio público accesible sin autenticación
- [x] Directorios `escala-skills/`, `conocimiento/`, `coaching/`, `validators/` existen
- [x] README.md describe el proyecto y comandos disponibles
- [x] LICENSE es MIT sin copyright personal
- [x] .gitignore excluye `__pycache__/`, `.DS_Store`, `.env`
