# S11.1: Crear repo público y estructura base

## User Story

**Como** Eduardo (creador del Agente de Escalamiento),
**Quiero** tener un repositorio público en GitHub con la estructura de directorios lista,
**Para** que mis estudiantes de licenciatura puedan clonarlo e instalar el agente.

## Acceptance Criteria

### Scenario: Creación del repositorio
- **Given** que tengo acceso a mi cuenta de GitHub
- **When** creo el repositorio `agente-de-escalamiento` como público
- **Then** el repositorio existe en `github.com/lunitomx/agente-de-escalamiento`
- **And** tiene visibilidad pública

### Scenario: Estructura de directorios
- **Given** el repositorio está creado
- **When** configuro la estructura base
- **Then** existen los directorios `escala-skills/`, `conocimiento/`, `coaching/`, `validators/`
- **And** existe `.gitignore`, `LICENSE` (MIT), `README.md`

### Scenario: Primer commit
- **Given** la estructura está lista
- **When** hago el primer commit y push
- **Then** el repositorio remoto refleja la estructura inicial
