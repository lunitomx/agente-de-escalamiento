# Scope: S18.3 — Power of One Interactive (PILOT)

## In Scope
- Modificar el HTML existente de Power of One para incluir sliders (range inputs) para 7 palancas clave
- Cálculo de impacto en tiempo real al mover sliders
- Botón "Guardar" que envía datos a la API del servidor
- Carga de datos guardados al abrir la página (GET /api/worksheets/cash/power-of-one)
- Indicador visual de estado: "modificado" vs "guardado"
- Patrón reutilizable para los demás dashboards (S18.4-S18.7)

## Out of Scope
- Navegación entre dashboards (S18.2)
- SQLite persistencia (S18.8)
- Cambios a otros dashboards (S18.4+)
- Autenticación o multi-usuario

## Done When
- [ ] Power of One tiene 7 sliders funcionales (range input)
- [ ] Mover un slider recalcula el revenue impact en tiempo real
- [ ] Indicador visual muestra "modificado" cuando hay cambios sin guardar
- [ ] Botón "Guardar" hace POST a la API con los datos actuales
- [ ] Al recargar la página, los sliders recuperan los valores guardados
- [ ] Los demás dashboards de Cash (S18.4) pueden heredar el mismo patrón JS
