# Scope: S18.1 — Server Core

## In Scope
- HTTP server using Python http.server on localhost:8080
- Serve static HTML/CSS/JS files (existing dashboards from E14-E17)
- API routing system with GET/POST/PATCH methods
- Endpoints: /api/companies, /api/worksheets, /api/sessions
- CORS headers for local development (localhost origins)
- CLI commands: `escala-server start`, `escala-server stop`, `escala-server status`
- Basic JSON response format for all API endpoints
- Graceful shutdown (SIGINT/SIGTERM handling)
- DAO layer (data access objects) separated from HTTP handler

## Out of Scope
- SQLite schema and persistence (S18.8)
- Authentication or authorization
- Production deployment or cloud hosting
- Dashboard interactivity or UI logic (S18.3+)
- Memory or knowledge graph (S18.9)

## Done When
- [ ] `escala-server start` launches server on port 8080
- [ ] Static HTML files are served correctly from a configured directory
- [ ] GET /api/companies returns valid JSON
- [ ] POST /api/worksheets/{category}/{tool} accepts and returns JSON
- [ ] CORS headers allow cross-origin requests from common local dev ports
- [ ] `escala-server stop` terminates the server process
- [ ] `escala-server status` reports running/stopped state
- [ ] All endpoints respond within 200ms on localhost
- [ ] Server process is a single Python module (escala_server.py or package)
