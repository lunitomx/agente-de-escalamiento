## Task 1: Create .gitignore (S)

**Action:** Update `.gitignore` at repo root with comprehensive exclusion rules.

**Steps:**
1. Read current `.gitignore` content
2. Replace with category-based .gitignore per design doc structure:
   - RaiSE governance: `governance/`, `work/`, `.raise/`, `AGENTS.md`
   - RaiSE dev skills: `.claude/skills/rai-*`
   - Source files: `*.pdf`
   - Build/runtime: `build/`, `__pycache__/`, `*.pyc`, `*.pyo`, `node_modules/`, `.venv/`

3. Confirm NOT ignored (tracked): `.claude/skills/scaleup-*`, `.scaleup/`, `CLAUDE.md`, `README.md`, `templates/`

**Verification:**
```bash

```

**AC coverage:** All 4 Gherkin scenarios

## Task 2: Verify & Integration Test (XS)

**Action:** Validate that .gitignore correctly partitions dev vs product files.

**Steps:**
1. Run `git status` — confirm only end-user files are trackable
2. Run `git check-ignore .claude/skills/rai-session-start` — should return the path (ignored)
3. Run `git check-ignore .claude/skills/scaleup-welcome` — should return nothing (tracked)
