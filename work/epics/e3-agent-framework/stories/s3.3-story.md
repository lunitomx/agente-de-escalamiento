# S3.3 — README.md Quick Start para el empresario

## User Story

**As a** empresario que encuentra el repo en GitHub,
**I want** un README que me explique en < 1 minuto qué es esto y cómo usarlo,
**So that** puedo decidir rápidamente si me sirve y empezar a usarlo sin fricción.

## Acceptance Criteria

```gherkin
Feature: README.md como puerta de entrada al producto

  Scenario: Primera impresión en GitHub
    Given un empresario visita el repo en GitHub
    When lee el README
    Then entiende qué es ScaleUp en los primeros 3 renglones
    And ve los pasos para instalarlo (< 3 pasos)
    And ve qué puede hacer con los slash commands

  Scenario: Instalación y primer uso
    Given el empresario sigue las instrucciones del README
    When clona el repo y abre Claude Code
    Then puede escribir /scaleup-welcome y empezar
    And no necesita configuración adicional

  Scenario: Sin información de desarrollo
    Given el README es para el usuario final
    When lo lee un empresario
    Then NO ve referencias a RaiSE, governance, ni proceso de desarrollo
```

## Size

M

## Notes

- El README es la cara del producto en GitHub
- Debe ser conciso — empresarios no leen documentación larga
- Referencia a CLAUDE.md para detalles de los comandos
- No incluir instrucciones de desarrollo
