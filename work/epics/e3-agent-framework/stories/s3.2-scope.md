# Scope: S3.2 — .gitignore + limpieza del repo

## In Scope

- Create/update `.gitignore` to exclude all development-only files
- Exclude: `governance/`, `work/`, `.raise/`, `.claude/skills/rai-*`, `AGENTS.md`
- Exclude: `*.pdf`, `build/`, `node_modules/`, `__pycache__/`, `.env`, `*.pyc`
- Preserve: `.claude/skills/scaleup-*`, `.scaleup/`, `CLAUDE.md`, `README.md`, `templates/`
- Verify exclusion list is complete against current repo contents

- Deleting files from git history (that's E5 distribution concern)
- Creating README.md or CLAUDE.md content (S3.1, S3.3)
- Restructuring `.scaleup/` directory (S3.4)
- Any changes to skill content
