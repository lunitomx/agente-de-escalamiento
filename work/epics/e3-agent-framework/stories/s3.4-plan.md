## Task 1: Create my-company templates (S)

**Action:** Create `.scaleup/my-company/` directory with 4 template files containing instructional placeholder text.

**Steps:**
1. Create `.scaleup/my-company/profile.md` — company info template with sections: company name, industry, size (employees/revenue), growth stage, top challenges. Each section uses HTML comment placeholders (e.g., `<!-- Replace this with... -->`)
2. Create `.scaleup/my-company/annual-goal.md` — SMART goal template with sections: goal statement, specific, measurable, achievable, relevant, time-bound, key results
3. Create `.scaleup/my-company/quarterly-focus.md` — quarterly focus template with sections: quarter identifier, top 3 rocks/priorities, success metrics, weekly cadence notes
4. Create `.scaleup/my-company/tasks.md` — kanban-style task board with columns: To Do, In Progress, Done. Includes example placeholder tasks showing the format

**Verification:**
```bash
ls -la .scaleup/my-company/
# Expected: profile.md, annual-goal.md, quarterly-focus.md, tasks.md (4 files)
grep -l "<!--" .scaleup/my-company/*.md
# Expected: all 4 files contain placeholder instructions
```

**AC coverage:** AC1 (profile template exists), AC2 (zero real data), AC4 (E6 placeholders exist)
