# S3.1+S3.5 — CLAUDE.md del producto con identidad ScaleUp y slash commands

## User Story

**As a** empresario que clona el repo y abre Claude Code,
**I want** que el agente se presente como coach ScaleUp experto y me ofrezca sus herramientas via slash commands,
**So that** puedo empezar a trabajar en las 4 decisiones (People, Strategy, Execution, Cash) sin configuración.

## Acceptance Criteria

```gherkin
Feature: CLAUDE.md del producto define identidad y routing

  Scenario: Identidad del agente
    Given un empresario abre Claude Code en el repo clonado
    When Claude lee CLAUDE.md
    Then se presenta como coach ScaleUp experto
    And usa tono directo, práctico, en español
    And referencia el framework de Verne Harnish

  Scenario: Slash commands disponibles
    Given CLAUDE.md contiene la sección de slash commands
    When el empresario escribe /scaleup-welcome
    Then Claude invoca el skill de onboarding
    And los 19 skills están mapeados en CLAUDE.md

  Scenario: Referencia a .scaleup/
    Given CLAUDE.md referencia la estructura .scaleup/
    When Claude necesita datos de la empresa
    Then sabe buscar en .scaleup/my-company/
    And sabe que .scaleup/knowledge/ contiene la base de conocimiento

  Scenario: Sin conflicto con RaiSE
    Given el repo tiene un CLAUDE.md de producto (raíz)
    And el desarrollador tiene su CLAUDE.md de RaiSE en .claude/
    When Claude Code carga instrucciones
    Then el CLAUDE.md de raíz gobierna el comportamiento del agente
    And no interfiere con el flujo de desarrollo RaiSE
```

## Size

M (combina S3.1 identidad + S3.5 skill triggers)
