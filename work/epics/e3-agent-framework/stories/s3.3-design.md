# S3.3 — Design: README.md Quick Start

## Problem & Value

**Problem:** El repo no tiene README. Un empresario que lo encuentra en GitHub no sabe qué es ni cómo usarlo.

**Value:** README conciso que convierte visitantes en usuarios en < 1 minuto de lectura.

## Approach

Crear un README.md optimizado para GitHub con estructura de landing page:
1. Hero section (qué es, en 3 líneas)
2. Quick start (3 pasos: requisitos, clone, primer comando)
3. Comandos disponibles (tabla resumida, no detalle completo)
4. Estructura del directorio (qué hay en .scaleup/)

**Componentes:**

| Componente | Tipo | Descripción |
|------------|------|-------------|
| `README.md` (raíz) | crear | README de producto para GitHub |

## Example

```markdown
# ScaleUp Agent

Tu coach AI de escalamiento empresarial. Implementa la metodología **Scaling Up**
de Verne Harnish directamente en tu terminal.

## Quick Start

1. Clona este repositorio
2. Abre Claude Code en el directorio
3. Escribe `/scaleup-welcome`

## Comandos
(tabla resumida por decisión)
```

## Acceptance Criteria

### MUST
1. README.md en raíz explica qué es ScaleUp en < 3 líneas
2. Quick start en 3 pasos (clone, abrir Claude Code, /scaleup-welcome)
3. Tabla resumida de comandos por decisión
4. Sin referencias a RaiSE o desarrollo

### SHOULD
1. Estructura de .scaleup/ explicada brevemente

### MUST NOT
1. No duplicar el detalle de CLAUDE.md (solo resumen)
2. No incluir badges, CI/CD, o infra open source
