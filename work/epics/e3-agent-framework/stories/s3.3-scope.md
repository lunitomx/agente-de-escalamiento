# S3.3 — Scope

## In Scope

- README.md en la raíz del repo con:
  - Qué es ScaleUp (elevator pitch, 3 líneas)
  - Requisitos (Claude Code)
  - Instalación (clone + abrir)
  - Primer uso (/scaleup-welcome)
  - Lista resumida de comandos disponibles

- Documentación detallada de cada comando (eso está en CLAUDE.md)
- Instrucciones de desarrollo o contribución
- Badges, CI/CD, o infraestructura de proyecto open source
- Changelog o versioning
