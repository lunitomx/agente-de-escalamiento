# Story: Adaptadores de capacidad Claude/Codex

## User Story

Como usuario, quiero sugerencias compatibles con mi cliente, sin que ScaleUp me
mande a instalar o autorizar cosas inexistentes.

## Scope

- Contrato de capacidades declaradas por el host, sin adivinarlas.
- Copy específico para Claude, Codex y ausencia de conectores.
- Instrucciones nativas sólo si la capacidad está disponible.

## Acceptance Criteria

- [x] Host sin capacidad recibe alternativa local, no error.
- [x] Ninguna ruta afirma que ScaleUp conectó una cuenta.
- [x] Sugerencias se prueban con fixtures de capacidad.
- [x] Agregar host no cambia política de datos.

## Out of Scope

Instalar o mantener plugins de terceros desde ScaleUp.
