# Story: Política de sugerencia y frontera de datos

## User Story

Como empresario, quiero entender qué fuente externa me ayudaría y qué datos no
debo compartir antes de conectarla.

## Scope

- Matriz de necesidad, fuente mínima, riesgo y alternativa local.
- Taxonomía de secretos, datos empresariales delicados y datos aptos.
- Consentimiento separado: sugerir, preparar, autorizar persistencia o no.

## Acceptance Criteria

- [x] Prohíbe tokens, claves, contraseñas y datos de acceso.
- [x] Cada necesidad tiene alternativa manual/local.
- [x] Autorizar conector no autoriza almacenamiento/indexación.
- [x] Casos ambiguos preguntan o advierten, nunca suponen.

## Out of Scope

UI conversacional o detección de plugins.
