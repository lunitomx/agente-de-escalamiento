# Story: Evaluación adversarial y documentación

## User Story

Como empresa, quiero comprobar que las recomendaciones externas no filtren
información ni engañen sobre permisos.

## Scope

- Casos de secretos, PII, instrucciones inyectadas y permiso ambiguo.
- Matriz de transparencia por host/fuente sugerida.
- Regresión E22/E23/E24 y guía pública no técnica.

## Acceptance Criteria

- [x] Secretos/contenido inseguro no se guardan, indexan ni aparecen en logs.
- [x] Cada recomendación comunica límite, alternativa y cómo detenerse.
- [x] Claude, Codex y host sin conector tienen prueba representativa.
- [x] Documentación no promete integración inexistente.

## Out of Scope

Certificación de servicios externos.
