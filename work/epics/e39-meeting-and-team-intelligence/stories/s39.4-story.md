# S39.4: Local Scheduling and Report Exchange

## User story

Como director, quiero ejecutar una revisión diaria y dejar el reporte en una carpeta ordinaria que pueda compartir, para que el sistema siga siendo local y la carpeta de intercambio nunca se vuelva la autoridad de datos.

## Acceptance criteria

- Given a valid local workspace, when se agenda una revisión, then the schedule manifest is under `data_root` and contains no machine path or cloud endpoint.
- Given an executive review, when se exports, then Markdown/HTML/JSON artifacts are deterministic, relative and local.
- Given an exchange containing SQLite/DB state, when se validates the workspace, then the result fails closed with an explicit local authority finding.
- Given a valid exchange folder, when se writes a report, then the original transcripts remain unchanged and no hosted worker/API is invoked.

## Out of scope

Native OS installer, cloud APIs, email/calendar delivery, report PDF and human acceptance.
