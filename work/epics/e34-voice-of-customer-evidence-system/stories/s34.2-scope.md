# S34.2 Scope: Testimonial Normalization

## In Scope

- Normalize raw quote dictionaries into `CustomerEvidenceRecord` instances.
- Preserve missing source/context/date as reviewable gaps instead of guessing.
- Generate stable evidence ids when raw input does not provide one.
- Detect duplicate source/quote pairs during batch normalization.
- Keep raw quote text separate from interpretation.

## Out of Scope

- Sentiment scoring.
- Bulk external review scraping.
- Voice-to-strategy mapping.
- Prompt hardening.
- Production evidence storage.

## Done When

- Complete raw quotes normalize into valid evidence records.
- Incomplete raw quotes produce reviewable draft records that are not
  strategy-usable.
- Duplicate quote/source pairs are reported and excluded from normalized
  records.
- Tests cover complete normalization, missing provenance, stable id generation,
  and duplicate detection.
