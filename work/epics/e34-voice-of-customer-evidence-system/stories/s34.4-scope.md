# S34.4 Scope: Strategy Prompt Hardening

## In Scope

- Add Voice of Customer evidence requirements to strategy entrypoint guidance.
- Add evidence-first rules to OPSP and 7 Strata strategy prompts.
- Require cited evidence ids before Core Customer, Brand Promise, positioning,
  and Strategy Canvas claims.
- Preserve one-question-per-turn flow when evidence is missing.
- Keep `.agents` and `.claude` mirrored strategy skill docs aligned.

## Out of Scope

- Full strategy course rewrite.
- New strategy framework.
- Visual redesign.
- New evidence mapping code beyond S34.3.
- Production evidence storage.

## Done When

- Strategy skill docs reference `map_evidence_to_strategy`.
- Strategy skill docs require cited evidence ids before claims.
- Strategy skill docs instruct the agent to ask one missing-evidence question at
  a time instead of inventing.
- `.agents` and `.claude` strategy skill mirrors remain aligned.
- Tests prove the prompt hardening language is present.
