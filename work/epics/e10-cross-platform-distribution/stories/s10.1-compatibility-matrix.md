## Tool Call Mapping: Claude Code → Hermes

### Direct Mappings

| Claude Code Tool | Hermes Equivalent | Confidence | Example |
|-----------------|-------------------|------------|---------|
| `Bash("cmd")` | `terminal("cmd")` | High | `terminal("cat .scaleup/my-company/profile.md")` |
| `Read("path")` | `terminal("cat path")` | High | `terminal("cat .scaleup/knowledge/decisions/people.yaml")` |
| `Write("path", content)` | `terminal("cat > path << 'SCALEUP_EOF'\n{content}\nSCALEUP_EOF")` | Medium | Heredoc pattern — needs escaping for YAML content |
| `Edit(file, old, new)` | `terminal("python3 -c \"...\"")` or `process("edit", ...)` | Medium | Python one-liner for safe string replacement |

### Requires Adaptation

| Claude Code Tool | Hermes Approach | Notes |
|-----------------|----------------|-------|
| `AskUserQuestion(questions)` | Hermes native prompt system | Different API — Hermes uses conversational prompts, not structured questions with options |
| `Skill("name")` | Hermes `/skill-name` slash command | Same concept, different invocation |
| `Agent(prompt)` | Hermes task delegation | May need custom wrapper |

### Python Engine Invocation (Same on Both)

```bash
# Claude Code
PYTHONPATH=~/.claude/scaleup python3 -m coaching.diagnose --context '{"profile_path": ".scaleup/my-company/profile.md"}'

# Hermes (identical — both use terminal/bash)
terminal("PYTHONPATH=~/.hermes/scaleup python3 -m coaching.diagnose --context '{\"profile_path\": \".scaleup/my-company/profile.md\"}'")
```

The Python engine invocation is **identical** across platforms — only the PYTHONPATH prefix changes.

## Knowledge Portability Assessment

| Aspect | Status | Notes |
|--------|--------|-------|
| Path references | **All relative** | `retrieval.py` uses `pathlib.Path(__file__).parent` — fully portable |
| External dependencies | **PyYAML only** | Standard library + PyYAML. Available on all platforms |
| Absolute paths | **None found** | Zero hardcoded paths in 90+ YAML files |
| Encoding | **UTF-8 explicit** | All file reads specify `encoding="utf-8"` |

**Verdict:** Knowledge is 100% portable. Copy the directory, set PYTHONPATH, it works.
