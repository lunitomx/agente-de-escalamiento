# S10.1: Discovery & Skill Audit

## User Story

**As a** developer preparing to distribute ScaleUp cross-platform,
**I want to** audit all 39 skills and map platform differences,
**So that** I can build engines and adapters with full knowledge of what exists and what each platform needs.

## Acceptance Criteria

```gherkin
Given the 39 ScaleUp skills in .claude/skills/scaleup-*
When I run the discovery audit
Then each skill is classified as: engine-backed, validator-only, sub-agent, decision-specific, session/task, or utility

Given the Claude Code and Hermes Agent platforms
When I compare tool call conventions
Then a compatibility matrix documents every tool mapping (Bash→terminal, Read→process, Edit, Write, AskUserQuestion)

Given the knowledge files in .scaleup/knowledge/
When I check path references
Then all paths are verified as relative (portable) or flagged as absolute (needs fix)
```
