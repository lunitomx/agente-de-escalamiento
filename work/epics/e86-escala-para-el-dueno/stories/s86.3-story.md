# S86.3 — Cuando algo falla, el dueño sabe qué hacer

## Objetivo

Que el dueño nunca vea (ni el agente improvise a partir de) un traceback, y que
los tropiezos con Drive tengan una frase fija y una salida.

## Alcance

- **A1.** Una sola función en `coaching/core/failsafe.py` (`run_safely`) que
  envuelve el arranque de los 23 `coaching/**/__main__.py`, incluida la
  importación del módulo. Si algo truena: imprime en stdout un JSON con
  `message` = `output` = texto fijo, `artifacts: {}`, `errors: ["internal_error"]`;
  el traceback va a stderr (detalle técnico para el reporte), sale con código 1
  (el mismo que un error no atrapado). Las salidas normales no cambian.
  Texto fijo: "No pude abrir esa parte de ESCALA en tu computadora. No se perdió
  nada. Escribe 'reportar problema' y preparo un aviso para el equipo."
- Skills que dicen "explica/muestra cada error" (dashboard, export, pulse) dicen
  el `message` tal cual ante `internal_error`; `escala/SKILL.md` da la misma
  frase si el módulo ni siquiera arranca (falta Python); `escala-bugreport`
  se activa también con "reportar problema".
- **A2.** En `coaching/tracker/messages.py`: `DRIVE_FILE_NOT_FOUND`,
  `DRIVE_NO_ACCESS` y `connect_message()` neutral ("en la configuración de este
  asistente, en Conectores o Apps"), sin "tu Claude". Nuevas acciones del flujo
  `drive_not_found` / `drive_no_access` (sólo el agente detecta esos casos con
  su conector) y su instrucción en el skill del tracker.
- **Opcional barato.** Encabezados en inglés del formatter de welcome
  ("Company Profile", "Current Focus") en español.

## Tareas (TDD)

1. T1 — `run_safely` + test parametrizado por los 23 módulos (fallo simulado y
   fallo al importar; JSON válido, mensaje fijo, sin traceback en stdout).
2. T2 — Skills: regla de `internal_error`, falta de Python y activación de
   "reportar problema".
3. T3 — Drive: tres casos + test "ningún texto al dueño dice 'tu Claude'".
4. T4 — Encabezados de welcome en español.

- [x] Ningún `message` ni texto al dueño en `coaching/` o `escala-skills/` dice "tu Claude".
- [x] Tests para los tres casos de Drive.
