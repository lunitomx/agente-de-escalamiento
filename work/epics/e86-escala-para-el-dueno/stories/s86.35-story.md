# S86.35 — Quitar el instalador zip viejo

## Objetivo

El dueño instala ESCALA con una sola línea (`instalar.sh`): clona el repo
público a `~/ESCALA` y corre `install.sh`. Actualiza con la misma línea.
Queda vivo un camino de julio 2026 (épica E41) que arma
`escala-local-<plataforma>-<versión>.zip` con su `README.txt`, `install.sh` e
`install.ps1` internos. Nadie lo usa y el README ya no lo menciona. Se quita.

## Mapa: qué usa hoy la instalación real (gemba 2026-10-16)

| Pieza | ¿La usa la instalación de una línea? | ¿Quién más la usa? | Decisión |
|---|---|---|---|
| `instalar.sh`, `install.sh`, `update.sh`, `uninstall.sh` | Sí, son la instalación | — | Se quedan (no citan el zip) |
| `lifecycle/installer.py` → `build_install_bundle` (arma el zip, `README.txt`, `install.sh`/`install.ps1` internos) | No | Sólo pruebas E41 y scripts de calificación E41/E42 | **Se quita** |
| `lifecycle/installer.py` → `install_package` (lee y extrae el zip) | No | Igual | **Se quita la parte del zip** |
| `install_package` → preparar carpetas locales (`install.json`, `config.json`, SQLite, autoridad del espacio) | No | `LifecycleRuntime` y `UpdateManager` leen `install.json`; calificación E41 (REQ-E41-003..007) | **Se queda** como `prepare_local_install(request)` |
| `models.py` → `InstallFile`, `InstallManifest` | No | Sólo el manifiesto del zip | **Se quitan** |
| `models.py` → `InstallRequest`, `InstallReceipt`, `InstallCheck`, resto | No | cli, runtime, updates, scheduler, recibos E41 | Se quedan |
| `lifecycle/cli.py` (comando `escala`, `python -m escala_server.lifecycle`) | No | `pyproject.toml`, prueba de la copia exportada | Se queda |
| `runtime.py`, `updates.py` (respaldo, rollback, migración), `scheduler.py` | No | cli, calificación E41, pruebas | Se quedan |

| `scripts/qualify_e41.py`, `qualify_e42_s42.1.py`, `qualify_e42_s42.3.py` | No | Pruebas e2e y recibos del libro maestro | Se ajustan: sin zip; casos negativos del zip se quitan |
| `install.ps1` en la raíz | No existe | — | — |

## Contrato del libro maestro

- La misión `escala-local-v2-plan-maestro-2607202112` es un identificador; no
  depende del zip. No se toca.
- REQ-E41-001/002 se probaban instalando el zip. La declaración (texto del
  libro) no cambia. Cambia la evidencia: ahora prepara las carpetas locales con
  `prepare_local_install`, sin zip. Se recalifican los 7 recibos E41.
- La lista de lo que viaja (`governance/public-export.yaml`) selecciona la
  carpeta `escala_server/lifecycle` completa: no cambia, no hay re-fijación.

## Criterios de aceptación

1. No queda en el código un generador de `escala-local-*.zip`. Una prueba falla si vuelve.
2. Una prueba confirma que el README sigue indicando la instalación de una línea.
3. Runtime, actualización, rollback, migración y agenda siguen probados.
4. Recibos E41 recalificados; libro maestro: 36 probados, 6 sin probar, igual que antes.
5. Suite, pyright y ruff en verde.
