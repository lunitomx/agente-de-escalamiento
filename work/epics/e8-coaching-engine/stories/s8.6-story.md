# S8.6 — Sub-agent Router

## User Story

**As** a ScaleUp user who completed a diagnosis,
**I want** the agent to automatically route me to the right decision sub-agent,
**So that** I don't have to decide where to start — the methodology guides me.

**As** a developer,
**I want** the routing logic in `.scaleup/coaching/router/`,
**So that** routing rules are deterministic and platform-independent.

## Size: S

## Acceptance Criteria

```gherkin
Feature: Sub-agent Router

  Scenario: Route to lowest-scoring decision
    Given a diagnosis is complete
    When the user accepts the recommended priority
    Then the agent routes to the lowest-scoring decision's sub-agent
    And the sub-agent receives full context (scores, profile, recent sessions)

  Scenario: Direct request overrides routing
    Given a user says "I want to work on Cash"
    When a diagnosis exists
    Then the user's explicit request takes priority over score-based routing

  Scenario: Route to specific decision from progress
    Given a user runs `/scaleup-progress`
    When they click on a decision area
    Then they are routed to that decision's sub-agent
    And shown the relevant pending worksheets

  Scenario: All sub-agents accessible
    Given routing rules are defined
    When any decision is selected (by score, request, or progress)
    Then the corresponding sub-agent is activated
    And routing decisions are logged in session log
```

## Technical Notes

- Router is deterministic: rules in code, not LLM judgment
- Priority rule: lowest score first; tiebreaker People > Strategy > Execution > Cash
- Sub-agents already exist (people.md, strategy.md, execution.md, cash.md in .scaleup/agent/sub-agents/)
- Router in `.scaleup/coaching/router/`
- Integration into CLAUDE.md routing table
- No separate SKILL.md adapter — routing is embedded in CLAUDE.md and diagnosis output
