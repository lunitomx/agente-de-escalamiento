# S8.4 — Progress Tracker

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-progress` and see my coaching progress at a glance,
**So that** I know which decision areas I've completed and what to tackle next.

**As** a developer,
**I want** the progress logic in `.scaleup/coaching/progress/`,
**So that** it works the same way regardless of which agent platform I'm using.

## Size: M

## Acceptance Criteria

```gherkin
Feature: Progress Tracker

  Scenario: View full progress dashboard
    Given a user runs `/scaleup-progress`
    When diagnosis scores exist and worksheets have been completed
    Then completion percentage is shown per decision area (People/Strategy/Execution/Cash)
    And completed vs pending worksheets are listed per decision
    And the next recommended worksheet is suggested based on scores and dependencies

  Scenario: No data yet
    Given a user runs `/scaleup-progress`
    When no diagnosis or worksheets exist
    Then a message suggests starting with `/scaleup-diagnose` first

  Scenario: Data consistency validation
    Given progress data is calculated
    When a Python quality gate runs
    Then it validates completion percentages are non-negative
    And checks that worksheet references match the registry
    And reports inconsistencies if found
```

## Technical Notes

- Reads scores from `company-profile.yaml` and completed worksheets from registry
- Progress = completed worksheets / total worksheets per decision
- Next suggestion = lowest-scored decision with pending worksheets sorted by prerequisite
- Core in `.scaleup/coaching/progress/`, adapter in `.claude/skills/scaleup-progress/`
- Quality gate: `.scaleup/agent/validators/progress.py`
- Output as formatted markdown table (dashboard-style)
