# S8.2 — Diagnosis Engine

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-diagnose` and get a structured assessment of my company across all 4 decisions (People, Strategy, Execution, Cash),
**So that** I know exactly where to focus first based on data, not intuition.

**As** a developer,
**I want** the diagnosis logic in `.scaleup/coaching/diagnose/` as a pure Python module,
**So that** it can be adapted to any agent platform without rewriting assessment logic.

## Size: L

## Acceptance Criteria

```gherkin
Feature: Diagnosis Engine

  Scenario: Full diagnosis of all 4 decisions
    Given a user runs `/scaleup-diagnose`
    When the user answers structured questions for each decision
    Then a score (1-5) is calculated per decision
    And a prioritized recommendation is generated
    And scores are saved to `.scaleup/agent/memory/company-profile.yaml`

  Scenario: Partial re-diagnosis
    Given a user runs `/scaleup-diagnose --decision people`
    When only the People decision is assessed
    Then only the People score is updated
    And other scores remain unchanged

  Scenario: Score validation
    Given scores are calculated
    When a Python quality gate runs
    Then it validates all scores are integers 1-5
    And at least one question was answered per assessed decision
    And validation errors are reported before saving

  Scenario: Priority detection
    Given a new diagnosis is complete
    When scores are calculated
    Then the lowest-scoring decision is flagged as highest priority
    And a brief rationale is provided
```

## Technical Notes

- Each decision assessment is a structured sequence of questions mapped to ontology nodes (E6)
- Questions come from `.scaleup/knowledge/decisions/{decision}.yaml`
- Score calculation: average of question scores, rounded to nearest integer
- Priority = lowest score; tiebreaker: People > Strategy > Execution > Cash
- Core in `.scaleup/coaching/diagnose/`, adapter in `.claude/skills/scaleup-diagnose/`
- Quality gate: `.scaleup/agent/validators/diagnose.py`
