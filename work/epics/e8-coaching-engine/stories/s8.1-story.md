# S8.1 — Coaching Core + Welcome

## User Story

**As** a new ScaleUp user,
**I want** to run `/scaleup-welcome` and be guided through creating my company profile,
**So that** the agent knows my company context and can personalize the coaching from session one.

**As** a developer,
**I want** the welcome logic in a Python core module `.scaleup/coaching/welcome/`,
**So that** it can be reused across Claude Code, Hermes Agent, and Codex via thin adapters.

## Size: L

## Acceptance Criteria

```gherkin
Feature: Welcome / Onboarding

  Scenario: First-time user, no profile
    Given a user runs `/scaleup-welcome`
    When no company profile exists
    Then the intake form is presented (company name, industry, employees, stage)
    And inputs are validated by a Python quality gate
    And profile is saved to `.scaleup/agent/memory/company-profile.yaml`
    And stage is detected (startup/growth/scaling/expansion)
    And the user is offered Lean Canvas (startup) or BMC (expansion)

  Scenario: Returning user with existing profile
    Given a user runs `/scaleup-welcome`
    When a company profile already exists
    Then the existing profile is displayed
    And the user is offered to update or skip
    And updates are validated and saved

  Scenario: Core Python module is callable standalone
    Given the core module `.scaleup/coaching/welcome/`
    When invoked with stdin JSON context
    Then it returns validated output and artifacts
    And it has no dependency on Claude Code or any agent platform
```

## Technical Notes

- Create `.scaleup/coaching/` namespace package
- Create `.scaleup/coaching/core/` with shared utilities (format_profile, validate_yaml)
- Create `.scaleup/coaching/welcome/` with `__init__.py`, `engine.py`, `models.py`
- Create `.claude/skills/scaleup-welcome/SKILL.md` as thin adapter
- Create `.scaleup/agent/validators/welcome.py` quality gate
- Stage detection logic: employees + revenue heuristics per Verne Harnish stages
- Tests in `.scaleup/coaching/welcome/tests/`
