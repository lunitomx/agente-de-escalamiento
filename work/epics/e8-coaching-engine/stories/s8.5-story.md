# S8.5 — Level-Aware Coaching (Shu/Ha/Ri)

## User Story

**As** a returning ScaleUp user with growing mastery,
**I want** the coaching tone and depth to adapt to my level,
**So that** beginners get step-by-step guidance while advanced users get strategic challenges.

**As** a developer,
**I want** the level detection logic in `.scaleup/coaching/level/`,
**So that** the adaptation logic is reusable across agent platforms.

## Size: M

## Acceptance Criteria

```gherkin
Feature: Level-Aware Coaching

  Scenario: Beginner (Shu) level detected
    Given a user has average diagnosis score < 2.5
    When any coaching skill is invoked
    Then the response includes step-by-step instructions
    And explanations of why each step matters
    And no assumption of prior methodology knowledge

  Scenario: Intermediate (Ha) level detected
    Given a user has average diagnosis score 2.5-3.5
    When any coaching skill is invoked
    Then frameworks are presented with autonomy
    And the user is asked to apply concepts independently
    And common pitfalls are highlighted

  Scenario: Advanced (Ri) level detected
    Given a user has average diagnosis score > 3.5
    When any coaching skill is invoked
    Then strategic challenges and edge cases are presented
    And the user is asked to teach back or critique
    And deeper connections between decisions are explored

  Scenario: Level override
    Given a user runs `/scaleup-level --set ha`
    When the level is explicitly set
    Then it overrides the automatic detection
    And is saved to company profile
```

## Technical Notes

- Level detection: average of all 4 diagnosis scores
- Shu: < 2.5, Ha: 2.5-3.5, Ri: > 3.5
- Level info stored in `company-profile.yaml` under `coaching.level`
- Core in `.scaleup/coaching/level/`
- Adapter integrated into ALL other skills' SKILL.md (load level, pass to core)
- Quality gate checks level field format
