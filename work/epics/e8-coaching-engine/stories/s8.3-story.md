# S8.3 — Worksheet Guidance Engine

## User Story

**As** a ScaleUp user,
**I want** to run `/scaleup-worksheet [name]` and be guided step by step through any Scaling Up worksheet,
**So that** I complete worksheets correctly and they get saved to my company directory.

**As** a developer,
**I want** the worksheet guidance logic in `.scaleup/coaching/worksheet/`,
**So that** the guided experience is consistent across agent platforms.

## Size: XL

## Acceptance Criteria

```gherkin
Feature: Worksheet Guidance Engine

  Scenario: Load worksheet by name
    Given a user runs `/scaleup-worksheet core-values`
    When the worksheet exists in `.scaleup/knowledge/registry/worksheets.yaml`
    Then the worksheet template is loaded from the ontology
    And step-by-step guidance is presented
    And each step has validation before proceeding

  Scenario: Complete and save worksheet
    Given a user completes a worksheet
    When all required fields are filled
    Then the completed worksheet is saved to `.scaleup/my-company/worksheets/{name}.md`
    And the registry is updated to mark it completed
    And a Python quality gate validates required fields

  Scenario: Worksheet not found
    Given a user runs `/scaleup-worksheet nonexistent`
    When the worksheet name is not in the registry
    Then a friendly error suggests available worksheets by decision area

  Scenario: Resume incomplete worksheet
    Given a user starts a worksheet
    When they return to it later
    Then previously filled fields are shown
    And they continue from the last incomplete step

  Scenario: Cross-platform core
    Given the core module `.scaleup/coaching/worksheet/`
    When invoked standalone with worksheet name + context
    Then it returns step data, validation rules, and completed output
    And has no agent-platform dependency
```

## Technical Notes

- 34 worksheets in registry; each has: steps, fields per step, validation rules, decision area
- Core module loads worksheet from ontology, manages state (current step, filled data, phase)
- State persisted in session context (YAML frontmatter + body)
- Adapter in `.claude/skills/scaleup-worksheet/SKILL.md`
- Quality gate: `.scaleup/agent/validators/worksheet.py`
- This is the most complex skill — consider splitting into sub-skills if needed
