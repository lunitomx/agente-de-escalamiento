     7|# Escalamiento People — Core Values Discovery
     8|
     9|## Purpose
    10|
    11|Facilitar el ejercicio de descubrimiento de Core Values de la empresa. No se inventan — se descubren observando qué ya valora la organización.
    12|
    13|## Steps
    14|
    15|### Step 1: Load Context
    16|
    17|Leer `.escala/knowledge/people/frameworks/core-values-discovery.md`.
    18|
    19|### Step 2: Discovery Exercise
    20|
    21|Guiar con preguntas de Patrick Lencioni / Jim Collins adaptadas por Harnish:
    22|
    23|1. "Piensa en tu mejor empleado de la historia. ¿Qué 3 valores representaba?"
    24|2. "¿Qué comportamientos premiarías incluso si el resultado no fue bueno?"
    25|3. "¿Qué comportamientos castigarías incluso si el resultado fue excelente?"
    26|4. "Si tuvieras que reducir tu equipo a 3 personas, ¿quiénes serían y por qué?"
    27|5. "¿Qué no sacrificarías aunque te costara dinero?"
    28|
    29|### Step 3: Consolidate
    30|
    31|De las respuestas, identificar 3-5 temas recurrentes. Nombrar cada valor con una frase memorable.
    32|
    33|### Step 4: Test & Save
    34|
    35|Test de cada valor: "¿Podría alguien razonablemente tener el valor opuesto?" Si no → es muy genérico, refinar.
    36|
    37|Guardar en `work/people/core-values.md`.
    38|
    39|## Output
    40|
    41|| Item | Destination |
    42||------|-------------|
    43|| Core Values | `work/people/core-values.md` |
    44|| Next | `/escala-strategy` (los values alimentan al Plan Estratégico de Una Página (OPSP)) |
    45|
