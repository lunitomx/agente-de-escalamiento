# Escalamiento Execution — Prioridad #1 y Tema del Trimestre

## Purpose

Cada trimestre necesitas UNA prioridad. No 3, no 5. Una. Y un Tema que la haga memorable para todo el equipo. Este skill analiza los datos de tus sesiones, worksheets y KPIs, y propone cuál debería ser tu Prioridad #1 con justificación numérica.

## Steps

### Step 1: Analizar las 4 Decisiones

Revisar el estado actual de cada decisión desde los datos disponibles:

- **People:** ¿Hay un hueco crítico en el FACe sin el cual nada más avanza?
- **Strategy:** ¿Hay una decisión estratégica pospuesta que está bloqueando todo?
- **Execution:** ¿Qué KPI tiene la peor tendencia?
- **Cash:** ¿Qué palanca del Power of One daría el mayor impacto?

### Step 2: Proponer la Prioridad #1

Basado en el análisis, proponer:

"Tu Prioridad #1 este trimestre debería ser **[X]** porque:
1. [Evidencia 1 con datos]
2. [Evidencia 2 con datos]
3. Si no lo resuelves este trimestre, [consecuencia concreta]"

Ejemplos de propuestas:
- "Cash: reducir CCC de 67 a 50 días. Si lo logras, liberas $180,000."
- "People: contratar VP de Ventas. Sin esa persona, tu meta de crecer 20% es imposible."
- "Strategy: decidir quién es tu Core Customer. Llevas 3 trimestres sin definirlo y todas tus decisiones estratégicas son inconsistentes."

### Step 3: Definir el Critical Number

"El Critical Number para esta prioridad es **[métrica]**. Meta: [número] para [fecha]."

Reglas:
- Una sola métrica
- Medible semanalmente
- Leading (predice), no lagging (reporta)

### Step 4: Proponer el Tema del Trimestre

El Tema debe ser:
- Memorable (que el equipo lo recuerde sin verlo)
- Accionable (sugiere acción)
- Conectado a la Prioridad #1

Ejemplos:
- Prioridad: Reducir CCC → Tema: "Cash is King"
- Prioridad: Contratar VP Ventas → Tema: "The Right Seat"
- Prioridad: Definir Core Customer → Tema: "Who Matters Most"

### Step 5: Guardar y compartir

Guardar en `work/execution/prioridad-{trimestre}.md`.

"Este es el plan. En el próximo daily huddle, anuncia el Tema. En el próximo weekly, revisa el Critical Number."

## Output

- Prioridad #1 definida con justificación
- Critical Number con meta trimestral
- Tema del trimestre (memorable, accionable)
- Guardado en work/execution/

## Notas

- Si el CEO ya tiene una Prioridad #1 que sigue siendo válida, el skill la refuerza con datos frescos.
- Si los datos no justifican un cambio de prioridad, lo dice: "Tu Prioridad #1 actual (Reducir CCC) sigue siendo la correcta. Aquí está el progreso."
