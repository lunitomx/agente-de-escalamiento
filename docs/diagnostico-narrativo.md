# Diagnóstico narrativo

ScaleUp primero escucha y después mide. Para cada una de las cuatro decisiones
pide una descripción concreta: qué sucede, un ejemplo reciente, su impacto y
el bloqueo principal.

Al terminar una respuesta, muestra lo que entendió y propone una calificación
provisional. Esa cifra no es obligatoria: puedes decir sí, cambiarla con un
número o elegir sin calificación. También puedes dar un número directamente si
prefieres el atajo.

Logo, archivos y enlaces son referencias declaradas. No se confunden con el
nombre o giro de la empresa, ni se revisan, almacenan como contenido o indexan
automáticamente.
