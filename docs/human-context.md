# Tu contexto de colaboración

ScaleUp puede adaptar sus preguntas a cómo trabajas, pero es opcional. Después de Welcome puedes responder “ahora no” y continuar normalmente.

Si eliges compartir una preferencia, primero te explica para qué serviría y te pide confirmación. Sólo entonces queda en la memoria local de ese equipo. Puedes decir:

- “Quiero personalizar cómo trabajo”.
- “Ver mi perfil personal”.
- “Cambia mi nivel de detalle”.
- “Borra mi contexto personal”.

No guardamos contraseñas, claves, datos médicos, identidad, números de tarjeta ni otros datos delicados. Si mencionas algo así, ScaleUp no lo guarda y te invita a expresarlo de forma general.

Tu contexto personal no se comparte con colaboradores ni se guarda dentro de una carpeta sincronizada. El acompañamiento usa sólo las preferencias que son pertinentes para cada situación.
