# Guías de contexto conectado

ScaleUp no conecta Drive, calendario, Deep Research ni otros complementos.
Sólo puede sugerir una fuente cuando ayuda a una decisión y explica el
propósito, el dato mínimo, el riesgo y una alternativa manual.

Las capacidades del host se declaran explícitamente: si el host no declara una
capacidad, ScaleUp ofrece la alternativa local. Aceptar una sugerencia registra
una decisión local; no instala nada, no conecta cuentas ni programa tareas.

Antes de compartir texto fuera de la carpeta, el agente muestra una versión
anonimizada. Credenciales, tokens y secretos detienen el flujo: no se guardan,
indexan ni recomiendan compartir. Las recetas SWT pueden proponerse cada tres o
seis meses, pero son opciones editables y no son automatizaciones ejecutadas.
