# ScaleUp Agent — Estructura

Este directorio contiene todo lo que el agente ScaleUp necesita para ayudarte.

## Directorios

### `my-company/` — Tu Información
Aquí va todo sobre TU empresa. Empieza por `profile.md`.

| Archivo | Qué es | Cuándo llenarlo |
|---------|--------|-----------------|
| `profile.md` | Información de tu empresa | Al inicio (primera sesión) |
| `annual-goal.md` | Tu meta SMART del año | Al inicio y cada año |
| `quarterly-focus.md` | Foco y rocks del trimestre | Cada trimestre |
| `tasks.md` | Compromisos y seguimiento | El agente lo actualiza |

### `knowledge/` — Base de Conocimiento
Contenido del framework Scaling Up organizado por las 4 decisiones:
- `people/` — Personas correctas en los asientos correctos
- `strategy/` — Dirección estratégica clara
- `execution/` — Disciplina de ejecución
- `cash/` — Flujo de efectivo y aceleración

### `agent/` — Configuración del Agente
Personalidad, routing, y sub-agentes. No necesitas modificar esto.

## ¿Por dónde empiezo?

1. Abre Claude Code en este directorio
2. Escribe `/scaleup-welcome` para iniciar tu primera sesión
3. El agente te guiará para llenar tu perfil y hacer tu primer diagnóstico
