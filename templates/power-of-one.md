# Power of One — Análisis de Palancas de Cash

> Empresa: {company_name} | Fecha: {date}

## Concepto

El "Power of One" muestra el impacto en cash flow de mejorar en **1%** (o 1 día) cada una de las 7 palancas. Pequeños cambios en las palancas correctas generan impacto masivo.

---

## Las 7 Palancas

| # | Palanca | Valor Actual | Mejora 1% / 1 día | Impacto en Cash ($) |
|---|---------|-------------|-------------------|-------------------|
| 1 | **Precio** — Subir precio 1% | | +1% | |
| 2 | **Volumen** — Vender 1% más unidades | | +1% | |
| 3 | **COGS** — Reducir costo de producto/servicio 1% | | -1% | |
| 4 | **OpEx** — Reducir gastos operativos 1% | | -1% | |
| 5 | **Cuentas por Cobrar** — Cobrar 1 día antes | | -1 día | |
| 6 | **Inventario/WIP** — Reducir 1 día de inventario | | -1 día | |
| 7 | **Cuentas por Pagar** — Pagar 1 día después | | +1 día | |
