# People Decision Overview

## Purpose
People answers the question: "Would you enthusiastically rehire everyone on your team?"

## Core Concepts
- **Right People, Right Seats**: A-players in roles where they can excel.
- **Core Values**: the filter for hiring, reviews, and exits.
- **Culture**: the observable behaviors that values produce.
- **Role Fit**: the match between person, role, and accountability.

## Tools
- Core Values Discovery
- Function Accountability Chart (FACe)
- Topgrading Hiring Process
- Employee Engagement Practices

## When to Use
Use People tools when the leader struggles with hiring, accountability, culture, or team structure.

## Readiness Check
- Core Values defined? If no → start with Core Values Discovery.
- Roles and accountability unclear? → build FACe.
- Hiring quality low? → implement Topgrading.
- Engagement or retention dropping? → diagnose engagement drivers.
