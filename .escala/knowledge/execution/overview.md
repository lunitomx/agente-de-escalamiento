# Execution Decision Overview

## Purpose
Execution answers the question: "Are all processes running without drama and driving industry-leading profitability?"

## Core Concepts
- **Priorities / Rocks**: the few critical objectives for the quarter.
- **Critical Number**: the one metric that matters most right now.
- **Quarterly Theme**: the rallying cry that makes the priority memorable.
- **Meeting Rhythms**: the cadence that keeps the team aligned.
- **Leading Indicators**: metrics that predict future results.

## Tools
- Rockefeller Habits Checklist
- Meeting Rhythms Planner
- Quarterly Priorities Worksheet
- KPI Development Worksheet

## When to Use
Use Execution tools when the team lacks focus, meetings are ineffective, or priorities are not met.

## Readiness Check
- Regular meeting cadence? If no → start with Meeting Rhythms.
- Clear quarterly priorities? If no → define Quarterly Priorities.
- Visible scoreboard? If no → build KPI Scoreboard.
- Discipline breaking down? → assess Rockefeller Habits.
